Protomaps로 지도 타일 셀프호스팅하기: 이제는 저렴하고 간단하다
via Hacker News (Top)
frontend

상업용 지도 API는 트래픽이 늘면 비용이 급증하는데, Protomaps의 PMTiles 포맷을 이용하면 HTTP Range 요청만으로 단일 파일 지도 타일을 CDN에서 직접 서빙할 수 있습니다. Bunny.net을 이용해 139GB 세계 지도를 복제 저장해도 월 약 $5의 스토리지 비용으로 운영 가능하며, 트래픽 비용도 Mapbox 대비 크게 절감됩니다. rclone을 이용한 업로드 방법과 풀 존 보안·속도 제한 설정, MapLibre GL 임베드 방법까지 실전 가이드를 다룹니다.

💡
트래픽이 급증해도 비용 폭탄 걱정 없이 지도 기능을 제공하고 싶은 프런트엔드 개발자에게, 상업 API 없이 직접 지도 타일을 호스팅하는 실전 비용·구현 가이드를 제공합니다.

uBlock Origin 엘리먼트 피커를 악용한 Universal XSS 취약점 분석
via Hacker News (Top)
frontend

uBlock Origin(Firefox MV2 버전)의 엘리먼트 피커 iframe이 발신자 검증 없이 postMessage를 받아들이는 점을 악용해, 악성 웹사이트가 임의 도메인에 신뢰된 필터(trusted filter)를 주입하고 JavaScript를 실행할 수 있는 Universal XSS가 발견됐습니다. 공격자는 기본 필터 규칙의 fetch 후킹을 역이용해 확장 프로그램 UUID를 알아낸 뒤, 보이지 않는 iframe으로 엘리먼트 피커를 임베드하고 opt 필드에 개행 문자를 삽입해 임의 필터를 생성시켰습니다. 해당 취약점은 현재 패치 완료됐으며, GPT-5.6 Sol이 취약점 가설 조사를, Claude가 PoC 코드 작성을 도운 점도 특징입니다.

💡
브라우저 확장 프로그램이 web_accessible_resources로 노출하는 페이지의 postMessage 검증 부재가 얼마나 치명적인 결과(임의 사이트 코드 실행)로 이어질 수 있는지 보여주는 사례로, 확장 프로그램을 개발하거나 신뢰하는 프론트엔드 개발자 모두가 참고할 보안 설계 교훈을 담고 있습니다.
