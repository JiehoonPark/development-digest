## 핵심 개념

> [!abstract]
> Next.js 16.3의 Turbopack에 개발 메모리 제거, 빌드 지속 파일 캐시, 실험적 Rust React Compiler, `import.meta.glob` 지원이 추가되었다.

## 상세 내용

- 개발 시 메모리 사용 최적화와 빌드 성능 향상을 위한 지속 파일 캐시 추가
- Rust 기반 React Compiler 실험 버전과 `import.meta.glob` 지원으로 개발 경험 개선

> [!tip] 왜 중요한가
> 더 빠른 빌드와 개발 서버 성능이 개발자의 생산성을 직접적으로 향상시킨다.
