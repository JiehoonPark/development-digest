## 핵심 개념

> [!abstract]
> Turbopack의 청킹 전략으로 페이지 로드 속도를 높이고 페이지 간 코드 공유가 가능하며, Next.js 16.3에서 청킹 개선을 위한 실험 기능을 제공한다.

## 상세 내용

- 효과적인 청킹으로 페이지 로드 성능 향상 및 코드 재사용성 증가
- Next.js 16.3의 새로운 실험 기능으로 청킹 전략이 더욱 최적화됨

> [!tip] 왜 중요한가
> 번들 크기 최적화와 성능 개선을 자동으로 처리하여 수동 최적화 작업을 줄일 수 있다.
