## 핵심 개념

> [!abstract]
> phoria2는 차트, 대시보드, 제품 뷰어용으로 설계된 작고 빠른 WebGL 2 기반 3D 라이브러리입니다. PBR 머티리얼, 인스턴싱, 그림자, glTF 로딩 등을 지원하며 런타임 의존성 없이 ES 모듈로 제공됩니다. 특히 모든 옵션을 검증하고 수정 방법까지 알려주는 에러 메시지를 통해 사람과 AI 코딩 에이전트 모두가 쉽게 사용할 수 있도록 설계됐습니다. 2013년 canvas 2D 기반이었던 phoria.js를 WebGL 2로 재구현한 프로젝트입니다.

## 아티클

웹에서 3D를 다루는 라이브러리는 three.js처럼 거대하고 기능이 풍부한 선택지부터 가벼운 캔버스 기반 라이브러리까지 다양합니다. 이번에 Hacker News에 올라온 phoria2는 2013년에 나온 canvas 2D 기반 3D 라이브러리 phoria.js를 WebGL 2로 완전히 다시 만든 프로젝트인데요, 13년이라는 시간 동안 웹 3D 생태계가 어떻게 변했는지, 그리고 그 변화 속에서 작은 라이브러리가 어떤 포지션을 잡으려 하는지 살펴볼 만합니다.

## phoria2가 하려는 것

phoria2는 차트, 레이블이 붙은 씬, 대시보드, 제품 뷰어 같은 비교적 가벼운 3D 시각화를 타겟으로 하는 작고 빠른 JavaScript 라이브러리입니다. 렌더러는 WebGL 2를 사용하며, 공식 소개에 따르면 API를 "하루 오후"면 익힐 수 있을 정도로 단순하게 설계했다고 합니다. three.js 같은 범용 3D 엔진이 아니라, 특정 용도에 맞춰 작고 명확한 API를 제공하는 쪽을 택한 셈입니다.

제공하는 기능 범위도 명시되어 있는데, PBR(Physically Based Rendering) 머티리얼, 인스턴싱, 포인트, 라인, 레이블, 피킹(picking), 그림자, 파티클, 그리고 glTF 모델 로딩까지 포함합니다. 차트나 대시보드 수준의 시각화에 필요한 요소들을 WebGL 2 위에서 한 세트로 묶어 놓은 구성입니다.

## 가벼움과 성능에 대한 접근

phoria2는 런타임 의존성이 전혀 없고, 순수한 ES 모듈로 작성되어 있습니다. 번들러나 프레임워크에 종속되지 않고 바로 가져다 쓸 수 있는 구조인 셈이죠. 또한 뷰(view)는 뭔가 변경이 있을 때만 다시 그리는 방식으로 동작합니다. 즉 매 프레임마다 무조건 렌더링 루프를 도는 게 아니라, 변경 사항이 감지될 때만 다시 그려서 불필요한 GPU 작업을 줄이는 접근입니다. 정적인 차트나 대시보드처럼 사용자 인터랙션이 간헐적으로 일어나는 UI에서는 이런 방식이 CPU/GPU 사용량을 크게 줄여줄 수 있습니다.

## 에이전트 친화적인 설계

이 라이브러리에서 눈에 띄는 설명 중 하나는 "사람과 에이전트 모두를 위한 사용 편의성을 처음부터 염두에 두고 설계했다"는 부분입니다. 구체적으로는 모든 옵션이 검증(validate)되며, 잘못된 값을 넣으면 단순한 에러가 아니라 "어떻게 고쳐야 하는지"까지 설명하는 에러 메시지가 반환됩니다. 이는 사람 개발자뿐 아니라 코드를 생성하는 AI 코딩 에이전트를 염두에 둔 설계입니다. 에이전트가 API를 잘못 사용했을 때, 에러 메시지만으로 스스로 수정할 수 있도록 친절한 피드백 루프를 만들어 둔 셈인데요, 최근 LLM 기반 코딩 도구들이 라이브러리 문서를 직접 읽기보다 실행 결과의 에러 메시지를 참고해 코드를 교정하는 경우가 많다는 점을 생각하면, 이런 설계 철학은 향후 라이브러리 API 설계의 한 트렌드가 될 수 있어 보입니다.

## 배포와 접근성

phoria2는 MIT 라이선스로 공개된 오픈소스 프로젝트입니다. `npm install phoria2` 명령 하나로 설치할 수 있고, GitHub 저장소에서 소스 코드와 문서, 그리고 React 예제까지 확인할 수 있습니다. React 예제가 제공된다는 점에서 단독 사용뿐 아니라 React 기반 대시보드나 제품 페이지에 통합하는 시나리오도 염두에 둔 것으로 보입니다.

## phoria.js에서 phoria2로

phoria2는 2013년 Kevin Roast가 만든 phoria.js의 후속작입니다. phoria.js는 당시 WebGL이 지금처럼 보편화되지 않았던 시절, canvas의 2D 컨텍스트 위에 3D 렌더링을 구현한 라이브러리였습니다. 원문에서는 이를 "그때는 우리가 아직 마법사였던 시절(Back when we were still wizards)"이라는 농담 섞인 표현으로 회고하고 있는데요, canvas 2D API만으로 3D 투영과 래스터화를 직접 구현해야 했던 당시의 수고로움을 돌아보는 뉘앙스입니다. 13년이 지난 지금은 WebGL 2가 브라우저 표준으로 자리 잡았고, phoria2는 그 인프라 위에서 더 적은 코드로 더 풍부한 기능(PBR, glTF, 그림자 등)을 제공할 수 있게 된 셈입니다.

## 정리

- phoria2는 차트, 대시보드, 제품 뷰어 같은 용도에 특화된 작고 빠른 WebGL 2 기반 3D 라이브러리입니다.
- PBR 머티리얼, 인스턴싱, 포인트/라인/레이블, 피킹, 그림자, 파티클, glTF 로딩 등 실용적인 3D 시각화 기능을 갖추고 있습니다.
- 런타임 의존성 없는 순수 ES 모듈이며, 변경이 있을 때만 다시 그리는 방식으로 가볍게 동작합니다.
- 모든 옵션에 대한 검증과 수정 방법을 알려주는 에러 메시지를 제공해, 사람 개발자뿐 아니라 AI 코딩 에이전트의 사용성까지 고려한 설계가 특징입니다.
- MIT 라이선스로 npm에 공개되어 있으며, 2013년 canvas 2D 기반 3D 라이브러리 phoria.js를 WebGL 2로 재구현한 프로젝트입니다.

three.js 같은 대형 엔진이 부담스러운 가벼운 3D 시각화 프로젝트를 고려 중이라면, 또는 AI 코딩 에이전트와 함께 작업할 라이브러리의 API를 설계하는 입장이라면, phoria2의 "에러 메시지가 곧 문서"라는 접근 방식은 참고해볼 만한 포인트입니다.
