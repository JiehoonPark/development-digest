## 핵심 개념

> [!abstract]
> Kevin Powell이 Adam Argyle과 함께 진행한 'CSS 패스트 머니' 퀴즈 코너로, 좋아하는 색상 값·색상 포맷·CSS 속성·단위·항상 찾아보는 속성에 대해 즉석에서 답하고 이를 커뮤니티 설문 결과와 비교합니다. OKLCH가 색상 포맷 1위를 차지하고, display가 선호 속성 1위, rem이 선호 단위 1위, grid가 가장 문법을 헷갈리는 속성 1위로 꼽히는 등 흥미로운 결과가 나왔습니다. Rebecca Purple이 색상 값 1위를 차지한 점도 눈에 띕니다.

## 아티클

크리스 코이어가 떠난 자리를 채우며 CSS 생태계에 꾸준히 의견을 내온 Adam Argyle이 Kevin Powell의 유튜브 채널에 출연해 짧은 "패스트 머니" 퀴즈를 진행했습니다. 방식은 간단합니다. Adam이 CSS 관련 질문 다섯 개에 즉흥적으로 답하고, 이후 Kevin이 미리 커뮤니티를 대상으로 진행한 설문 결과와 비교해보는 식인데요. 전문적인 기술 설명이라기보다는 가벼운 토크 코너지만, 실제 개발자들이 CSS의 어떤 부분을 선호하고 어떤 부분에서 자주 막히는지를 엿볼 수 있는 흥미로운 데이터가 담겨 있습니다.

## 가장 좋아하는 색상 값: 딥핑크는 3표, 1위는 레베카 퍼플

첫 질문은 "가장 좋아하는 CSS 네임드 컬러"였습니다. Adam은 망설임 없이 "deep pink(딥핑크)"를 꼽았는데요. 실제로 설문에서도 딥핑크를 선택한 사람이 3명 있었습니다. 하지만 전체 1위는 아니었습니다.

Kevin이 1위를 맞춰보라고 하자 Adam은 "red나 blue처럼 뻔한 색 아니냐"고 추측했지만, 실제로는 **red가 겨우 2표**, blue는 리스트에 오르지도 못할 만큼 득표가 저조했습니다. 대신 1위는 **Rebecca Purple(레베카 퍼플)**로 29표를 받았습니다. Adam은 이를 듣고 "예상했어야 했는데"라며 아쉬워했는데요. 레베카 퍼플은 CSS 커뮤니티에서 상징적인 의미를 가진 색상 이름인 만큼, 많은 개발자들이 애정을 담아 선택한 결과로 보입니다.

## 가장 좋아하는 색상 포맷: OKLCH가 예상외로 압도적 1위

두 번째 질문인 "가장 좋아하는 색상 포맷"에서 Adam은 **OKLCH**를 선택했습니다. 그런데 이번엔 Adam의 답이 그대로 설문 1위와 일치했습니다. Adam 본인도 "OKLCH는 너무 생소한 개념이라 1위일 거라고는 생각 못 했다"며 놀라워했는데요. 최신 색상 공간인 OKLCH가 이미 실무 개발자들 사이에서 상당히 널리 받아들여지고 있다는 걸 보여주는 결과였습니다.

## 가장 좋아하는 CSS 속성: overflow는 0표, 모두의 선택은 display

세 번째 질문 "가장 좋아하는 CSS 속성"에서 Adam은 **overflow**를 꼽았습니다. 하지만 설문 결과 overflow에 표를 던진 사람은 단 한 명도 없었습니다.

Kevin이 1위를 맞춰보라고 하자 Adam은 anchor, flex 등을 추측했는데요. flex는 5표로 2위를 기록했지만, 정작 1위는 **display**였습니다. 무려 23표를 받았는데, Adam은 이 결과에 "그냥 반사적으로 튀어나오는 답 아니냐"며 다소 황당해했습니다. display가 강력하고 중요한 속성이긴 하지만 "가장 좋아하는 속성"으로 꼽기엔 의아하다는 반응이었죠.

## 가장 좋아하는 단위: CH는 2위, rem이 압승

네 번째 질문은 "가장 좋아하는 CSS 단위"였습니다. Adam은 글자 너비를 기준으로 하는 **CH(character 단위)**를 선택했는데, 이는 15표로 2위에 올랐습니다. 1위는 Adam도 바로 맞춘 **rem**으로, 27표를 받아 확실한 우위를 보였습니다.

## 항상 문법을 찾아봐야 하는 속성: 그라디언트 2위, 그리드가 1위

마지막 질문은 "매번 문법을 검색해서 찾아봐야 하는 CSS 속성"이었습니다. Adam은 **그라디언트(gradient)**를 꼽았고, 이는 14표로 다시 한번 2위를 차지했습니다.

Kevin이 1위를 맞춰보라고 하자 Adam은 background 단축 속성이나 mask를 추측했는데, background는 5표로 상위권에 들긴 했지만 1위는 아니었습니다. 실제 1위는 **grid**로 22표를 받았고, flex와 정렬·정렬축 관련 속성들을 묶은 그룹이 10표로 뒤를 이었습니다. 특히 눈에 띈 건 **box-shadow**가 10표를 받으며 3위를 차지했다는 점인데요. Adam은 "box-shadow 문법은 꽤 직관적인 편이라고 생각했는데 의외"라며 놀라움을 표했습니다.

## 정리

이번 "패스트 머니" 코너는 전문적인 기술 해설보다는 CSS 커뮤니티의 취향과 실무 체감을 숫자로 확인해보는 자리였습니다. 핵심 결과를 정리하면 다음과 같습니다.

- **색상 값**: 개인 취향은 deep pink처럼 갈렸지만, 커뮤니티 전체로는 Rebecca Purple(29표)이 압도적 1위였고 red·blue 같은 전통적인 색은 오히려 인기가 낮았습니다.
- **색상 포맷**: OKLCH가 이미 개발자들 사이에서 가장 선호하는 포맷으로 자리 잡았습니다. 생소하다고 여겨질 수 있는 최신 색상 공간이 실제로는 빠르게 채택되고 있다는 신호입니다.
- **CSS 속성**: display가 "가장 좋아하는 속성" 1위라는 점은 다소 의외의 결과로, 복잡하거나 화려한 속성보다 기본적이고 강력한 속성에 대한 애정을 보여줍니다.
- **단위**: rem이 CH를 제치고 압도적 1위를 차지하며, 반응형·접근성을 고려한 상대 단위 사용이 여전히 대세임을 확인할 수 있었습니다.
- **헷갈리는 문법**: grid가 1위, box-shadow가 예상외의 3위를 차지하며 레이아웃 관련 속성뿐 아니라 비교적 단순해 보이는 속성도 문법을 자주 까먹는다는 공감대를 보여줬습니다.

가벼운 퀴즈 형식이지만, 실제 프론트엔드 개발자들이 어떤 CSS 기능에 애정을 갖고 어떤 부분에서 자주 구글링을 하는지 가늠해볼 수 있는 재미있는 스냅샷이라 할 수 있습니다.
