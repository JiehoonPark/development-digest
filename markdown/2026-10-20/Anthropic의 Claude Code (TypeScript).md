## 핵심 개념

> [!abstract]
> Claude Code는 터미널에서 실행되는 에이전트 기반 코딩 도구로, 코드베이스를 이해하고 자연어 명령을 통해 반복적인 작업 실행, 복잡한 코드 설명, Git 워크플로우 처리 등을 지원한다.

## 상세 내용

- 터미널 기반의 자연어 인터페이스로 코딩 작업 자동화
- 코드베이스 이해 및 Git 워크플로우 통합 지원

> [!tip] 왜 중요한가
> AI 에이전트가 일상적인 개발 작업을 자동화하면서 개발자의 생산성을 크게 향상시킬 수 있는 도구이다.
