## 핵심 개념

> [!abstract]
> 실시간 위성 데이터를 기반으로 한 브라우저 기반 스파이 위성 시뮬레이터로, 포토리얼리스틱한 3D 지구본 위에 오픈소스 공간 정보를 표시합니다.

- 실제 위성 데이터 기반의 시뮬레이션

- 브라우저에서 직접 실행 가능한 오픈소스

> 지구 공간 데이터의 실시간 시각화 기술은 지리정보 기반 애플리케이션 개발에 활용될 수 있습니다.
