## 핵심 개념

> [!abstract]
> Turbopack의 청킹 방식은 페이지 로드 속도를 높이고 페이지 간 코드 공유를 가능하게 하며, Next.js 16.3에서 청킹 개선을 위한 새로운 실험적 기능이 출시되었습니다.

## 상세 내용

- 청킹을 통해 페이지 로드 성능 최적화
- 여러 페이지 간 코드 공유 효율성 증대
- Next.js 16.3에서 청킹 개선을 위한 실험적 기능 제공

> [!tip] 왜 중요한가
> 효과적인 번들 청킹은 최종 사용자의 웹 애플리케이션 성능을 직접적으로 향상시킵니다.
