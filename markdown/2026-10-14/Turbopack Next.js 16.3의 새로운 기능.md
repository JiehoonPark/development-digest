## 핵심 개념

> [!abstract]
> Next.js 16.3의 Turbopack은 개발 중 메모리 제거, 빌드용 지속적 파일 캐시, 실험적 Rust React Compiler, import.meta.glob 지원을 추가했습니다.

## 상세 내용

- 개발 메모리 제거 기능으로 메모리 효율성 개선
- 빌드 성능 향상을 위한 지속적 파일 캐시 도입
- Rust 기반 React Compiler와 import.meta.glob 지원 추가

> [!tip] 왜 중요한가
> Turbopack의 성능 최적화 기능들은 대규모 프로젝트의 빌드 시간 단축과 개발 환경의 안정성을 직접 향상시킵니다.
