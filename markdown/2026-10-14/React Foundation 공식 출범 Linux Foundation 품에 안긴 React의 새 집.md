## 핵심 개념

> [!abstract]
> React와 React Native, JSX 등 관련 프로젝트의 소유권이 Meta에서 Linux Foundation이 호스팅하는 독립 재단인 React Foundation으로 공식 이전됐습니다. Amazon, Callstack, Expo, Huawei, Meta, Microsoft, Software Mansion, Vercel 8개사가 Platinum 창립 멤버로 참여하며 Seth Webster가 상임이사를 맡습니다. React의 기술적 방향성은 재단 이사회와 별개로, 실제 기여자들이 참여하는 거버넌스 구조를 통해 독립적으로 결정될 예정입니다.

## 아티클

React 팀이 2025년 10월 예고했던 React Foundation 출범 소식이 공식화됐습니다. React와 React Native의 소유권이 Meta에서 독립 재단으로 넘어가는 이번 발표는 React 생태계의 거버넌스 구조에 중요한 변화를 의미하는데요, 어떤 조직이 참여하고 앞으로 무엇이 달라지는지 정리해보겠습니다.

## React Foundation 공식 출범

Linux Foundation 산하로 React Foundation이 공식 출범했습니다. 지난 10월 React Foundation 설립 의사를 밝힌 지 약 넉 달 만의 공식화인데요, 이제 React, React Native, 그리고 JSX를 비롯한 관련 프로젝트들은 더 이상 Meta 소유가 아닙니다. 이들 프로젝트는 Linux Foundation이 호스팅하는 독립 재단인 React Foundation 소유로 이전됐습니다. 자세한 내용은 Linux Foundation의 공식 보도자료에서 확인할 수 있습니다.

## 창립 멤버 구성

React Foundation은 8개의 Platinum 등급 창립 멤버로 구성됩니다: Amazon, Callstack, Expo, Huawei, Meta, Microsoft, Software Mansion, Vercel입니다. 10월 최초 발표 이후 Huawei가 새롭게 합류했습니다.

재단 운영은 각 멤버사를 대표하는 이사들로 구성된 이사회가 맡게 되며, Seth Webster가 상임이사(executive director)를 맡습니다.

## 잠정 리더십 위원회 구성

주목할 점은 React의 기술적 방향성 결정 구조가 재단 이사회와는 별개로 운영된다는 것입니다. React의 기술적 거버넌스는 React Foundation 이사회와는 항상 독립적으로 유지되며, React의 기술 방향은 앞으로도 React에 기여하고 유지보수하는 사람들이 직접 결정하게 됩니다.

이 거버넌스 구조를 구체화하기 위해 잠정 리더십 위원회(provisional leadership council)가 구성됐으며, 향후 몇 달 내로 세부 구조에 대한 업데이트가 공유될 예정입니다.

## 앞으로의 과제

재단 전환 작업은 아직 완료되지 않았습니다. 앞으로 몇 달간 다음과 같은 작업들이 진행될 예정입니다.

- React의 기술 거버넌스 구조 확정
- 저장소, 웹사이트 및 기타 인프라를 React Foundation으로 이관
- React 생태계를 지원할 프로그램 모색
- 차기 React Conf 기획 착수

이러한 작업이 진행되는 대로 추가 업데이트가 공유될 예정입니다.

## 정리

- React, React Native, JSX 등 관련 프로젝트는 Meta 소유를 벗어나 Linux Foundation이 호스팅하는 독립 재단인 React Foundation 소유로 전환됐습니다.
- Platinum 창립 멤버는 Amazon, Callstack, Expo, Huawei, Meta, Microsoft, Software Mansion, Vercel 8곳이며, Seth Webster가 상임이사를 맡아 이사회를 운영합니다.
- React의 기술적 의사결정은 재단 이사회와 분리되어, 실제 기여자와 메인테이너들로 구성될 거버넌스 구조(잠정 리더십 위원회가 설계 중)를 통해 독립적으로 이뤄집니다.
- 저장소·인프라 이관, 생태계 지원 프로그램, 차기 React Conf 기획 등 전환 작업이 향후 몇 달간 순차적으로 진행됩니다.
- 이번 전환은 지난 10년간 React를 만들어온 수천 명의 기여자와 커뮤니티 덕분에 가능했다는 점을 React 팀이 강조하고 있습니다.
