## 핵심 개념

> [!abstract]
> 한 개발자가 3D 프린팅한 태양계 행성과 LED 조명을 포치에 설치하고, 이를 대형 스크린과 연동하기 위해 React Native 기반의 Amazon Vega 플랫폼을 사용했습니다. VS Code 확장과 로컬 시뮬레이터, CLI 덕분에 개발이 예상보다 쉬웠고, WLED 컨트롤러 제어는 일반 fetch로, 음성 명령 인식은 aria-label만 추가해 간단히 구현했습니다. React/React Native 경험이 있다면 낮은 진입 장벽으로 TV 앱을 만들 수 있다는 점을 강조하는 짧은 소개 영상입니다.

## 아티클

천체 관측을 좋아하는 가족을 위해 포치(porch)에 태양계 조명 인테리어를 꾸민 개발자의 이야기입니다. 단순히 조명을 다는 데서 그치지 않고, 큰 화면과 조명을 연동해 방문객이 직접 태양계를 탐험할 수 있는 인터랙티브 시스템을 만들었는데요, 이 과정에서 Amazon의 새로운 TV 앱 플랫폼인 Vega를 사용한 경험을 짧게 공유합니다.

## 프로젝트 배경: 3D 프린팅 행성과 LED 조명

이 개발자는 평소 천문학에 관심이 많은 가족을 위해 3D 프린터로 태양계 행성들을 출력해서 포치 뒤쪽에 나란히 배치했습니다. 그리고 각 행성에 제어 가능한 LED 조명을 달아, 영화를 보거나 손님이 왔을 때 분위기를 낼 수 있도록 꾸몄죠. 여기서 한 걸음 더 나아가, 포치에 설치된 대형 프로젝션 스크린과 이 행성 조명들을 서로 연결하고 싶었다고 합니다. 화면에 태양계 지도를 띄우고, 그 정보와 실제 조명을 함께 제어하는 하나의 경험을 만들고 싶었던 겁니다.

## 왜 Amazon Vega인가

이를 구현할 플랫폼을 찾던 중 Amazon Fire Stick과 Vega를 선택했습니다. 이유는 간단한데, Vega가 UI 레이어로 React Native를 사용하기 때문입니다. React와 React Native에 이미 익숙한 개발자 입장에서는 학습 곡선이 거의 없다시피 한 선택이었죠.

실제로 사용해보니 예상보다 훨씬 수월했다고 합니다. Vega는 VS Code 확장을 제공하고, 여기에 로컬 시뮬레이터가 내장되어 있어서 실제 Fire Stick 기기 없이도 코드를 바로 디버깅할 수 있었습니다. 또한 프로젝트를 빠르게 시작할 수 있는 CLI 도구도 함께 제공됩니다.

여기에 더해, LLM 코딩 에이전트들이 React Native 코드를 워낙 잘 다루기 때문에, Vega 공식 문서만 참고 자료로 던져주면 나머지 세부 구현은 에이전트의 도움을 받아 빠르게 처리할 수 있었다고 설명합니다.

## 화면과 조명 연동하기

이렇게 만든 앱을 통해 손님이 방문하면 화면에 태양계 지도를 띄우고, 각 행성에 대한 정보를 함께 보여줄 수 있게 되었습니다. 사용자는 리모컨의 D-pad로 지도를 탐색하면서 포치에 설치된 실제 조명들과 화면 속 행성을 함께 오갈 수 있습니다.

LED 제어에는 WLED 컨트롤러를 사용했는데, Vega 앱에서 일반적인 `fetch` API로 HTTP 요청을 보내는 방식으로 간단히 연동했습니다. 별도의 복잡한 통신 계층 없이, 웹 개발에서 흔히 쓰는 방식 그대로 하드웨어 제어까지 확장한 셈입니다.

## 음성 명령으로 마무리하기

프로젝트의 화룡점정은 음성 인식 기능이었습니다. 방문객이 행성 이름을 말하면 화면과 조명에 해당 행성이 표시되도록 만들고 싶었는데, 이를 구현하는 데 특별히 복잡한 작업이 필요하지 않았습니다. 컴포넌트에 `aria-label`만 추가하면 Vega가 음성 인식 처리를 알아서 해주고, 사용자가 이름을 말했을 때 해당 요소에 대한 press 이벤트를 자동으로 발생시켜 줬기 때문입니다. 실제로 "Saturn"이라고 말하면 바로 그 행성이 화면에 반응하는 모습을 시연하며, 이 기능이 전체 프로젝트를 한층 완성도 있게 만들어줬다고 강조합니다.

## 정리

- 포치에 설치한 3D 프린팅 행성 LED 조명을 프로젝션 스크린과 연동하기 위해 Amazon Vega(React Native 기반 Fire Stick 앱 플랫폼)를 선택했습니다.
- Vega는 VS Code 확장과 로컬 시뮬레이터, 프로젝트 초기화용 CLI를 제공해 React/React Native 경험이 있는 개발자라면 진입 장벽이 낮습니다. LLM 코딩 에이전트와의 궁합도 좋아 공식 문서만 참고해도 개발 속도가 빨랐습니다.
- LED 하드웨어 제어는 WLED 컨트롤러에 일반 `fetch`로 HTTP 요청을 보내는 방식으로 간단히 처리했습니다.
- 컴포넌트에 `aria-label`만 붙이면 Vega가 음성 인식과 press 이벤트 발생을 자동으로 처리해줘서, 별도의 음성 인식 로직 없이 "행성 이름을 말하면 반응하는" 기능을 손쉽게 구현했습니다.
- React/React Native 경험이 있는 프론트엔드 개발자라면, Vega를 통해 익숙한 스택으로 TV/대형 화면용 애플리케이션을 빠르게 만들어볼 수 있다는 점이 핵심 메시지입니다.
