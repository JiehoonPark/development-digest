## 아티클

# Vega로 만든 나만의 태양계 포치 조명 프로젝트

천문학에 진심인 가족을 위해 3D 프린터로 태양계 행성 모형을 만들어 포치 뒤편에 쭉 늘어놓고, 각 행성마다 제어 가능한 LED로 조명을 달아준 적이 있습니다. 영화를 볼 때면 분위기가 정말 좋았는데요, 여기서 한 걸음 더 나아가 포치의 행성 조명들을 대형 프로젝션 스크린과 연동하고 싶어졌습니다. 이번 글에서는 Amazon의 Fire TV용 프레임워크인 **Vega**를 이용해 이 아이디어를 실제로 구현한 과정을 정리해봅니다.

## 왜 Vega를 선택했나

여러 옵션을 살펴보다가 Amazon Fire Stick의 Vega를 선택했습니다. 결정적인 이유는 Vega의 UI가 **React Native** 기반이라는 점이었는데요, React와 React Native에 이미 익숙했기 때문에 진입장벽이 낮을 것이라 판단했습니다. 그리고 실제로 써보니 예상보다 훨씬 수월했습니다.

## 개발 환경과 도구

Vega는 개발 편의성을 위한 도구들을 잘 갖추고 있었습니다.

- **VS Code 확장 프로그램** 제공: 로컬 시뮬레이터가 포함되어 있어 실기기 없이도 코드를 손쉽게 디버깅할 수 있었습니다.
- **CLI 도구** 제공: 프로젝트를 빠르게 초기 세팅할 수 있는 CLI 앱이 있어 시작이 편했습니다.
- **AI 코딩 에이전트와의 궁합**: React Native 기반이다 보니 AI 코딩 에이전트들이 코드 작성을 잘 도와줬고, 세부적인 부분이 필요할 때는 Vega 공식 문서를 에이전트에게 참조시켜 해결했습니다.

## 실제 구현한 기능

이렇게 구축한 환경 위에서 태양계 지도 화면을 만들었습니다. 화면에는 각 행성에 대한 정보가 함께 표시되고, 리모컨의 **D-pad**로 행성들 사이를 이동하며 탐색할 수 있게 했습니다. 손님이 놀러 오면 이 지도를 띄워놓고 각 행성의 정보를 보여줄 수 있게 된 거죠.

LED 조명 제어는 **WLED 컨트롤러**를 사용했습니다. Vega 앱에서 평범한 `fetch`로 WLED 컨트롤러에 HTTP 명령을 바로 전송하는 방식으로, 별도의 복잡한 통신 계층 없이 간단하게 처리했습니다.

## 음성 인식으로 마무리

프로젝트를 한층 더 완성도 있게 만들기 위해 음성으로 행성 이름을 말하면 화면과 조명에 해당 행성이 반응하도록 구현하고 싶었습니다. 놀랍게도 이 기능은 각 요소에 **aria label**을 추가하는 것만으로 해결됐습니다. Vega가 음성 인식 처리를 전부 알아서 해주고, 사용자가 행성 이름을 말하면 그에 맞는 press 이벤트를 자동으로 보내주는 방식이었습니다. "Saturn"이라고 말하면 실제로 화면과 조명이 반응하는데, 이 디테일 하나가 프로젝트 전체를 훨씬 생동감 있게 만들어줬습니다.

## 정리

- Amazon의 Vega는 React Native 기반이라 React/React Native 경험이 있는 개발자라면 진입장벽이 매우 낮습니다.
- VS Code 확장의 로컬 시뮬레이터, 전용 CLI 도구 덕분에 개발-디버깅 사이클이 빠르고 편합니다.
- React Native 생태계 덕분에 AI 코딩 에이전트를 활용한 개발도 잘 맞아떨어집니다.
- 외부 하드웨어 제어(WLED 컨트롤러)도 표준 `fetch` API로 간단히 HTTP 통신만 하면 되어 별도 SDK 학습 부담이 없습니다.
- 접근성을 위해 넣는 `aria-label` 같은 표준 속성이 Vega에서는 음성 명령 인식과 바로 연결되어, 접근성 작업이 곧 부가 기능 구현으로 이어지는 점이 인상적입니다.
- React/React Native를 다뤄본 개발자가 TV/거실 화면용 앱을 빠르게 만들어보고 싶다면 Vega를 시도해볼 만합니다.
