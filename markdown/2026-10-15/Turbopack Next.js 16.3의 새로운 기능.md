## 핵심 개념

> [!abstract]
> Next.js 16.3의 Turbopack에 개발 환경 메모리 제거, 지속적인 파일 캐시, 실험적 Rust React Compiler, `import.meta.glob` 지원이 추가되었습니다.

## 상세 내용

- 개발 중 메모리 효율성 향상을 위한 메모리 제거 기능 도입
- 빌드 성능 개선을 위한 지속적 파일 캐시 지원
- Rust 기반 React Compiler와 동적 import 구문 지원 추가

> [!tip] 왜 중요한가
> 개발 환경의 성능과 빌드 속도 개선으로 개발 생산성이 향상됩니다.
