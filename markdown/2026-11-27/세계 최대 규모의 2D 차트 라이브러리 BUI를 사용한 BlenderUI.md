## 핵심 개념

> [!abstract]
> BlenderUI는 BUI(Blender User Interface)를 기반으로 구축된 2D 차트 라이브러리로, 세계 최대 규모를 표방하고 있습니다.

## 상세 내용

- BUI 프레임워크 위에 구축된 차트 라이브러리
- 2D 차트 시각화에 특화된 솔루션

> [!tip] 왜 중요한가
> 데이터 시각화가 필요한 개발자들이 Blender 기반의 UI 패러다임으로 차트를 구현할 수 있는 대안을 제공합니다.
