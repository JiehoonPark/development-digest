## 핵심 개념

> [!abstract]
> Jack Herrington이 3D 프린팅한 행성 모형과 LED 조명을 대형 스크린과 연동하기 위해 Amazon의 Fire TV 개발 플랫폼 Vega를 사용한 경험을 공유합니다. Vega가 React Native 기반이라 기존 React 지식으로 쉽게 접근할 수 있었고, VS Code 확장과 로컬 시뮬레이터, CLI 도구 덕분에 개발이 예상보다 수월했다고 설명합니다. WLED 컨트롤러 제어는 표준 fetch로, 음성 제어는 aria label 추가만으로 구현 가능했다는 점이 핵심입니다.

## 아티클

## 도입

집 포치에 3D 프린팅한 행성 모형을 죽 늘어놓고 LED로 조명을 밝히는 개인 프로젝트를 진행하던 중, 이걸 거실의 대형 프로젝션 스크린과 연동하고 싶다는 아이디어가 떠올랐습니다. 영화를 보면서 화면 속 행성과 실제 포치의 조명이 함께 반응하면 훨씬 몰입감 있는 경험이 될 것 같았기 때문인데요. 이번 글에서는 Amazon의 Fire TV용 개발 플랫폼인 Vega를 활용해 이 프로젝트를 어떻게 구현했는지 정리해보겠습니다.

## 왜 Vega를 선택했나

천문학에 진심인 가족을 위해 3D 프린터로 태양계 행성 모형을 만들어 포치 뒤쪽에 배치하고, 각 행성을 제어 가능한 LED로 조명을 밝히는 작업을 해왔습니다. 영화를 볼 때 분위기는 좋았지만, 이 조명들을 대형 프로젝션 스크린과 연결할 방법이 필요했습니다.

이것저것 살펴본 끝에 Fire Stick과 Amazon Vega를 선택했는데, 결정적인 이유는 Vega가 UI 구성에 React Native를 사용한다는 점이었습니다. 평소 React와 React Native에 익숙했기 때문에 자연스러운 선택이었고, 실제로 작업해보니 예상보다 훨씬 수월했습니다.

## 개발 경험: VS Code 확장과 로컬 시뮬레이터

Vega에는 VS Code용 확장 기능이 제공되는데, 여기에 로컬 시뮬레이터가 포함되어 있어 코드를 디버깅하기가 매우 편리했습니다. 또한 프로젝트를 빠르게 시작할 수 있는 CLI 도구도 함께 제공되어 초기 세팅 부담이 적었습니다.

React Native 기반이다 보니 AI 코딩 에이전트들도 자연스럽게 잘 활용할 수 있었습니다. Vega 공식 문서를 에이전트에게 참고 자료로 던져주는 것만으로 세부적인 구현 디테일까지 무리 없이 처리할 수 있었습니다.

## 실제 구현: 태양계 지도와 D-pad 내비게이션

완성된 결과물은 이렇습니다. 손님이 오면 화면에 태양계 지도를 띄우고, 각 행성에 대한 정보를 함께 보여줍니다. 리모컨의 D-pad로 지도를 탐색하면서 조명이 켜진 실제 포치의 행성 모형들과 화면 속 지도를 함께 확인할 수 있습니다.

LED 제어는 WLED 컨트롤러를 사용했고, Vega 앱에서 일반적인 `fetch`로 HTTP 명령을 직접 WLED 컨트롤러에 보내는 방식으로 구현했습니다. 별도의 복잡한 통신 계층 없이 표준 웹 API만으로 조명 제어가 가능했던 셈입니다.

## 마무리 터치: 음성 인식으로 행성 이름 부르기

프로젝트를 한 단계 더 완성도 있게 만들기 위해, 사용자가 행성 이름을 말하면 화면과 조명에 해당 행성이 반응하도록 음성 인식 기능을 추가했습니다. 이 부분이 놀라울 정도로 간단했는데, 컴포넌트에 aria label만 추가하면 Vega가 음성 처리 로직을 전부 알아서 처리하고, 이름을 말했을 때의 press 이벤트까지 자동으로 보내줍니다. 예를 들어 "Saturn"이라고 말하면 해당 행성 정보가 화면에 표시되고 실제 조명도 반응하는 식입니다. 별도의 음성 인식 라이브러리나 API 연동 없이 접근성 속성만으로 음성 제어 기능을 구현할 수 있었다는 점이 인상적이었습니다.

## 정리

- Amazon Vega는 Fire TV 앱 개발 플랫폼으로, UI 레이어가 React Native 기반이라 React/React Native 경험이 있는 개발자라면 진입 장벽이 낮습니다.
- VS Code 확장과 로컬 시뮬레이터, 프로젝트 스캐폴딩용 CLI 등 개발 편의 도구가 잘 갖춰져 있어 디버깅과 초기 세팅이 수월합니다.
- React Native 생태계를 그대로 활용하기 때문에 AI 코딩 에이전트를 붙이기도 쉽고, 공식 문서만 참고 자료로 제공해도 충분한 결과를 얻을 수 있습니다.
- 외부 하드웨어(WLED 컨트롤러) 제어는 표준 `fetch`로 HTTP 요청을 보내는 방식만으로 충분히 구현 가능합니다.
- 음성 제어는 컴포넌트에 aria label을 추가하는 것만으로 Vega가 자동으로 처리해주기 때문에, 별도의 음성 인식 구현 없이도 접근성 속성을 재활용해 음성 UX를 만들 수 있습니다.
- React/React Native 경험이 있다면 Vega는 대형 화면(TV) 앱을 만드는 데 있어 상당히 적은 학습 비용으로 시작할 수 있는 선택지입니다.
