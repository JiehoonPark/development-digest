## 핵심 개념

> [!abstract]
> bipluk은 Web MIDI API를 활용해 별도 드라이버나 데스크톱 앱 설치 없이 브라우저 탭에서 80~90년대 신디사이저의 SysEx 패치를 백업·검색·복원할 수 있게 해주는 도구입니다. 헥스-투-ASCII 파서로 패치 이름을 실시간 추출하고 Web Audio로 전송 전 사운드를 미리 들어볼 수 있으며, 클라우드 볼트에 저장된 패치를 CSV로 내보내거나 원클릭으로 하드웨어에 복원할 수 있습니다. 가격은 무료 체험과 $49 평생 라이선스로 나뉘며, $200대인 기존 데스크톱 라이브러리언 대비 저렴함을 내세웁니다.

## 아티클

빈티지 신디사이저를 다뤄본 사람이라면 `.syx` 파일과 씨름해본 경험이 있을 겁니다. 1980~90년대 신디사이저는 패치(사운드 프리셋)를 저장하는 RAM 배터리가 내장돼 있는데, 이 배터리는 결국 방전됩니다. 수십 년간 공들여 만든 사운드를 지키려면 SysEx(System Exclusive) 덤프를 백업해둬야 하는데, 지금까지 이 작업은 MIDI-OX 같은 데스크톱 유틸리티를 설치하고 레거시 드라이버를 붙잡고 씨름해야 하는 일이었습니다. `bipluk`은 이 과정을 통째로 브라우저 안으로 끌고 들어온 프로젝트인데요, Web MIDI API 하나로 설치 없는 SysEx 라이브러리언을 구현했다는 점에서 프론트엔드 개발자 입장에서도 눈여겨볼 만한 사례입니다.

## 문제: 왜 신디사이저 백업은 여전히 1995년에 머물러 있나

빈티지 신디사이저는 하드웨어 자체는 반영구적으로 쓸 수 있게 설계됐지만, 이를 관리하는 소프트웨어 생태계는 전혀 발전하지 못했습니다. bipluk이 지적하는 기존 워크플로우의 문제는 크게 세 가지입니다.

- **데스크톱 유틸리티 설치 필요**: 데스크톱 애플리케이션을 깔거나 레거시 드라이버를 직접 구성해야 함
- **메타데이터 부재**: `.syx` 파일을 수동으로 정리해야 하고, 시각적 검색이나 태그 기능이 없어 이름만 보고는 어떤 패치인지 알 수 없음
- **까다로운 타이밍 제어**: 패킷 손실을 막기 위해 버퍼 페이싱과 밀리초 단위 지연을 직접 설정해야 함

빈티지 신디사이저는 8비트 마이크로프로세서 기반이라 요즘 기준으로는 매우 느린 속도로 데이터를 주고받습니다. 이 타이밍을 잘못 맞추면 덤프 도중 데이터가 깨지거나 유실되는데, 이 부분을 정교하게 다루는 것 자체가 진입 장벽이었습니다.

## 해결책: Web MIDI API 기반의 브라우저 네이티브 워크플로우

bipluk의 핵심은 별도의 앱이나 드라이버 없이 Chrome/Edge 브라우저 탭 안에서 Web MIDI API를 통해 신디사이저와 직접 통신한다는 점입니다. 전체 흐름은 세 단계로 요약됩니다.

**1. MIDI 핸드셰이크(The MIDI Handshake)**
표준 USB-to-MIDI 어댑터로 신디사이저를 연결하면, 브라우저에서 bipluk을 여는 즉시 Web MIDI API가 핸드셰이크를 시작합니다. 별도 드라이버 설치 없이 브라우저가 MIDI 포트를 직접 인식하는 구조입니다.

**2. 인덱스 추출(Index Extraction)**
저수준(low-level) 요청 시퀀스를 신디사이저로 보내 프리셋을 덤프받고, 자체 파서가 실시간으로 레지스터에서 텍스트 문자를 추출합니다. 즉, RAM 메모리 뱅크 레지스터에 담긴 헥스 데이터를 즉석에서 ASCII로 디코딩해 패치 이름을 화면에 바로 표시하는 방식입니다. 여기에 Web Audio API를 활용해 전송 전에 브라우저 안에서 바로 사운드를 미리 들어볼 수 있는 오디션 기능도 붙어 있습니다.

**3. 원클릭 리콜(Single-Click Recall)**
"Sync" 버튼을 누르면 사운드 뱅크 전체 헥사데시멀 데이터 페이로드를 하드웨어에 다시 플래시(flash)해서, 신디사이저의 RAM 레지스터를 즉시 덮어씁니다.

이 과정에서 bipluk이 특히 신경 쓴 부분은 데이터 페이싱(pacing)입니다. 빈티지 8비트 칩의 "섬세한 아키텍처 펄스"에 맞춰 전송 속도를 보정해, 표준 MIDI 덤프를 바이트 단위로 정확하게 기록합니다. 필터 커브나 아날로그적 뉘앙스까지 파라미터 하나하나를 신디사이저의 마이크로프로세서에서 나온 그대로 캡처하는 것을 목표로 삼고 있습니다.

## 클라우드 볼트: 검색 가능한 SysEx 아카이브

단순히 덤프받은 파일을 로컬에 저장하는 것을 넘어, bipluk은 백업한 패치를 프라이빗 클라우드 볼트에 저장합니다. 이 덕분에 사운드 뱅크를 검색하거나, 패치 카탈로그를 CSV로 내보내거나, 필요할 때 원클릭으로 하드웨어에 복원하는 것이 가능해집니다. 랜딩 페이지에 표시된 지표로는 80개 이상의 신디사이저 전용 라이브러리언, 611개의 백업된 패치가 언급되어 있고, 100% 브라우저 네이티브·드라이버 설치 0건을 강조하고 있습니다.

권장 하드웨어 인터페이스로는 Roland UM-ONE나 iConnectivity mio 같은 고품질 USB-MIDI 어댑터가 제시됩니다.

## 가격 정책과 비즈니스 모델

bipluk은 프리 티어와 유료 평생 라이선스로 이원화되어 있습니다.

- **무료 시작(Start Free)**: $0, 카드 등록 없이 바로 시작 가능
- **bipluk+ (Lifetime Access)**: $49 일회성 결제, 구독 없음
  - 무제한 사운드 뱅크 저장
  - 프리셋 이름 즉시 확인
  - 평생 업데이트, 월 요금 없음
  - 83종 이상의 빈티지·모던 신디사이저 지원
  - 백업 파일을 `.syx`/`.zip`/`.csv` 형식으로 언제든 다운로드
  - RAM 배터리 방전으로부터 패치 보호
  - 광고 없음, VC 투자 없이 고객 결제만으로 운영

랜딩 페이지에서는 데스크톱 라이브러리언 소프트웨어가 보통 $200 이상인 것과 비교해, $49 일회성 결제로 80% 이상 절감된다는 점을 셀링 포인트로 내세우고 있습니다. 256비트 SSL 암호화를 적용했고, 지원은 이메일(halfradiationllc@gmail.com)로 받으며 통상 2~4시간 내 응답한다고 안내합니다.

## 정리

- bipluk은 Web MIDI API만으로 데스크톱 앱이나 드라이버 설치 없이 브라우저 탭에서 SysEx 덤프를 주고받는 프로젝트로, "설치 제로"라는 콘셉트를 실제 하드웨어 통신 영역까지 확장한 사례입니다.
- 헥스-투-ASCII 파서로 RAM 레지스터의 패치 이름을 실시간 추출하고, Web Audio API로 전송 전 오디션 기능을 제공하는 등 브라우저 API 조합만으로 전문 유틸리티급 워크플로우를 구현했습니다.
- 빈티지 8비트 신디사이저의 느린 통신 속도에 맞춘 데이터 페이싱 보정, 바이트 단위 정밀 덤프 등 저수준 MIDI 프로토콜을 브라우저 환경에서 안정적으로 다루는 기술적 디테일이 핵심입니다.
- 비즈니스 모델은 무료 체험 + $49 평생 라이선스 구조로, $200대인 기존 데스크톱 라이브러리언 대비 가격 경쟁력을 내세우며 광고·VC 없이 고객 결제만으로 운영되는 인디 개발 방식을 표방합니다.
- 프론트엔드 개발자에게는 Web MIDI API, Web Audio API 같은 브라우저 하드웨어 접근 API를 실제 레거시 하드웨어와의 통신이라는 니치 영역에 적용해 SaaS 제품으로 완성한 참고 사례로 볼 수 있습니다.
