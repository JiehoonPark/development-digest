## 핵심 개념

> [!abstract]
> AI 코딩 에이전트의 컨텍스트 윈도우 최적화를 위해 도구 출력을 샌드박싱(98% 감소), 세션 메모리 유지, MCP와 훅을 통한 17개 플랫폼 라우팅을 제공합니다.

- 출력 크기를 98% 감소시키는 샌드박싱 기술로 컨텍스트 윈도우 효율화
- MCP 기반 멀티플랫폼 라우팅과 세션 메모리 관리

> [!tip] 왜 중요한가
> LLM 에이전트의 토큰 효율성을 크게 개선하여 비용 절감과 응답 성능 향상에 기여합니다.
