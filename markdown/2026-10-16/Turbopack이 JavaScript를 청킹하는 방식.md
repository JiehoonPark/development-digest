## 핵심 개념

> [!abstract]
> Turbopack의 청킹 기능이 페이지 로드 속도를 개선하고 페이지 간 코드 공유를 가능하게 합니다. Next.js 16.3에서 청킹 개선을 위한 새로운 실험 기능이 추가되었습니다.

## 상세 내용

- Turbopack의 청킹 메커니즘으로 페이지 로드 성능 최적화
- Next.js 16.3에서 청킹 관련 새로운 실험 기능 출시

> [!tip] 왜 중요한가
> 번들 최적화는 웹 애플리케이션의 성능에 직결되므로 개발자가 주목해야 할 기능입니다.
