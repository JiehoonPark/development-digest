## 핵심 개념

> [!abstract]
> Next.js 16.3의 Turbopack에 개발 메모리 제거, 지속적 파일 캐시, 실험적 Rust React Compiler, `import.meta.glob` 지원 등이 추가되었습니다.

## 상세 내용

- 개발 환경 메모리 사용량 최적화와 빌드 캐싱 성능 개선
- Rust 기반 React Compiler와 동적 import 문법 지원으로 개발 경험 향상

> [!tip] 왜 중요한가
> Turbopack의 성능 개선 사항들은 개발 속도와 프로덕션 빌드 효율성에 직접적인 영향을 미칩니다.
