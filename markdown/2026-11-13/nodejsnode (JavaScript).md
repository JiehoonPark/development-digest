## 핵심 개념

> [!abstract]
> Node.js는 JavaScript 런타임으로, 서버 측 JavaScript 실행 환경을 제공합니다. 오픈소스 프로젝트로 활발히 유지보수되고 있습니다.

## 상세 내용

- JavaScript를 이용한 서버 애플리케이션 개발 가능
- 이벤트 기반 비동기 처리로 높은 성능 제공

> [!tip] 왜 중요한가
> Node.js는 웹 백엔드 개발의 표준 런타임으로 JavaScript 풀스택 개발을 가능하게 합니다.
