## 핵심 개념

> [!abstract]
> Tailwind CSS는 유틸리티 클래스 기반의 CSS 프레임워크로, 빠른 UI 개발을 지원합니다.

## 상세 내용

- 유틸리티 우선(utility-first) 방식으로 HTML에서 직접 스타일 적용
- 빠른 프로토타이핑과 반응형 디자인에 최적화

> [!tip] 왜 중요한가
> 현대적인 웹 개발에서 CSS 작성 방식을 변화시켜 개발 생산성을 높일 수 있습니다.
