## 핵심 개념

> [!abstract]
> 포치에 세운 3D 프린팅 행성 조명과 거실 프로젝션 스크린을 연동하기 위해 Amazon Fire Stick의 Vega 프레임워크를 사용한 개인 프로젝트 경험을 다룹니다. React/React Native 경험만으로 VS Code 확장, 로컬 시뮬레이터, CLI 도구를 활용해 손쉽게 개발할 수 있었고, fetch로 WLED 컨트롤러를 제어하고 aria-label만으로 음성 인식 기능까지 구현한 과정을 소개합니다.

## 아티클

포치에 3D 프린팅한 태양계 행성들을 세워두고 LED로 조명을 밝히는 개인 프로젝트를 진행하던 중, 영화를 볼 때 사용하는 대형 프로젝션 스크린과 이 조명들을 연동하고 싶다는 아이디어가 생겼습니다. 이를 구현하기 위해 React/React Native 경험을 살려 Amazon의 Fire Stick용 프레임워크인 Vega를 선택했는데, 실제로 사용해보니 예상보다 훨씬 수월했다는 경험을 공유합니다.

## 프로젝트의 시작: 포치 위의 태양계

집안 전체가 천문학에 관심이 많아서, 3D 프린터로 출력한 행성 모형들을 포치 뒤편에 나란히 세워두고 각각 제어 가능한 LED로 조명을 밝히는 작업을 해두었습니다. 영화를 보는 동안 이 조명들이 있으면 분위기가 꽤 좋았는데요, 여기서 한 걸음 더 나아가 포치의 행성 조명들과 거실의 대형 프로젝션 스크린을 서로 연결하고 싶다는 생각이 들었습니다.

## 왜 Vega인가

여러 옵션을 찾아보다가 Amazon Fire Stick의 Vega를 선택했습니다. 결정적인 이유는 Vega의 UI가 React Native 기반이라는 점이었습니다. 평소 React와 React Native에 익숙했기 때문에 진입 장벽이 낮을 것이라 예상했고, 실제로도 그 예상은 정확히 맞아떨어졌습니다.

Vega는 개발 경험 측면에서도 꽤 잘 갖춰져 있었습니다.

- **VS Code 확장 프로그램** 제공: 코드 디버깅을 훨씬 편하게 만들어주는 로컬 시뮬레이터가 포함되어 있어 실제 기기 없이도 개발 중 확인이 가능했습니다.
- **CLI 도구** 제공: 프로젝트를 처음 세팅할 때 CLI 앱으로 빠르게 시작할 수 있었습니다.
- **AI 코딩 에이전트와의 궁합**: React Native 기반이다 보니 코딩 에이전트들이 이미 관련 지식을 잘 갖추고 있었고, 세부적인 부분은 Vega 공식 문서를 참고하도록 에이전트에 지시하는 것만으로 충분했습니다.

## 실제 구현: 지도, 조명 제어, 음성 인식

이렇게 만든 결과물은 다음과 같이 동작합니다.

**태양계 지도 내비게이션**: 손님이 오면 리모컨의 D-패드로 태양계 지도를 탐색하며 각 행성에 대한 정보를 화면에 띄울 수 있습니다.

**LED 제어**: 포치의 LED는 WLED 컨트롤러로 제어하는데, Vega 앱 안에서 일반적인 `fetch`를 사용해 HTTP 요청을 직접 WLED 컨트롤러로 보내는 방식으로 구현했습니다. 별도의 복잡한 미들웨어 없이 표준 웹 API만으로 하드웨어 제어까지 연결한 셈입니다.

**음성 인식 연동**: 마지막 화룡점정으로, 사용자가 행성 이름을 말하면 화면과 조명에 해당 행성이 표시되도록 만들고 싶었습니다. 이 기능은 놀랍도록 간단하게 구현됐는데, 컴포넌트에 `aria-label`만 추가하면 Vega가 음성 인식 처리를 전부 알아서 처리하고, 사용자가 그 이름을 말했을 때 press 이벤트를 자동으로 보내주는 방식이었습니다. 예를 들어 "Saturn"이라고 말하면 해당 행성이 자동으로 선택되는 식입니다. 접근성을 위해 추가하는 속성 하나로 음성 제어 기능까지 얻게 된 셈이라, 프로젝트에 생동감을 더하는 데 큰 역할을 했습니다.

## 정리

- 이미 React나 React Native 경험이 있다면 Amazon Vega는 TV/Fire Stick용 애플리케이션을 만드는 데 진입 장벽이 매우 낮은 선택지입니다.
- VS Code 확장과 로컬 시뮬레이터 덕분에 실기기 없이도 디버깅이 가능하고, CLI로 프로젝트를 빠르게 시작할 수 있습니다.
- React Native 기반이라 AI 코딩 에이전트의 지원을 받기도 수월하며, 세부 사항은 공식 문서를 참고시키는 것만으로 충분했습니다.
- 표준 `fetch`로 외부 하드웨어(WLED 컨트롤러)를 제어할 수 있고, `aria-label`만 추가해도 음성 명령 처리가 자동으로 붙는 등, 웹 개발자에게 익숙한 패턴들이 그대로 적용됩니다.
- 대형 화면(TV)용 애플리케이션을 만들어야 하는데 React 생태계에 익숙하다면, Vega는 시도해볼 만한 실용적인 선택지입니다.
