## 핵심 개념

> [!abstract]
> Turbopack의 청킹 기능이 페이지 로드 속도를 높이고 페이지 간 코드 공유를 가능하게 하며, Next.js 16.3에서 청킹 개선을 위한 새로운 실험 기능이 출시되었다.

## 상세 내용

- JavaScript 청킹을 통해 초기 페이지 로드 시간 단축
- 여러 페이지 간의 공통 코드 재사용으로 번들 크기 최적화
- Next.js 16.3의 실험 기능으로 청킹 전략 지속적으로 개선 중

> [!tip] 왜 중요한가
> 효율적인 코드 분할은 사용자 경험을 직접 향상시키는 핵심 최적화 기법이다.
