## 핵심 개념

> [!abstract]
> Next.js 16.3의 Turbopack에 개발 메모리 제거, 빌드용 영구 파일 캐시, 실험적 Rust React Compiler, import.meta.glob 지원이 추가되었다.

## 상세 내용

- 개발 모드에서 메모리 효율성을 개선하는 메모리 제거 기능 도입
- 빌드 성능을 높이는 영구 파일 캐시 추가
- import.meta.glob 지원으로 동적 모듈 로딩 기능 확대

> [!tip] 왜 중요한가
> Next.js 프로젝트의 빌드 속도와 개발 환경 메모리 효율을 개선하여 개발 경험을 향상시킨다.
