## 핵심 개념

> [!abstract]
> Pangram이 AI 생성 이미지와 영상을 탐지하는 정식 모델 Pangram Image 1.0과 경량 모델 Flash 1.0을 공개했습니다. 이미지 모델은 1,200장 합성 이미지 평가에서 99.96% 정확도를 기록했고, 영상 모델은 DF26 벤치마크에서 98.7%로 2위 대비 29%포인트 앞섰습니다. 두 모델 모두 크롬 익스텐션과 API로 제공되며, 저해상도·압축 환경에 대한 견고성도 강화됐습니다.

## 아티클

AI로 생성된 이미지·영상을 가려내는 탐지 모델 시장이 빠르게 성장하고 있습니다. 텍스트 생성형 AI 탐지로 이름을 알린 Pangram이 이번엔 이미지와 비디오 영역으로 보폭을 넓혀, 정식 버전인 Pangram Image 1.0과 경량 모델 Pangram Image Flash 1.0을 공개했습니다. 몇 달 전 연구 프리뷰로 먼저 선보였던 제품이 커뮤니티의 피드백을 거쳐 정식 출시된 것인데, 어떤 점이 달라졌는지 살펴보겠습니다.

## 무엇이 새로워졌나

이번 릴리스는 두 개의 모델로 구성됩니다.

플래그십 모델인 **Pangram Image 1.0**은 다음 기능을 제공합니다.

- 최신 AI 이미지 생성기 탐지에서 최고 수준의 성능
- 이미지 내 AI 생성 영역을 정확히 짚어주는 히트맵 출력
- 편집, 압축, 저해상도 변환에 대한 강인성

더 작고 빠른 모델인 **Pangram Image Flash 1.0**은 다음을 제공합니다.

- 최신 AI 영상 생성기 탐지에서 최고 수준의 성능
- AI로 편집된 영상에 대한 프레임 단위 분석
- 피드 속 AI 콘텐츠를 탐지하는 크롬 익스텐션 지원
- 이미지·영상 모두를 위한 API 지원

## Pangram Image 1.0의 탐지 성능

연구팀은 자체 모델을 여러 상용·학계 AI 이미지 탐지기와 비교 평가했습니다. 실제 사진 100장을 원본과 최대한 유사한 프롬프트로 12개의 최신 AI 이미지 생성기에 입력해 총 1,200장의 합성 이미지를 만들고, 이를 실제 사진과 구분하는 테스트를 진행했습니다. 그 결과 Pangram Image 1.0은 이 평가셋에서 **99.96%의 정확도**를 기록했습니다.

또한 X-AIGD, Mirage-Test, AIGenImages2026, Synthbuster + RAISE comparison, Community Forensics 등 여러 학계 벤치마크에서도 비교 검증을 거쳤습니다.

### 압축·저해상도에도 강한 견고성

소셜 미디어 플랫폼 대부분은 업로드되는 이미지를 압축하고 해상도를 낮춥니다. 또한 악의적인 사용자는 블러, 노이즈 등의 아티팩트를 추가해 탐지기를 속이려 시도하기도 합니다. Pangram은 이런 변형들을 학습 단계에서부터 고려해, 이러한 편집에도 모델이 견고하게 작동하도록 훈련했다고 밝혔습니다.

기존 버전은 입력 이미지의 최소 크기를 512x512로 제한했는데, 그 이하 해상도에서 정확도가 떨어졌기 때문입니다. 이번 1.0 버전에서는 저해상도에서도 정확도가 개선되어 최소 입력 크기를 **256x256**까지 낮췄습니다. 다만 512 미만 해상도에서는 결과에 신뢰도가 낮다는 경고 문구가 함께 표시됩니다.

## 영상 탐지: Pangram Image Flash 1.0

사람이 말하는 모습을 담은 영상에서 실제 영상과 AI 생성 영상을 구분하는 일은 생각보다 어렵습니다. 최근 발표된 학계 연구 **DF26**에 따르면, 사람이 이를 구분하는 정확도는 무작위 추측과 거의 다를 바 없었고, 기존 탐지 모델들도 크게 나을 것이 없었다고 합니다.

이런 배경에서 공개된 Pangram Image Flash 1.0은 최신 AI 영상 생성기 탐지에 특화된 빠른 모델입니다. DF26 벤치마크에서 **98.7%**의 점수를 기록했는데, 이는 2위 탐지기 대비 **29%포인트** 앞선 수치입니다.

### 업계 비교 테스트

연구팀은 실제 소셜 미디어 영상 129개를 수집하고, 14개의 최신 영상 생성기를 이용해 각 생성기당 100개씩(129개의 실제 영상 중에서 샘플링) 합성 영상을 만들었습니다. 생성기에는 실제 영상의 첫 프레임을 시드로 주고, VLM이 생성한 영상 설명을 프롬프트로 함께 입력해 최대한 실제와 유사한 합성 미러 영상을 만들었습니다. 이렇게 만들어진 총 1,529개의 영상을 대상으로 여러 주요 AI 영상 탐지 서비스와 Pangram 모델을 비교했습니다.

실제 영상 프레임에서 출발해 합성 미러를 만드는 이 방식은 두 개의 매우 사실적인 영상을 구분하는 모델의 능력을 평가할 수 있게 해줍니다. 실제 영상과 그 미러가 동일한 장면과 피사체를 공유하기 때문에, 특정 유형의 콘텐츠를 무조건 AI로 판정하는 편향을 방지할 수 있다는 설명입니다.

또한 AIGVDBench, DF26, Ivy-Fake 등 여러 학계 벤치마크에서도 Image Flash 모델이 최고 수준의 성능을 기록했으며, 이 벤치마크들을 합치면 사실상 거의 모든 최신 영상 생성 모델을 커버한다고 밝혔습니다.

## 네이티브 비디오 지원과 크롬 익스텐션

Pangram은 이제 영상 업로드를 네이티브로 지원합니다. 영상을 업로드하면 Pangram Image Flash 1.0이 프레임 단위로 분석해, 영상의 어느 부분이 AI로 생성됐는지 전체적으로 보여줍니다.

크롬 익스텐션에도 Pangram Image 1.0이 통합되었습니다. 소셜 미디어 피드, 온라인 쇼핑, 임대 매물 리스팅 등 콘텐츠의 진위 여부가 중요한 모든 사이트에서 스크롤하는 동안 AI 생성 콘텐츠를 실시간으로 표시해줍니다.

## API

Pangram Image 1.0과 Flash 1.0 출시와 함께 API도 이미지·영상 탐지를 모두 지원하도록 업데이트되었습니다. 이를 통해 개발자와 커뮤니티가 직접 이 모델들을 자신의 서비스에 통합할 수 있습니다.

## 정리

Pangram Image 1.0은 100장의 실제 사진을 12개 최신 생성기로 복제한 1,200장의 합성 이미지 평가에서 99.96% 정확도를 기록했고, 최소 입력 해상도를 512x512에서 256x256으로 낮추며 저해상도·압축 환경에서도 견고성을 높였습니다. Flash 1.0은 사람조차 구분하기 어려운 AI 생성 영상을 DF26 벤치마크에서 98.7% 정확도로 탐지해 2위 모델보다 29%포인트 앞섰으며, 프레임 단위 분석과 네이티브 비디오 업로드를 지원합니다. 두 모델 모두 크롬 익스텐션과 API로 제공되어, 소셜 미디어나 쇼핑몰 등 실생활 환경에서 AI 생성 콘텐츠를 가려내는 데 바로 활용할 수 있습니다.

프론트엔드나 콘텐츠 플랫폼을 다루는 개발자라면, 사용자 생성 콘텐츠(UGC)의 신뢰도를 검증해야 하는 서비스에 이런 탐지 API를 연동하는 사례가 앞으로 늘어날 것으로 보입니다. 특히 해상도 제한이나 압축 환경에서의 성능 저하 이슈는 실제 프로덕션에 적용할 때 눈여겨봐야 할 부분입니다.
