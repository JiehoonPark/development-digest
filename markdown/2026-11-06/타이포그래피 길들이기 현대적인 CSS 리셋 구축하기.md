## 핵심 개념

> [!abstract]
> text-wrap, container query units, text-box 등 최신 CSS 기능을 활용한 종합적인 타이포그래피 리셋 가이드다. tidy-typography.css라는 현대적 기본 스타일시트를 제시하며, 브라우저 지원이 제한적인 실험적 기능들을 점진적으로 적용할 수 있도록 안내한다.

## 상세 내용

- text-wrap: pretty와 text-box-trim을 활용하여 고아 단어 제거 및 수직 리듬 개선
- Container query units(cqi), font-variant-*, text-decoration 세부 속성 등으로 타이포그래피의 세밀한 제어 가능
- 모든 선언이 브라우저에서 무시되므로, 지원되지 않는 기능도 포함하여 점진적으로 도입 가능

> [!tip] 왜 중요한가
> 최신 CSS 타이포그래피 기능을 체계적으로 활용하면 더 나은 가독성과 사용자 경험을 제공하는 웹페이지를 구축할 수 있다.
