## 핵심 개념

> [!abstract]
> Firenook는 Firebase 에뮬레이터의 Rust 구현으로, 네이티브 및 웹 SDK, 실시간 리스너, Security Rules, 명명된 데이터베이스, 공식 임포트/익스포트를 지원한다. 기존 Firebase 에뮬레이터 대비 쓰기 성능이 40배 향상되고 메모리 사용량이 10배 감소하였다.

## 상세 내용

- Firebase 에뮬레이터를 Rust로 재구현하여 쓰기 성능 40배 개선 및 메모리 사용량 10배 감소 달성
- 실시간 리스너, Security Rules 등 Firebase의 주요 기능을 완벽히 지원하며 기존 임포트/익스포트 호환성 유지

> [!tip] 왜 중요한가
> Firebase 개발 시 로컬 에뮬레이션 환경의 성능 병목을 크게 해소할 수 있어, 개발 속도와 효율성 향상에 기여한다.
