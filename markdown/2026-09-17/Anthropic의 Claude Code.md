## 핵심 개념

> [!abstract]
> Claude Code는 터미널에서 동작하는 에이전트 기반 코딩 도구로, 자연어 명령을 통해 코드베이스를 이해하고 일상적 작업 자동화, 복잡한 코드 설명, Git 워크플로우 처리를 지원합니다.

## 상세 내용

- 터미널 기반의 자연어 인터페이스로 코딩 작업 자동화
- 코드베이스 분석 및 복잡한 코드 설명 기능 제공
- Git 워크플로우를 포함한 반복적 작업 자동 처리

> [!tip] 왜 중요한가
> 개발자의 생산성 향상과 루틴 작업 자동화로 핵심 개발에 집중할 수 있습니다.
