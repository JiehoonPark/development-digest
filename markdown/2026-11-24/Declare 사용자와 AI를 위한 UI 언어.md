## 핵심 개념

> [!abstract]
> Declare는 UI 개발을 위한 도메인 특화 언어로, 구조화되고 컴파일러가 검증할 수 있으며 AI와 협업하도록 설계되었습니다. 같은 요구사항으로 작성한 React 앱(2,666줄)과 비교할 때 Declare 앱(1,279줄)이 더 짧고 첫 번째 빌드에서 모든 검증을 통과했습니다.

## 상세 내용

- 레이아웃, 모션, 상태, 테마, 그리기가 언어 자체에 포함되어 라이브러리 의존성 없이 디자인을 직접 표현 가능합니다.
- 컴파일러가 모든 오류를 정확한 재작성 제안과 함께 보고하여 AI 모델의 오류 수정을 개선하고 프로그램 정확성을 보장합니다.
- OpenLaszlo의 직계 후손으로, 100회 이상의 비교 테스트에서 AI가 작성한 Declare 앱이 React 앱보다 짧고 더 많은 검증을 통과했습니다.

> [!tip] 왜 중요한가
> AI가 코드 작성을 자동화하는 현재 상황에서, 언어의 역할은 더욱 중요해지며, 컴파일러가 검증할 수 있는 간결하고 읽기 쉬운 언어 설계가 신뢰할 수 있는 개발의 핵심이 됩니다.
