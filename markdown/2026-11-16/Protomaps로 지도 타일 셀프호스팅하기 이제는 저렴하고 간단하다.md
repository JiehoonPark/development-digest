## 핵심 개념

> [!abstract]
> 상업용 지도 API는 트래픽이 늘면 비용이 급증하는데, Protomaps의 PMTiles 포맷을 이용하면 HTTP Range 요청만으로 단일 파일 지도 타일을 CDN에서 직접 서빙할 수 있습니다. Bunny.net을 이용해 139GB 세계 지도를 복제 저장해도 월 약 $5의 스토리지 비용으로 운영 가능하며, 트래픽 비용도 Mapbox 대비 크게 절감됩니다. rclone을 이용한 업로드 방법과 풀 존 보안·속도 제한 설정, MapLibre GL 임베드 방법까지 실전 가이드를 다룹니다.

## 아티클

# Protomaps로 지도 타일을 직접 호스팅하기: 저렴하고 간단해진 셀프호스팅 지도 서비스

상업용 지도 API는 트래픽이 급증하는 순간 비용 폭탄으로 돌아옵니다. Mapbox의 경우 무료 티어를 소진하면 지도 로드 1,000회당 $5를 부과하는데, 비상업 프로젝트 입장에서는 부담스러운 가격입니다. 저자는 여행 계획용 지도 프로젝트 Mapboard를 개발하던 중 Protomaps라는 오픈 생태계를 발견했고, 이를 활용해 CDN에 지도 타일을 직접 올려 운영하는 방법을 정리했습니다.

## PMTiles란 무엇인가

Protomaps 생태계의 핵심인 PMTiles는 단일 파일로 배포되는 타일 포맷입니다. 전통적인 x/y/z 경로 기반 타일 서버 대신, HTTP Range 요청을 통해 파일의 특정 부분만 읽어오는 방식으로 동작합니다. 덕분에 서버 로직 없이도 매우 이식성 있고 배포가 간단합니다.

큰 파일의 Range 요청 캐싱을 지원하는 CDN이라면 파일을 다운로드해서 스토리지에 업로드하는 것 외에 별도 작업이 필요 없습니다. Cloudflare처럼 이를 지원하지 않는 CDN을 쓰는 경우에는 엣지 함수를 통해 전통적인 x/y/z URL 경로를 Range 요청으로 변환해주면 됩니다.

## 지도 데이터 구하기

세계 전체 지도만 필요하다면 빌드 페이지에서 최신 데일리 빌드를 다운로드하는 것으로 충분합니다. 하지만 CLI를 사용하면 특정 바운딩 박스나 줌 레벨만 추출해 훨씬 작은 파일을 만들 수 있어 실용적입니다.

## Bunny.net에 배포하기

이 포맷을 배포하기 좋은 CDN으로 Bunny.net을 꼽습니다. HTTP Range 요청을 지원하고, 기본적으로 개인 정보를 수집하지 않으며(IP 주소의 마지막 옥텟을 제거하는 방식), EU에 본사를 두고 있고, 전 세계 CDN/엣지 스토리지 네트워크를 저렴하게 제공한다는 점이 장점입니다.

가격은 리전과 엣지 스토리지 복제 계수에 따라 달라지는데, 대체로 유럽·북미 대역폭 기준 GB당 $0.01(작은 Volume 네트워크는 GB당 $0.005), 스토리지는 월 GB당 $0.01(복제 없음)에서 $0.055(최대 복제)까지입니다. 복제 수준이 높을수록 캐시 미스 발생 시 지연 시간이 줄어드는데, 데이터가 CDN PoP에 캐시될 때 더 넓게 복제되기 때문입니다.

실제 비용으로 환산하면, 139GB 규모의 세계 지도를 대부분의 대륙에 복제(5배)해서 저장할 경우 스토리지 비용은 월 약 $5입니다. 노트북에서 유럽 지도를 로드하고 특정 도시로 줌인할 때 전송되는 데이터량은 약 5MB로, 비용은 $0.00005 수준입니다. 이후 탐색이나 리로드는 로컬에 캐시된 데이터가 늘어나면서 더 저렴해집니다. 지도 로드 1,000회당 $0.05 수준이라면 Mapbox 대비 100배 저렴할 수 있습니다. 다만 실제 대역폭 사용량은 사용자마다 크게 다릅니다(바로 이탈하는 사용자는 적게, 헤비 유저는 수십 MB까지 소모). 참고로 Mapbox는 방문당 정액 요금을 부과하는 방식입니다.

### 파일 업로드하기

HTTP API로 업로드하면 15분 만에 타임아웃이 발생했기 때문에, S3 호환성을 활성화한 스토리지 존을 만드는 편이 좋습니다. rclone을 설치한 뒤 Bunny 스토리지 존으로 파일을 다운로드하면서 바로 스트리밍할 수 있습니다. 인터넷 연결이 불안정하다면 tmux나 임시 VPS에서 실행하는 것을 권장합니다.

```
rclone config create bunnycdn s3 \
provider=Other \
access_key_id="<zone-name>" \
secret_access_key="<storage-key>" \
endpoint="https://<primary-region>-s3.storage.bunnycdn.com"
```

```
rclone copyurl "<build-url>" "bunnycdn:<zone-name>/<filename>.pmtiles" \
--s3-chunk-size 256M \
--progress
```

### 풀 존(Pull Zone) 설정하기

이론적으로는 풀 존을 만들고 스토리지 존을 오리진으로 지정하면 끝이지만, 실제로는 몇 가지 설정을 추가로 조정하는 것이 좋습니다.

- **CORS 설정**: Security > General > Allowed referrers에서 허용할 CORS 출처를 지정해, 다른 웹사이트가 내 타일을 무단으로 임베드하지 못하게 막을 수 있습니다.
- **Range 요청 캐싱**: Caching 설정에서 "Optimize for large object delivery"가 활성화되어 있는지 확인해야 합니다. 이 옵션이 Range 요청 캐싱을 가능하게 합니다.
- **다운로드 제한**: 누군가 전체 파일을 통째로 다운로드해서 CDN 요금 폭탄을 안기는 것을 막기 위해, "Download speed limits"와 "Limit after" 설정을 이용해 단일 요청에서 10MB 이상 전송된 이후 다운로드 속도를 10kB/s로 제한하는 방법이 실용적입니다. 일반적인 사용 패턴에서는 이 한도에 도달할 일이 거의 없습니다. 추가로 초당 요청 수 제한(정상적인 사용에서도 빠르게 높은 숫자에 도달할 수 있으니 주의)이나 풀 존의 월간 대역폭 한도를 설정하는 것도 고려할 만합니다.

## 지도 임베드하기

타일 배포가 끝나면 남은 작업은 MapLibre GL 같은 라이브러리로 웹사이트에 지도를 임베드하는 것뿐입니다. pmtiles npm 패키지를 설치하고, 공식 설치 가이드에 따라 MapLibre에 프로토콜과 스타일을 추가하면 됩니다.

이렇게 하면 비용 효율적이면서도 고가용성을 갖춘 나만의 세계 지도를 직접 호스팅할 수 있습니다.

## 정리

- **PMTiles**는 HTTP Range 요청 기반으로 동작하는 단일 파일 타일 포맷으로, 별도 타일 서버 없이 스토리지 버킷에 올리는 것만으로 배포가 끝납니다.
- Bunny.net 같은 Range 요청 지원 CDN을 활용하면 139GB 세계 지도를 5배 복제해도 월 약 $5의 스토리지 비용으로 운영할 수 있고, 트래픽 비용도 Mapbox 대비 수십~수백 배 저렴할 수 있습니다.
- 업로드는 HTTP API 타임아웃 문제 때문에 S3 호환 모드와 rclone을 사용하는 것이 안정적입니다.
- 풀 존에서 CORS 제한, Range 요청 캐싱 최적화, 다운로드 속도 제한 설정을 해두면 무단 사용이나 과도한 트래픽 비용을 예방할 수 있습니다.
- 최종적으로 MapLibre GL과 pmtiles npm 패키지만 설치하면 프런트엔드에 손쉽게 지도를 임베드할 수 있어, 트래픽이 많은 비상업 프로젝트에서도 지도 기능을 부담 없이 제공할 수 있습니다.
