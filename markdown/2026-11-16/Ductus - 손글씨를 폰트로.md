## 핵심 개념

> [!abstract]
> 손글씨를 디지털 폰트로 변환하는 도구. 사용자의 손글씨를 입력하여 개인화된 폰트를 만들 수 있으며, 모든 처리는 로컬에서 이루어지므로 데이터 업로드 없이 사용 가능합니다.

## 상세 내용

- 손글씨를 드래그 앤 드롭으로 업로드하여 폰트 생성
- 로컬 처리로 데이터 업로드 없이 개인정보 보호
- 사용자의 고유한 필기체 폰트를 생성할 수 있음

> [!tip] 왜 중요한가
> 웹 기술을 활용한 창의적인 폰트 생성 도구로, 사용자 개인화와 클라이언트 사이드 처리의 좋은 예시입니다.
