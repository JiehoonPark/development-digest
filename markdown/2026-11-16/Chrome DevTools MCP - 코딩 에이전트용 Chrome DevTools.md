## 핵심 개념

> [!abstract]
> Chrome DevTools를 코딩 에이전트에서 사용할 수 있도록 구현한 프로젝트. AI 에이전트가 Chrome DevTools의 기능을 활용하여 디버깅 및 개발 작업을 수행할 수 있게 합니다.

## 상세 내용

- Chrome DevTools 기능을 MCP(Model Context Protocol)를 통해 AI 에이전트에 통합
- 코딩 에이전트가 브라우저 디버깅 및 개발 도구에 직접 접근 가능

> [!tip] 왜 중요한가
> AI 코딩 에이전트의 개발 효율을 높이기 위해 브라우저 개발자 도구의 강력한 기능을 활용할 수 있는 기반을 제공합니다.
