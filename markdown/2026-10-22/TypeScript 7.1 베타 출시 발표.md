## 핵심 개념

> [!abstract]
> TypeScript 7.1 베타 버전이 출시되었습니다. 주요 기능으로 Ambient Modules에서 Import Attributes를 지원합니다.

## 상세 내용

- Ambient Modules에서 Import Attributes 지원으로 import 문에 메타데이터를 첨부할 수 있음

> [!tip] 왜 중요한가
> TypeScript의 새로운 기능을 통해 모듈 import 시 더 풍부한 메타데이터 처리가 가능해집니다.
