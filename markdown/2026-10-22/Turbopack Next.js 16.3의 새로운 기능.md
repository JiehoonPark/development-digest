## 핵심 개념

> [!abstract]
> Next.js 16.3에서 Turbopack이 개발 메모리 eviction, 지속적 파일 캐시, 실험적 Rust React Compiler, import.meta.glob 지원을 추가했습니다.

## 상세 내용

- 개발 중 메모리 효율성을 위한 eviction 메커니즘 추가
- 빌드 성능 개선을 위한 persistent file cache 구현
- import.meta.glob 지원으로 동적 import 기능 강화

> [!tip] 왜 중요한가
> Next.js 개발자는 더 빠른 빌드 속도와 효율적인 메모리 관리를 통해 개발 생산성을 향상시킬 수 있습니다.
