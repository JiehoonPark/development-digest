## 핵심 개념

> [!abstract]
> Turbopack의 청킹 기능은 페이지 로드를 가속화하고 페이지 간 코드 공유를 가능하게 합니다. Next.js 16.3에서 청킹 개선을 위한 새로운 실험적 기능이 추가되었습니다.

## 상세 내용

- 페이지 로드 성능 향상을 위한 효율적인 코드 청킹
- 여러 페이지에서 코드를 공유할 수 있는 구조

> [!tip] 왜 중요한가
> 개선된 청킹은 사용자의 페이지 로드 속도를 단축하고 번들 크기를 최적화합니다.
