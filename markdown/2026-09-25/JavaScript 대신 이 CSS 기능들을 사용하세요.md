## 핵심 개념

> [!abstract]
> JavaScript로 구현하던 UI 효과들을 CSS만으로 구현할 수 있는 최신 CSS 기능들을 소개합니다.

## 상세 내용

- CSS만으로 JavaScript 없이 동적 효과를 만들 수 있는 방법 제시
- 성능 향상과 코드 단순화를 위해 CSS 우선 접근 권장

> [!tip] 왜 중요한가
> 불필요한 JavaScript 의존성을 줄여 페이지 로드 속도와 유지보수성을 개선할 수 있습니다.
