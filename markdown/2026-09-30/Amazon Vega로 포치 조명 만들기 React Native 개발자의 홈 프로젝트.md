## 핵심 개념

> [!abstract]
> Jack Herrington이 3D 프린터로 만든 행성 모형 조명을 대형 프로젝션 스크린과 연동하기 위해 Amazon의 Fire TV 플랫폼 Vega를 사용한 경험을 소개합니다. Vega가 React Native 기반이라는 점 덕분에 VS Code 확장, 로컬 시뮬레이터, CLI 도구를 활용해 빠르게 개발할 수 있었고, WLED 컨트롤러를 fetch로 제어하고 aria 레이블만으로 음성 제어까지 구현했습니다. React/React Native 지식을 그대로 활용해 TV용 앱을 손쉽게 만들 수 있음을 보여주는 개인 프로젝트 사례입니다.

## 아티클

천체 관측을 좋아하는 가족을 위해 3D 프린터로 행성 모형을 만들고 포치 뒤편에 LED로 조명을 넣어 꾸민 개인 프로젝트를 소개하는 영상입니다. 영화를 볼 때 이 조명 장식과 대형 프로젝션 스크린을 연결하고 싶었던 저자가 어떤 기술로 이를 구현했는지, 그리고 그 과정이 왜 예상보다 훨씬 쉬웠는지를 짧게 정리해봅니다.

## 프로젝트의 시작: 행성 조명과 스크린을 연결하기

저자의 가족은 천체 관측에 관심이 많아서, 3D 프린터로 출력한 행성 모형들을 포치 뒤쪽에 나란히 배치하고 제어 가능한 LED로 조명을 넣었습니다. 영화를 볼 때 분위기를 살려주는 요소였는데, 여기서 한 걸음 더 나가 이 행성 조명들을 대형 프로젝션 스크린과 연동시키고 싶었습니다. 즉, 스크린에서 특정 행성을 선택하면 실제 조명도 반응하는 식의 인터랙티브한 경험을 만들고자 한 것입니다.

## 왜 Amazon Vega를 선택했나

이 문제를 해결하기 위해 저자는 Amazon Fire Stick과 Vega를 선택했습니다. 결정적인 이유는 Vega가 UI 구현에 React Native를 사용한다는 점이었는데요. 이미 React와 React Native에 익숙한 개발자였기 때문에 진입 장벽이 낮았고, 실제로 작업해보니 예상보다 훨씬 쉬웠다고 밝히고 있습니다.

개발 편의성 면에서도 여러 장점이 있었습니다.

- VS Code용 Vega 확장 프로그램이 제공되어 개발 환경 구성이 간단했습니다.
- 로컬 시뮬레이터가 내장되어 있어 디바이스 없이도 코드를 디버깅하기 쉬웠습니다.
- CLI 앱을 통해 프로젝트를 빠르게 시작할 수 있었습니다.
- React Native 기반이라 AI 코딩 에이전트들이 관련 코드를 잘 이해했고, Vega 공식 문서를 참고 자료로 넘겨주는 것만으로 세부 구현을 처리할 수 있었습니다.

## 실제 구현: 태양계 지도와 LED 제어

결과적으로 완성된 애플리케이션은 손님이 집에 방문했을 때, 태양계 지도를 화면에 띄우고 각 행성에 대한 정보를 보여주는 형태로 동작합니다. 리모컨의 D-패드를 이용해 지도 위에서 행성들과 조명 사이를 자유롭게 이동하며 탐색할 수 있습니다.

실제 LED 제어는 WLED 컨트롤러를 통해 이뤄집니다. Vega 앱에서 일반적인 `fetch`를 사용해 HTTP 요청을 WLED 컨트롤러에 직접 보내는 방식으로, 별도의 복잡한 통신 계층 없이 간단하게 하드웨어를 제어할 수 있었습니다.

## 마지막 완성도: 음성 인식으로 행성 호출하기

프로젝트를 한층 더 완성도 있게 만들기 위해 저자는 음성으로 행성 이름을 말하면 화면과 조명에 해당 행성이 표시되는 기능을 추가했습니다. 놀랍게도 이 기능은 각 요소에 aria 레이블만 추가하면 되는 수준이었는데요. Vega가 음성 인식 처리를 전부 알아서 담당하고, 사용자가 행성 이름(예: "Saturn")을 말하면 해당 레이블에 대한 press 이벤트를 자동으로 전달해주는 구조였습니다. 별도의 음성 인식 로직을 작성할 필요 없이 접근성을 위한 표준 속성만으로 음성 제어 기능을 구현할 수 있었다는 점이 인상적입니다.

## 정리

이 프로젝트는 React/React Native에 익숙한 프론트엔드 개발자가 IoT·스마트홈 성격의 개인 프로젝트를 얼마나 빠르게 구현할 수 있는지를 잘 보여주는 사례입니다.

- Amazon Vega는 Fire TV 계열 기기의 UI를 React Native로 구축하도록 지원하며, 기존 React/React Native 지식을 그대로 활용할 수 있습니다.
- VS Code 확장과 로컬 시뮬레이터, CLI 스캐폴딩 도구 덕분에 개발 환경 구성과 디버깅이 수월했습니다.
- React Native 기반이라는 특성 덕분에 AI 코딩 에이전트의 도움을 받기도 쉬웠고, 공식 문서만 참고 자료로 제공하면 세부 구현을 맡길 수 있었습니다.
- 하드웨어 제어는 표준 `fetch`를 이용한 HTTP 요청만으로 충분했고, 음성 제어는 aria 레이블 추가만으로 별도 구현 없이 지원되었습니다.
- React Native 경험이 있는 개발자라면 Vega를 통해 큰 화면(TV, 프로젝션 스크린) 기반의 애플리케이션을 손쉽게 만들어볼 수 있습니다.
