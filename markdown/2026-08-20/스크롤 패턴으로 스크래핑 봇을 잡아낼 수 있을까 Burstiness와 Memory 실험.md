## 핵심 개념

> [!abstract]
> 이 글은 사람이 스크롤 휠을 사용할 때 보이는 불규칙한 리듬을 Burstiness(B)와 Memory(M)라는 통계 지표로 정량화해, AI 브라우징 에이전트와 사람을 구분할 수 있는지 실험한 연구를 다룹니다. FP-Agent 데이터셋을 활용해 LightGBM 모델을 학습시킨 결과 B, M 단 두 피처만으로 73.4%의 정확도를 얻었으며, 사람과 ChatGPT Agent가 가장 자주 혼동되었습니다. 저자는 스크롤 기반 탐지가 블로그나 위키피디아 같은 정보성 사이트에서 특히 유효하며, 마우스 움직임 등 다른 행동 피처와 결합하면 더 강력한 봇 탐지 모델을 만들 수 있을 것이라 결론짓습니다.

## 아티클

스크래핑 봇을 막기 위한 시도는 대부분 요청 헤더나 트래픽 패턴 분석에 집중되어 있습니다. 하지만 헤드리스 브라우저로 CSS와 JS까지 완벽하게 로드하는 최신 AI 크롤러 앞에서는 이런 접근이 무력해지고 있는데요. 이 글은 사람이 마우스 스크롤 휠을 사용할 때 보이는 독특한 리듬, 즉 "버스티니스(Burstiness)"와 "메모리(Memory)"라는 통계적 지표를 이용해 사람과 봇을 구분할 수 있는지 실험한 연구를 소개합니다.

## Burstiness와 Memory란 무엇인가

이 연구의 출발점은 Kwang-Il Goh와 Albert-László Barabási가 2008년에 발표한 논문 "Burstiness and Memory in Complex Systems"입니다. 이 논문은 이벤트가 발생한 시점만 알고 있을 때, 그 시퀀스의 동역학을 분석할 수 있는 두 가지 계수를 제시합니다. 바로 Burstiness(B)와 Memory(M)입니다.

이 두 값은 문자 메시지를 보내는 패턴, 이메일을 보내는 시점, 심지어 심장 박동 간격까지 다양한 이벤트 기반 시스템에 적용할 수 있습니다. 예를 들어 사람은 문자에 답장을 보낼 때 균일하지 않은, 몰아치는 듯한(bursty) 패턴을 보이는 반면, 단순한 봇은 최대한 빠르게 응답하려는 경향이 있습니다. 이 차이가 바로 B와 M 계수에 그대로 드러납니다.

## 이전 시도의 한계: 헤드리스 브라우저는 사람처럼 보인다

필자는 이전 개인 연구에서 요청이 발생한 시점의 타이밍을 기반으로 B와 M 값을 계산해 사람 세션과 봇 세션을 구분하는 작업을 진행한 적이 있습니다. 이 방식은 어느 정도 효과가 있었지만, 치명적인 한계가 있었습니다. CSS와 JS 파일을 정상적으로 로드하는 브라우저에서 온 요청이라면 무조건 사람으로 분류해버린 것인데요. 이 때문에 ClaudeBot처럼 헤드리스 브라우저를 사용하는 정교한 봇은 손쉽게 사람인 척 위장할 수 있었습니다.

결국 이 방식은 "봇 vs 사람"을 구분한 것이 아니라, "직접 조작해서 만든(crafted) 요청 vs 실제 브라우저에서 보낸 요청"을 구분한 것에 가까웠던 셈입니다. 진짜 사람과 봇을 가르는 더 근본적인 신호가 필요했습니다.

## 스크롤 휠에 주목하다

필자는 최근 봇이 쉽게 흉내 낼 수 없다고 생각되는 인간 고유의 행동 패턴을 하나 발견했습니다. 바로 스크롤입니다. 사람이 스크롤 휠로 페이지를 훑으며 정보를 찾을 때는 원하는 것을 찾을 때까지 아래로 일정하게(linear) 내려가지 않고, 몰아쳤다 멈췄다를 반복하는 버스티한 패턴을 보입니다. Goh & Barabási 논문의 Figure 1에 등장하는 여러 시계열 패턴 중, 사람의 스크롤은 균일한 패턴 c보다는 불규칙한 패턴 a나 e에 훨씬 가깝다는 것이 필자의 관찰입니다.

대부분의 스크래핑 봇 개발자는 아직 이 스크롤 패턴까지 정교하게 다듬지 않았을 것이라는 가설 아래, 필자는 스크롤 이벤트의 발생 간격(inter-event time)에서 계산한 Burstiness와 Memory가 머신러닝 모델에서 사람과 봇을 구분하는 예측 변수로 쓰일 수 있는지 검증해보기로 했습니다.

## 실험: FP-Agent 데이터셋을 활용한 검증

이 실험을 위해 필자는 Ethan Wang 등이 발표한 논문 "FP-Agent: Fingerprinting AI Browsing Agents"에서 제공한 데이터셋을 사용했습니다. 이 논문의 저자들은 특별히 제작한 실험용 웹사이트에서 여러 AI 브라우징 에이전트와 사람이 탐색하는 과정을 기록하고, 이를 기반으로 에이전트를 구분하는 머신러닝 모델을 만들었습니다. 해당 모델 자체는 좋은 성능을 보였지만, 필자는 이 모델이 다양한 변수가 존재하는 실제 웹사이트 환경에서는 효과적이지 않을 것이라 판단했습니다. 다만 논문 저자들이 원본 데이터셋을 OSF.io에 공개해둔 덕분에, 이를 다른 방식으로 재분석할 수 있었습니다.

필자는 각 에이전트가 방문한 페이지마다 발생한 JavaScript "scroll" 이벤트를 기준으로 Burstiness와 Memory 값을 계산했습니다(방문 페이지 1개당 B, M 값 각 1개). 결과는 다음과 같았습니다.

- 사람의 분포는 다른 에이전트들과 명확하게 구분되었으며, 상대적으로 높은 Burstiness 계수와 거의 0에 가까운 Memory 값을 보였습니다.
- 유일하게 사람과 유사한 패턴을 보인 에이전트는 ChatGPT Agent였습니다.

이 결과는 고무적이었지만, 이 두 값이 실제로 예측력을 갖는지 확인하기 위해 LightGBM(결정 트리 기반 그래디언트 부스팅) 모델을 학습시켜 각 단일 페이지 상호작용을 분류하도록 했습니다.

## 모델 성능: 73.4%의 정확도

이 모델은 오직 B와 M, 단 두 개의 피처만 사용해 어떤 에이전트가 해당 상호작용을 수행했는지 예측하도록 학습되었습니다. 결과는 73.4%의 정확도로, 피처가 단 2개뿐이라는 점을 감안하면 나쁘지 않은 수치입니다.

예상대로 모델이 가장 많이 혼동한 쌍은 사람과 ChatGPT Agent였습니다. 이는 피처 개수가 너무 적거나, 데이터셋 규모가 작았기 때문으로 보입니다(에이전트당 데이터 포인트가 약 150개 정도로 충분하지 않았습니다). 이 둘을 더 명확하게 구분하려면 추가적인 피처가 필요할 것으로 보입니다.

## 정리

이번 실험을 통해 확인한 핵심 결론은 다음과 같습니다.

- **스크롤 행동은 사람과 봇을 구분하는 유의미한 데이터 포인트다.** 통제된 실험 환경에서 Burstiness와 Memory는 실제로 예측력을 가지고 있음이 확인되었습니다.
- **다만 스크롤이 필요 없는 사이트에서는 이 방법이 통하지 않습니다.** 반대로 블로그나 위키피디아 같은 정보성 사이트는 사용자가 스크롤을 많이 하므로 이 방법을 적용하기에 가장 적합한 대상입니다.
- **73.4%라는 정확도는 실전 배포용으로는 부족한 수준입니다.** 오직 B, M 두 피처만으로 나온 결과이며, 사람과 ChatGPT Agent를 구분하는 데는 한계가 뚜렷했습니다.
- **마우스 움직임이나 타이핑 패턴 등 다른 행동 피처와 결합한다면** 스크래핑 봇으로부터 웹사이트를 보호할 수 있는 보다 일반화된 탐지 모델을 만들 수 있을 것으로 기대됩니다.

필자는 다음 연구 주제로 마우스 움직임 패턴 분석을 예고하며 글을 마무리했습니다. 봇 탐지 기술이 헤더 위조나 트래픽 패턴 분석을 넘어, 이제는 사람의 미세한 행동 리듬 자체를 정량화하는 방향으로 진화하고 있음을 보여주는 흥미로운 사례입니다.
