## 핵심 개념

> [!abstract]
> Turbopack의 청킹 방식이 페이지 로드 속도를 개선하고 페이지 간 코드 공유를 가능하게 하며, Next.js 16.3에서 청킹 개선을 위한 새로운 실험적 기능이 추가되었습니다.

## 상세 내용

- Turbopack의 청킹 최적화로 페이지 로드 성능 향상
- Next.js 16.3의 새로운 실험적 청킹 기능으로 코드 공유 개선

> [!tip] 왜 중요한가
> 효율적인 청킹은 번들 크기 최적화와 초기 로드 시간 단축에 직결됩니다.
