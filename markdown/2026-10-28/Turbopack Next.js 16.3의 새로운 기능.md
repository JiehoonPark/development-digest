## 핵심 개념

> [!abstract]
> Next.js 16.3의 Turbopack은 개발 메모리 제거, 지속적인 파일 캐시, 실험적 Rust React Compiler, import.meta.glob 지원을 추가했습니다.

## 상세 내용

- 개발 환경에서 메모리 효율성을 개선하는 메모리 제거 기능 추가
- 빌드 시 지속적인 파일 캐시와 실험적 Rust React Compiler 지원
- import.meta.glob 지원으로 동적 모듈 임포트 개선

> [!tip] 왜 중요한가
> 개발 성능 향상과 빌드 최적화는 개발 생산성과 배포 효율을 직접 영향합니다.
