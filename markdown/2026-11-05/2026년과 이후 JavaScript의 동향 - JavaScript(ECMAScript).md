## 핵심 개념

> [!abstract]
> 2020년 이후 6년간 ECMAScript는 6번 개정되었으며, Temporal이 Stage 4에 올라 주요 브라우저와 Node.js에서 플래그 없이 사용 가능해졌습니다. AI 코딩 도구의 등장 등으로 코드 작성 방식도 크게 변화했습니다.

## 상세 내용

- Temporal이 9년의 논의 끝에 Stage 4에 도달하여 Chrome, Firefox, Node.js에서 네이티브 지원됨
- 2020년 이후 ECMAScript 명세가 6번 개정되어 언어가 지속적으로 진화 중

> [!tip] 왜 중요한가
> JavaScript 개발자들이 최신 명세 기능을 활용하고 미래 표준 방향을 파악하는 데 필수적인 정보입니다.
