## 핵심 개념

> [!abstract]
> Turbopack의 청킹 기능이 페이지 로드 속도를 높이고 페이지 간 코드 공유를 가능하게 한다. Next.js 16.3에서 청킹 개선을 위한 새로운 실험적 기능을 출시했다.

## 상세 내용

- Turbopack의 청킹 최적화로 페이지 로드 성능 향상
- Next.js 16.3에 청킹 개선 기능 추가

> [!tip] 왜 중요한가
> 번들 최적화는 프로덕션 애플리케이션의 성능에 직결되므로 개발자가 주목해야 할 기술입니다.
