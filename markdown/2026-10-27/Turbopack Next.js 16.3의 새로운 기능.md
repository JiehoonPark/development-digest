## 핵심 개념

> [!abstract]
> Next.js 16.3에서 Turbopack의 개발 메모리 제거, 빌드 영속 파일 캐시, 실험적 Rust React Compiler, `import.meta.glob` 지원 등 여러 기능을 추가했다.

## 상세 내용

- 개발 메모리 제거와 영속 파일 캐시로 빌드 성능 최적화
- 실험적 Rust React Compiler와 `import.meta.glob` 지원 추가

> [!tip] 왜 중요한가
> 빌드 성능과 개발 환경 최적화는 개발 생산성을 크게 향상시킵니다.
