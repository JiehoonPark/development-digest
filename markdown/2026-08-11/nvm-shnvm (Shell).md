## 핵심 개념

> [!abstract]
> Node.js의 여러 버전을 관리하는 POSIX 호환 bash 스크립트입니다. 개발 환경에서 프로젝트별로 다른 Node.js 버전을 쉽게 전환할 수 있습니다.

## 상세 내용

- POSIX 호환 bash 스크립트로 다양한 환경에서 사용 가능
- 여러 활성 Node.js 버전을 동시에 관리하고 빠르게 전환 가능

> [!tip] 왜 중요한가
> 프로젝트마다 필요한 Node.js 버전이 다를 때 버전 관리를 자동화할 수 있어 개발 환경 설정 시간을 단축합니다.
