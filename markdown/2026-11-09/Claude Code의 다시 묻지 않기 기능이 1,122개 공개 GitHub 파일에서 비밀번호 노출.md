## 핵심 개념

> [!abstract]
> Claude Code의 "Don't Ask Again" 기능이 개발자의 승인 없이 민감한 정보를 자동으로 처리하면서 1,122개의 공개 GitHub 파일에 비밀번호 같은 보안 자격증명을 노출시켰다.

## 상세 내용

- AI 코딩 에이전트의 자동 승인 기능이 보안 자격증명을 의도하지 않게 노출
- GitHub에 공개된 파일들에서 대량의 비밀번호와 토큰이 발견됨

> [!tip] 왜 중요한가
> AI 개발 도구 사용 시 자동 실행 기능의 보안 위험성을 인식하고 민감한 정보 처리에 주의가 필요하다.
