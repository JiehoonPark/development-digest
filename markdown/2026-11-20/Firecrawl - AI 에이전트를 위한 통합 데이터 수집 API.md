## 핵심 개념

> [!abstract]
> Firecrawl는 검색, 웹 스크래핑, 550개 이상의 데이터 제공자를 하나의 API로 통합한 지식 인프라입니다. AI 에이전트의 데이터 접근성을 향상시킵니다.

## 상세 내용

- 550개 이상의 데이터 제공자를 단일 API로 통합하여 접근
- AI 에이전트의 지능을 높이기 위한 데이터 인프라 제공

> [!tip] 왜 중요한가
> 개발자가 여러 데이터 소스를 개별적으로 연동하지 않고 하나의 API로 통합 관리할 수 있습니다.
