## 핵심 개념

> [!abstract]
> Node Version Manager(nvm)는 여러 개의 활성화된 Node.js 버전을 관리하는 POSIX 호환 bash 스크립트입니다.

## 상세 내용

- 다중 Node.js 버전 관리 도구
- POSIX 호환 bash 기반으로 widely 사용됨

> [!tip] 왜 중요한가
> Node.js 개발자가 프로젝트별로 다른 Node.js 버전을 쉽게 전환하고 관리할 수 있게 해줍니다.
