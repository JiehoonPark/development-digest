## 핵심 개념

> [!abstract]
> 천문학을 좋아하는 한 개발자가 포치에 설치한 3D 프린팅 행성 모형과 LED 조명을 대형 스크린과 연동하기 위해 Amazon Vega를 사용한 경험을 공유합니다. Vega는 React Native 기반 UI를 사용하는 Fire TV 플랫폼으로, VS Code 확장과 로컬 시뮬레이터, CLI 도구 덕분에 기존 React/React Native 지식만으로도 손쉽게 개발할 수 있었습니다. WLED 컨트롤러 연동은 일반 fetch로 처리했고, aria-label만 추가해도 음성 제어 기능이 자동으로 구현되는 점이 특히 인상적이었습니다.

## 아티클

천문학에 진심인 개발자가 자기 집 포치(porch)를 꾸미면서 겪은 재미있는 사이드 프로젝트 이야기입니다. 3D 프린팅한 행성 모형과 LED 조명, 그리고 대형 스크린을 하나로 묶는 과정에서 Amazon의 새로운 Fire TV 앱 플랫폼인 Vega를 실전에 써본 후기를 담고 있습니다.

## 프로젝트의 시작: 행성과 조명

집안 전체가 천문학을 좋아해서, 3D 프린터로 출력한 태양계 행성 모형들을 포치 뒤편에 쭉 늘어놓고 각각을 제어 가능한 LED로 밝혀두었다고 합니다. 영화를 볼 때 분위기를 살려주는 용도로는 충분했지만, 여기서 한 걸음 더 나아가 이 행성 조명들을 포치에 설치된 대형 프로젝션 스크린과 연동하고 싶었다는 게 이 프로젝트의 출발점입니다.

## 왜 Amazon Vega를 선택했나

여러 옵션을 살펴본 끝에 Fire Stick과 Amazon Vega 조합을 선택했는데, 이유는 간단합니다. Vega의 UI가 React Native 기반이기 때문입니다. React와 React Native에 이미 익숙했던 만큼, 새로운 스킬셋을 익힐 필요 없이 바로 개발에 뛰어들 수 있었습니다.

실제로 써보니 예상보다 훨씬 수월했다고 하는데, 그 이유로 다음 몇 가지를 꼽았습니다.

- **VS Code용 Vega 확장 프로그램**: 로컬 시뮬레이터가 내장되어 있어서 코드를 디버깅하기가 매우 편리했습니다.
- **AI 코딩 에이전트와의 궁합**: React Native는 코딩 에이전트들이 이미 잘 다루는 프레임워크라, Vega 관련 세부 사항만 공식 문서를 참고하도록 안내하면 나머지는 에이전트가 알아서 처리해줬습니다.
- **CLI 도구 제공**: 프로젝트를 처음 세팅할 때 쓸 수 있는 CLI 앱도 별도로 제공됩니다.

## 실제 구현: 태양계 지도와 LED 제어

이렇게 만든 앱은 손님이 놀러 왔을 때 태양계 지도를 화면에 띄우고, 각 행성에 대한 정보를 함께 보여줍니다. 리모컨의 D-패드로 지도를 탐색하면서 조명과 행성 모형 사이를 오갈 수 있습니다.

LED 조명 제어에는 WLED 컨트롤러를 사용했고, Vega 앱에서 일반적인 `fetch`로 HTTP 요청을 바로 보내는 방식으로 연동했습니다. 별도의 복잡한 통신 계층 없이, 웹 개발에서 흔히 쓰는 방식 그대로 하드웨어를 제어할 수 있었던 셈입니다.

## 마무리: 음성 인식으로 완성도 높이기

프로젝트에 화룡점정을 찍기 위해, 사용자가 행성 이름을 말하면 화면과 조명에 해당 행성이 표시되는 기능을 추가하고 싶었습니다. 이 부분이 놀랍도록 간단했는데, 컴포넌트에 `aria-label`만 추가하면 나머지 음성 처리는 Vega가 전부 알아서 해줬다고 합니다. 사용자가 "Saturn"이라고 말하면 Vega가 이를 인식해 해당 요소의 press 이벤트를 발생시켜주는 방식입니다. 접근성을 위한 표준 속성이 곧바로 음성 제어 기능으로 이어진다는 점이 특히 인상적이었던 부분입니다.

## 정리

- **핵심 선택 이유**: Amazon Vega는 UI 레이어가 React Native로 구성되어 있어, 기존 React/React Native 경험을 그대로 활용해 Fire TV용 앱을 만들 수 있습니다.
- **개발 편의성**: VS Code 확장과 로컬 시뮬레이터, 프로젝트 초기화용 CLI 등 개발 도구 체인이 잘 갖춰져 있어 진입 장벽이 낮습니다.
- **AI 코딩 에이전트 친화적**: React Native 기반이라 기존 코딩 에이전트들이 이미 익숙하게 다루며, Vega 고유의 부분만 공식 문서로 보완하면 됩니다.
- **하드웨어 연동은 표준 웹 API로**: WLED 같은 외부 디바이스 제어도 별도 SDK 없이 `fetch`를 통한 HTTP 요청으로 처리할 수 있습니다.
- **접근성 속성의 재발견**: `aria-label`만 추가해도 Vega가 음성 인식과 이벤트 처리를 자동으로 지원해주므로, 접근성 작업이 곧 음성 제어 기능 구현으로 이어집니다.

React나 React Native 경험이 있는 개발자라면, TV 스크린 위에서 동작하는 애플리케이션을 만들어보고 싶을 때 Vega가 꽤 낮은 진입 장벽을 제공한다는 점을 눈여겨볼 만합니다.
