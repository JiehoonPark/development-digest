## 핵심 개념

> [!abstract]
> GitHub이 스택된 풀 리퀘스트 기능을 공개 프리뷰로 제공하고 있습니다.

## 상세 내용

- 여러 PR을 순차적으로 연결하여 큰 변경 사항을 나누어 관리 가능
- 복잡한 리뷰 프로세스 단순화 및 병렬 작업 지원

> [!tip] 왜 중요한가
> 대규모 기능 개발 시 작은 단위의 PR로 나누면서도 의존성을 명확히 관리할 수 있어 코드 리뷰 품질이 향상됩니다.
