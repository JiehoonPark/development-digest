## 핵심 개념

> [!abstract]
> React 2025 버전에 MDX 지원이 추가되는 내용을 다룹니다.

## 상세 내용

- MDX를 통해 Markdown에서 React 컴포넌트 직접 사용 가능
- 컨텐츠와 인터랙티브 요소의 통합이 강화됨

> [!tip] 왜 중요한가
> MDX 통합으로 문서화와 동적 콘텐츠 생성의 경계가 허물어져 개발 효율성이 증가합니다.
