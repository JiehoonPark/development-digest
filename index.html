React Server Components에서 추가로 발견된 서비스 거부(DoS) 및 소스 코드 노출 취약점
via React Blog
🔥오늘의 화제frontend

React 팀이 지난주 공개한 RCE 취약점(React2Shell) 패치를 검증하는 과정에서 DoS 취약점 3건(CVE-2025-55184, CVE-2025-67779, CVE-2026-23864, CVSS 7.5)과 소스 코드 노출 취약점 1건(CVE-2025-55183, CVSS 5.3)이 추가로 발견됐습니다. 영향받는 패키지는 react-server-dom-webpack/parcel/turbopack의 19.0.0~19.2.3 버전이며, 19.0.4/19.1.5/19.2.4로 수정되었습니다. 이전에 19.0.3/19.1.4/19.2.3으로 업데이트했더라도 패치가 불완전했으므로 재업데이트가 필요합니다.

💡
React Server Components를 사용하는 프레임워크(Next.js 등)를 프로덕션에 배포한 팀이라면 서버가 다운되거나 시크릿이 유출될 수 있는 실질적 위험에 노출되어 있으므로, 정확한 영향 범위와 올바른 버전으로의 즉각적인 업그레이드 여부를 확인해야 한다.

CSS Zen Garden의 꿈, 드디어 프로덕션에서 실현되다
via Hacker News (Top)
frontend

필자는 Mozilla, Lincoln Loop와 함께 Firefox.com을 프리프로세서 없이 순수 모던 CSS만으로 리빌드했습니다. Custom Properties, Grid, Flexbox 등 CSS 명세가 성숙해지면서 2008년 CSS Zen Garden이 그렸던 '디자인과 콘텐츠의 완전한 분리'라는 이상이 마침내 실전에서 구현 가능해졌다는 이야기입니다. 70개 이상의 컴포넌트와 25개 템플릿으로 구성된 디자인 시스템을 Wagtail 컴포넌트로 구현해 19개 로케일을 지원하며, 유일한 빌드 도구인 PostCSS는 성능을 위한 @import 인라인화에만 사용됩니다.

💡
프리프로세서와 각종 CSS 편법에 익숙한 프론트엔드 개발자라면, 모던 CSS 명세만으로 대규모 다국어 사이트와 디자인 시스템을 실제로 구축할 수 있다는 실전 사례를 통해 자신의 스택을 재점검할 계기를 얻을 수 있습니다.

왜 당신의 AI는 형편없는 코드를 만들어낼까 - agents.md 제대로 설정하는 법
via Web Dev Simplified
▶영상frontendai

AI 코딩 에이전트에 프롬프트를 보낼 때는 시스템 프롬프트, agents.md, skill 파일 등이 함께 컨텍스트로 전달되는데, 이 중 매 요청마다 전체가 전송되는 agents.md가 비대해질수록 AI 성능이 떨어집니다. Codex, Airflow, VS Code의 agents.md 파일을 분석해보면 문제가 생길 때마다 항목을 계속 추가해 파일이 비대해졌고(Airflow는 8,600토큰), 이는 필요 없는 정보까지 매번 전송하며 토큰과 성능을 낭비하는 결과를 낳습니다. 해결책은 agents.md를 슬림하게 유지하고 CSS, API, React 등 영역별 상세 내용을 별도 문서로 분리해 참조 링크만 남기는 것입니다.

💡
agents.md 설정 방식은 AI 코딩 어시스턴트의 출력 품질과 토큰 효율에 직접적인 영향을 미치므로, 프론트엔드 개발자가 AI 도구를 팀 단위로 도입할 때 반드시 점검해야 할 실무 포인트입니다.

개발자들이 매번 검색해보는 CSS 문법 1위는? Front-end Family Feud로 알아본 결과
via Kevin Powell (CSS)
▶영상frontend

Kevin Powell 채널에서 개발자 100명을 대상으로 '항상 문법을 찾아봐야 하는 CSS 속성'을 설문한 결과를 Family Feud 형식으로 공개했습니다. 1위는 grid, 2위는 의외로 그라디언트였으며, 상대 색상 문법·margin/padding 쇼트핸드·transform/translate는 예상과 달리 상위권에 들지 못했습니다. 반면 background 쇼트핸드와 box-shadow는 진행자조차 예상 못한 강세를 보였는데, 공통점은 여러 값을 정해진 순서로 나열해야 하는 문법이라는 점입니다.

💡
