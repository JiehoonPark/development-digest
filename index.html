CSS로 형제 요소 세기: sibling-index()와 sibling-count() 활용법
via Kevin Powell (CSS)
▶영상frontend

CSS에 새로 추가된 sibling-index()와 sibling-count() 함수를 활용해 스태거 애니메이션과 z-index 관리 문제를 순수 CSS만으로 해결하는 방법을 다룹니다. 기존에는 :nth-child() 반복, HTML에 변수 수동 삽입, JavaScript 순회 같은 번거로운 방식이 필요했지만 이제는 간단한 calc() 계산식으로 대체할 수 있습니다. Firefox가 최근 지원을 추가하면서 모든 주요 브라우저에서 사용 가능해졌습니다.

💡
요소 개수가 유동적인 UI에서 스태거 애니메이션이나 z-index 레이어링을 처리할 때 JavaScript나 번거로운 선택자 반복 없이 순수 CSS만으로 유지보수하기 쉬운 코드를 작성할 수 있게 해줍니다.

WebMCP 입문: React로 에이전트가 다룰 수 있는 웹사이트 만들기
via James Q Quick
▶영상frontendai

WebMCP는 웹사이트가 에이전트에게 '이 페이지에서 할 수 있는 작업'을 구조화된 도구로 직접 선언할 수 있게 해주는 신규 스펙입니다. 이 글에서는 커피 쇼핑몰 데모에서 ChatGPT Desktop이 장바구니 도구를 자동으로 인식하고 실행하는 예시를 시작으로, 간단한 React 인사말 생성기 앱에 document.modelContext.registerTool()을 이용해 직접 WebMCP 도구를 등록하는 과정을 단계별로 다룹니다. 타입 설정부터 inputSchema 정의, execute 함수와 React 상태 연동, readOnlyHint 어노테이션까지 실제 코드로 살펴봅니다.

💡
프론트엔드 개발자가 직접 자신의 웹 애플리케이션에 에이전트 친화적인 인터페이스를 설계할 수 있게 되면서, 향후 AI 에이전트와의 상호작용을 고려한 UI/API 설계가 새로운 개발 역량으로 요구될 수 있습니다.

via Theo (t3.gg)
▶영상frontend

OpenAI와 Anthropic에서 사전학습 연구를 해온 제이콥 콕슨이 '두 회사 모두 책임감 있게 행동하지 않는다'며 Anthropic을 사임했습니다. 그는 두 회사가 자기 개선형 초지능을 향해 질주하며 인류의 생명을 걸고 도박하고 있다고 경고했습니다. 이미 GPT 5.6 Luna가 다른 모델(Sol)에 의해 학습되는 등 모델이 모델을 만드는 시대가 시작됐고, 이는 정렬과 모니터링 가능성 상실이라는 심각한 문제로 이어질 수 있습니다.

💡
