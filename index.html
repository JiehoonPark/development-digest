via Hacker News (Top)
💡알면 좋은 정보frontendgeneral

마케도니아 URL 단축 서비스 0.mk가 2009~2014년 생성된 65만여 개 링크의 옛 데이터베이스 백업을 발견하고, 2026년 8월 모든 목적지를 재크롤링한 결과를 공개했습니다. 크롤링 가능한 링크의 76.7%가 더 이상 페이지를 로딩하지 못했고, 중복을 제거한 고유 URL 기준으로는 로딩 성공률이 21.3%까지 떨어졌습니다. YouTube·Wikipedia 등 대형 플랫폼은 살아남았지만 개인 블로그, 포럼, 지역 뉴스, 사진 호스팅 서비스는 대부분 사라졌으며, 첫 링크·localhost 링크·17년째 살아있는 google.com 단축링크 같은 흥미로운 기록도 함께 소개합니다.

💡
외부 CDN 직링크나 타 서비스 단축 URL에 의존하는 것이 장기적으로 얼마나 취약한지, 그리고 'HTTP 응답 성공'과 '콘텐츠 실제 보존'은 다른 문제라는 점을 실증 데이터로 보여주기 때문에 링크 설계·아카이빙 전략을 고민하는 프론트엔드 개발자에게 실질적인 참고가 됩니다.

via Jack Herrington
▶영상frontend

천문학을 좋아하는 가족을 위해 포치에 설치한 3D 프린팅 행성 LED 조명을, Amazon Fire Stick의 Vega 플랫폼으로 만든 React Native 앱과 연동한 개인 프로젝트 소개입니다. VS Code 확장, 로컬 시뮬레이터, CLI 스캐폴딩 도구를 활용해 손쉽게 개발했고, WLED 컨트롤러 제어는 일반 fetch로, 음성 인식은 aria-label 추가만으로 구현했습니다. React/React Native 경험자라면 낮은 진입장벽으로 TV 앱을 만들 수 있다는 점을 강조합니다.

💡
React/React Native 지식만으로 TV 및 스마트홈 연동 애플리케이션까지 확장할 수 있음을 보여주는 사례로, 프론트엔드 개발자의 스킬셋 활용 범위를 넓혀준다.
