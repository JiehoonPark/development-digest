React Server Components 치명적 보안 취약점(CVE-2025-55182) 긴급 패치 안내
via React Blog
frontend

React Server Components의 페이로드 디코딩 결함으로 인해 인증 없이 원격 코드 실행이 가능한 CVSS 10.0 취약점(CVE-2025-55182)이 발견되었습니다. react-server-dom-webpack/parcel/turbopack 19.0~19.2.0 버전이 영향을 받으며 19.0.1/19.1.2/19.2.1로 패치되었습니다. Next.js, React Router, Waku, Redwood SDK 등 RSC를 지원하는 주요 프레임워크도 연쇄적으로 영향을 받아 즉시 업그레이드가 필요합니다. 이후 DoS 및 소스 코드 노출 취약점도 추가로 발견되어 같은 패치 라인에 반영되었습니다.

💡
RSC 기반 프레임워크(Next.js 등)를 운영 중인 서비스라면 원격 코드 실행으로 서버가 완전히 탈취될 수 있는 최고 등급 취약점이므로, 사용 여부와 무관하게 즉시 버전을 점검하고 패치해야 합니다.

Node가 이겼다: Deno의 창시자가 만든 두 번째 런타임, 결국 Cloudflare에 흡수되다
via Fireship
▶영상backend

Node.js 창시자 Ryan Dahl이 만든 Deno가 Cloudflare에 인수됐습니다. Node가 fetch, 권한 모델, TypeScript 직접 실행을 흡수하며 Deno의 차별점이 사라졌고, Deno Deploy·KV·Fresh 등 수익화 제품들도 성장이 정체됐습니다. Deno 팀은 결국 Cloudflare Durable Objects를 셀프 호스팅 가능하게 만든 'Celld'를 선보였고, Cloudflare는 이를 통째로 인수해 Workers 런타임에 통합할 계획입니다. Celld 외 나머지 Deno 제품들은 1년 내 개발이 종료되며, Deno Deploy 사용자는 6개월 내 마이그레이션해야 합니다.

💡
Deno Deploy, Deno KV, Fresh 등을 프로덕션에서 쓰고 있는 팀이라면 서비스 종료 일정에 맞춰 마이그레이션 계획을 세워야 하고, 자바스크립트 런타임 생태계의 플랫폼 종속 구조 변화를 이해하는 데도 중요한 사례입니다.
