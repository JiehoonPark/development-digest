via Next.js Blog
frontend

Next.js가 v16.3.8(Active LTS)과 v15.5.27(Maintenance LTS)을 통해 이미지 최적화 SSRF, SSG/ISR 캐시 포이즈닝, 메타데이터 이미지 라우트 정보 노출, use cache/Draft Mode 캐시 누출, 개발 서버 MCP 엔드포인트 노출 등 총 7건의 보안 취약점을 수정했습니다. 셀프 호스팅 환경과 Cache Components, Draft Mode를 사용하는 프로젝트가 특히 영향을 받을 수 있습니다. Vercel 배포 환경은 일부 취약점(캐시 포이즈닝)의 영향을 받지 않습니다.

💡

V8 isolate에서 Firecracker MicroVM으로: Netlify Edge Functions 5배 빨라진 이유
via Hacker News (Top)
frontenddevops

Netlify가 매일 10억 건씩 실행되는 Edge Functions의 인프라를 외부 호스팅 실행 서비스에서 자체 네트워크 내 Firecracker MicroVM 기반으로 전면 재구축했습니다. Unikraft와의 협업으로 웜 인보케이션 지연 시간이 25–40ms에서 5–6ms로 중앙값 기준 약 5배 단축됐고, p99 지연도 47.4% 개선됐습니다. 요청이 엣지 노드에서 스펙으로 변환되어 랑데부 해싱으로 컴퓨트 노드에 라우팅되고, 스냅샷 복원 방식의 MicroVM에서 실행되는 전체 경로를 상세히 다룹니다. 이번 전환은 개발 경험은 그대로 유지하면서 npm 패키지 정식 지원, 연산 한도 완화 등 향후 기능 확장의 발판이 됩니다.

💡
