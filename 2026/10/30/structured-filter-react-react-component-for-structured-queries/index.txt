15:T1ccc,<p>React 애플리케이션에서 &quot;이름이 'A'로 시작하고, 생일이 1990년 1월 1일 이후이며, 카테고리가 가족 또는 친구인&quot; 것과 같은 복잡한 구조화된 검색 조건을 만들어야 할 때가 있습니다. 이런 UI를 직접 구현하려면 필드 타입별 연산자 분기, 값 입력 컴포넌트, 조건 트리 관리까지 손이 많이 가는데요. <code>structured-filter-react</code>는 이 작업을 TypeScript로 작성된 React 컴포넌트 하나로 해결해주는 라이브러리입니다. 기존에 jQuery UI 위젯으로 존재하던 <code>Structured-Filter</code>를 React로 다시 작성한 버전이라고 합니다.</p>
<h3>설치 및 기본 사용법</h3>
<p>설치는 npm으로 간단하게 진행합니다.</p>
<pre><code>npm install structured-filter-react</code></pre>
<p>단, <code>react</code>와 <code>react-dom</code>(18 또는 19 버전)은 peer dependency이기 때문에 프로젝트에 미리 설치되어 있어야 합니다.</p>
<p>사용법은 필터링할 필드 목록을 정의하고 <code>Filter</code> 컴포넌트에 넘겨주는 방식입니다.</p>
<pre><code class="language-jsx">import Filter from &quot;structured-filter-react&quot;;
import &quot;structured-filter-react/dist/index.css&quot;;

const fields = [
  { id: &quot;lastname&quot;, type: &quot;text&quot;, label: &quot;Lastname&quot; },
  { id: &quot;firstname&quot;, type: &quot;text&quot;, label: &quot;Firstname&quot; },
  { id: &quot;active&quot;, type: &quot;boolean&quot;, label: &quot;Is active&quot; },
  { id: &quot;age&quot;, type: &quot;number&quot;, label: &quot;Age&quot; },
  { id: &quot;bday&quot;, type: &quot;date&quot;, label: &quot;Birthday&quot; },
  {
    id: &quot;category&quot;, type: &quot;list&quot;, label: &quot;Category&quot;,
    list: [
      { id: &quot;1&quot;, text: &quot;Family&quot; },
      { id: &quot;2&quot;, text: &quot;Friends&quot; },
      { id: &quot;3&quot;, text: &quot;Business&quot; },
      { id: &quot;4&quot;, text: &quot;Acquaintances&quot; },
      { id: &quot;5&quot;, text: &quot;Other&quot; },
    ],
  },
];

const App = () =&gt; &lt;Filter fields={fields} /&gt;;</code></pre>
<p><code>onChange</code> 콜백을 통해 현재 설정된 조건을 꺼내 쓸 수 있으며, 전체 예제는 데모 페이지에서 확인할 수 있습니다.</p>
<h3>데이터 모델 이해하기</h3>
<h4>필드(Fields)</h4>
<p>각 필드는 반드시 <code>id</code>, <code>type</code>, <code>label</code> 세 가지를 가져야 합니다.</p>
<ul>
<li><code>id</code>: 필드를 구분하는 고유 식별자</li>
<li><code>label</code>: 화면에 표시되는 필드명</li>
<li><code>type</code>: <code>text</code>, <code>number</code>, <code>boolean</code>, <code>date</code>, <code>time</code>, <code>list</code> 중 하나</li>
</ul>
<p><code>list</code> 타입의 필드는 추가로 <code>list</code> 속성을 가져야 하며, 이는 <code>{ id, text }</code> 형태의 옵션 배열입니다.</p>
<h4>조건(Conditions)</h4>
<p>필터의 값(value)은 조건들의 배열이며, 각 조건은 다음과 같은 형태를 가집니다.</p>
<pre><code>{ field: string, operator: string, value: string | string[] | null }</code></pre>
<p>사용 가능한 연산자는 필드의 타입에 따라 달라집니다.</p>
<div class="table-wrapper"><table><thead><tr><th>타입</th><th>연산자</th></tr></thead><tbody><tr><td>text</td><td>equals(eq), not equal(ne), starts with(sw), contains(ct), doesn't contain(nct), finishes with(fw), is empty(null), is not empty(nn)</td></tr><tr><td>number</td><td>=(eq), !=(ne), &gt;(gt), &lt;(lt), is empty(null), is not empty(nn)</td></tr><tr><td>boolean</td><td>equals(eq), is empty(null), is not empty(nn)</td></tr><tr><td>date</td><td>on/not on(eq/ne), after(gt), before(lt), between/not between(bw/nbw), is empty(null), is not empty(nn)</td></tr><tr><td>time</td><td>at/not at(eq/ne), after(gt), before(lt), between/not between(bw/nbw), is empty(null), is not empty(nn)</td></tr><tr><td>list</td><td>any of(in), is empty(null), is not empty(nn)</td></tr></tbody></table></div>
<p>여기서 한 가지 주의할 점이 있습니다. date/time 필드에는 연산자 드롭다운에 between/not between이 노출되지만, 현재 값 편집기는 단일 값만 입력받도록 구현되어 있다는 점입니다. 즉 &quot;~부터 ~까지&quot;를 입력할 두 번째 &quot;to&quot; 입력 필드는 아직 구현되지 않은 상태입니다. between 연산자를 실제로 활용하려면 이 부분이 향후 업데이트에서 추가되기를 기다려야 할 것으로 보입니다.</p>
<h3>Props</h3>
<p><code>&lt;Filter&gt;</code> 컴포넌트가 받는 props는 두 가지입니다.</p>
<div class="table-wrapper"><table><thead><tr><th>Prop</th><th>타입</th><th>필수 여부</th><th>설명</th></tr></thead><tbody><tr><td>fields</td><td>Field[]</td><td>필수</td><td>조건을 구성할 때 사용할 필드 목록</td></tr><tr><td>onChange</td><td>(conditions: Condition[]) =&gt; void</td><td>선택</td><td>조건 목록이 변경될 때마다 호출되는 콜백</td></tr></tbody></table></div>
<p>TypeScript 타입도 컴포넌트와 함께 export되므로, 아래처럼 바로 가져다 쓸 수 있습니다.</p>
<pre><code class="language-ts">import type { Field, FieldType, ListOption, Condition, ConditionValue } from &quot;structured-filter-react&quot;;</code></pre>

<h3>정리</h3>
<p><code>structured-filter-react</code>는 text, number, boolean, date, time, list 등 다양한 타입의 필드에 대해 타입별로 적절한 연산자 세트를 자동으로 제공하는 구조화된 필터 UI 컴포넌트입니다. 필드 정의 배열만 넘겨주면 복잡한 AND 조건의 검색 쿼리 빌더 UI를 손쉽게 구성할 수 있고, <code>onChange</code>로 조건 배열을 받아 백엔드 쿼리로 변환하는 식의 연동이 가능합니다.
