React Server Components 치명적 보안 취약점(CVE-2025-55182, CVSS 10.0) 긴급 패치 안내
via React Blog
🔥오늘의 화제frontend

React Server Components에서 인증 없이 원격 코드 실행이 가능한 치명적 취약점(CVE-2025-55182, CVSS 10.0)이 발견되어 React 팀이 긴급 패치를 배포했습니다. react-server-dom-webpack, react-server-dom-parcel, react-server-dom-turbopack의 19.0~19.2.0 버전이 영향을 받으며, Next.js, React Router, Waku, Redwood SDK 등 주요 프레임워크도 함께 패치가 필요합니다. 이후 서비스 거부(DoS)와 소스 코드 노출 관련 추가 취약점도 발견되어 함께 수정되었습니다.

💡
RSC 기반 애플리케이션을 운영 중인 모든 프론트엔드 개발자는 서버가 원격 코드 실행에 노출될 수 있는 최고 등급 심각도의 보안 사고이므로, 사용 중인 프레임워크와 패키지 버전을 즉시 점검하고 패치해야 합니다.

Next.js 16.4: 모든 앱에 권장되는 Cache Components와 새로운 에이전트 업그레이드 도구
via Next.js Blog
frontend

Next.js 16.4는 'use cache' 기반의 Cache Components를 모든 앱에 권장할 수 있을 만큼 완성도를 높인 릴리스입니다. 정적 렌더링을 보장하는 ensureStatic, 프리페치 범위를 세밀하게 제어하는 navigation()/prefetch() API가 새로 추가되었고, next upgrade --agent 같은 에이전트 기반 업그레이드 도구도 도입되었습니다. create-next-app으로 생성하는 신규 프로젝트는 이제 기본적으로 Cache Components가 활성화됩니다.

💡
App Router의 암묵적 캐싱으로 인한 성능·비용 이슈를 겪어온 팀이라면, Cache Components와 ensureStatic, 프리페치 제어 API를 통해 정적/동적 콘텐츠를 명시적이고 예측 가능하게 다룰 수 있게 되어 실무 적용 가치가 큽니다.

Ultra Fast, 써보니 정말 미쳤다 (좋은 쪽도 나쁜 쪽도)
via Theo (t3.gg)
▶영상frontend

OpenAI의 코드 생성 모드 'Ultra Fast'를 실제로 사용해본 경험을 다룹니다. 실시간으로 코드가 완성되는 몰입감 있는 경험을 제공하지만, 출력 토큰 가격이 100만 개당 50달러에서 300~450달러로 치솟고 월 500달러 플랜도 2시간이면 소진되는 등 비용이 비정상적으로 높습니다. 100줄 미만 PR 리뷰 두 건에 600달러가 청구된 사례, 같은 작업을 표준 모델로 처리했을 때와 40배 이상 차이나는 비용 비교 등 구체적 수치를 통해 Ultra Fast의 가치와 한계를 짚습니다.

💡
