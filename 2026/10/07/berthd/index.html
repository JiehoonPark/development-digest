Berthd

📅 2026-10-07📰 Hacker News (Top)
frontend

터미널 앞에 앉아 Claude Code나 Codex 같은 코딩 에이전트를 돌리다가, 노트북을 덮는 순간 작업이 끊겨버린 경험이 있을 겁니다. Berthd는 바로 이 문제를 해결하기 위해 나온 macOS 앱인데요, 코딩 에이전트를 노트북이 아니라 별도의 개발 서버(dev box)에서 실행시켜, 노트북을 닫아도 에이전트가 계속 작업을 이어가도록 만들어줍니다. Hacker News Top에 오른 이 프로젝트가 어떤 구조와 기능을 제공하는지 정리해봤습니다.

Berthd가 해결하려는 문제

Claude Code나 Codex 같은 에이전트형 코딩 도구는 보통 로컬 머신에서 실행됩니다. 문제는 이런 에이전트들이 장시간 작업(리팩터링, 대규모 코드 생성, 테스트 반복 등)을 수행할 때, 노트북을 닫거나 슬립 모드로 전환하면 프로세스가 같이 멈춰버린다는 점입니다. Berthd는 이 작업 주체를 노트북에서 분리해, 사용자가 지정한 개발 서버(박스)에서 에이전트를 돌립니다. 노트북은 그저 이 에이전트와 상호작용하는 클라이언트 역할만 하고, 실제 작업은 박스에서 계속 진행됩니다. 노트북을 덮었다가 아침에 다시 열어도 에이전트가 밤새 작업한 결과가 그대로 남아있는 구조입니다.

핵심 동작 방식: 워크트리 + 박스 + 에이전트

Berthd의 사용 흐름은 단순합니다. ⌘N을 누르고 원하는 작업을 말하면, 사용자가 선택한 박스 위에 Git 워크트리(worktree)를 하나 만들고, 그 안에서 Claude Code, Codex 혹은 다른 에이전트를 실행합니다. 이때 에이전트의 개발 서버(dev server)는 별도의 탭으로 함께 띄워집니다. 즉 "한 줄 명령 → 워크트리 생성 → 박스 할당 → 에이전트 기동"이 한 번의 흐름으로 처리되는 셈입니다.

실시간으로 지켜보는 작업 과정

에이전트가 수행하는 커맨드 실행과 파일 읽기는 한 줄로 접혀서 표시되고, 코드 수정 사항은 diff 형태로 그대로 보여집니다. Claude가 작업 중 질문을 던지면 그 자리에서 바로 답변할 수 있고, 에이전트가 만들어낸 결과물(아티팩트)은 클릭 한 번으로 바로 확인할 수 있습니다. 즉 에이전트의 진행 상황, 질문, 결과물을 모두 한 화면에서 추적할 수 있는 구조입니다.

두 워크트리를 나란히 비교하기

여러 워크트리를 다룰 때는 탭 그룹(tab groups) 기능을 사용합니다. 두 워크트리는 각각 고유한 색상을 가진 그룹으로 탭 스트립을 공유하며, 하나의 탭으로 합쳐서 볼 수도 있습니다. Compare 기능을 쓰면 두 워크트리를 거울처럼 나란히 배치해, 각각의 채팅, diff, 터미널을 동시에 비교하며 확인할 수 있습니다. 같은 문제를 서로 다른 에이전트나 접근 방식으로 풀어볼 때 유용한 구조입니다.

커스터마이징: 테마와 UI

Berthd는 자체 테마와 함께 Dracula, Rosé Pine 등 19종의 인기 테마를 포팅해 제공합니다. 이 테마는 터미널과 모든 diff 화면에 일관되게 적용됩니다. 채팅 배경도 원하는 대로 설정할 수 있고, ⌘+로 화면을 확대해 볼 수도 있습니다.

설치와 아키텍처

Berthd는 두 부분으로 구성됩니다. 하나는 Mac용 앱(Apple Silicon과 Intel 모두 지원, 서명 및 공증 완료)이고, 다른 하나는 실제 작업이 이뤄지는 각 박스에 설치하는 berthd 데몬입니다. 박스 쪽 설치는 다음 한 줄로 끝납니다.

curl -fsSL https://berthd.app/install | sh

앱과 데몬 모두 오픈소스로 공개되어 있고, Mac 앱은 무료로 다운로드할 수 있습니다.

정리

Berthd는 Claude Code, Codex 같은 코딩 에이전트의 실행 주체를 노트북에서 별도의 개발 서버로 옮겨, 노트북을 닫아도 작업이 끊기지 않도록 만든 macOS 클라이언트입니다. 핵심은 (1) 워크트리-박스-에이전트를 한 번에 기동하는 단순한 워크플로우, (2) 커맨드·diff·질문·아티팩트를 실시간으로 추적하는 뷰, (3) 여러 워크트리를 그룹화하고 나란히 비교하는 Compare 기능, (4) 터미널과 diff까지 일관되게 적용되는 다양한 테마입니다. 설치는 Mac 앱 다운로드와 박스에서의 curl 스크립트 실행 한 줄로 끝나며, 전체가 오픈소스로 공개되어 있습니다. 장시간 돌아가는 에이전트 작업을 노트북 전원 상태와 분리하고 싶은 개발자라면 가볍게 시도해볼 만한 도구입니다.
