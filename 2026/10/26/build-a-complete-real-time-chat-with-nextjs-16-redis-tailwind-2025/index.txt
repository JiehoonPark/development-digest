15:T27b3,<p>Next.js로 실시간 채팅 앱을 처음부터 끝까지 만들어보는 영상 시리즈를 정리합니다. 단순히 &quot;채팅 앱 만들기&quot; 튜토리얼이 아니라, Next.js 16의 최신 라우팅 패턴, Redis를 활용한 TTL 기반 데이터 관리, ElysiaJS라는 타입 세이프 백엔드 프레임워크, 그리고 현업 개발자가 실제로 쓰는 코드 컨벤션까지 함께 다루는 것이 이 프로젝트의 목표입니다. 이번 글에서는 전체 기획 의도와 초기 프로젝트 세팅, 그리고 레이아웃/스타일링을 시작하는 단계까지 정리합니다.</p>
<h3>만들려는 것: 프라이버시 중심의 1:1 실시간 채팅</h3>
<p>이 프로젝트의 핵심 컨셉은 <strong>Signal이나 Telegram처럼 프라이버시에 초점을 맞춘 채팅</strong>입니다. 주요 동작 방식은 다음과 같습니다.</p>
<ul>
<li>사용자는 방을 생성하면 커스텀 React 훅을 통해 자동으로 임의의 사용자명을 부여받습니다.</li>
<li>방 하나당 정확히 2명만 입장할 수 있는 <strong>프라이빗 1:1 채팅</strong>입니다. 이미 두 명이 들어가 있는 방에 제3자가 접근하면 에러가 발생합니다.</li>
<li>메시지는 <strong>실시간</strong>으로 전송됩니다. 한쪽에서 타이핑 후 엔터를 치면 상대방 화면에 즉시 반영됩니다.</li>
<li>방은 생성 후 <strong>10분이 지나면 자동으로 파기</strong>되며, 해당 방에 쌓인 모든 메시지는 데이터베이스에서 완전히 삭제됩니다.</li>
<li>상단의 버튼을 눌러 방을 수동으로 파기할 수도 있으며, 이 경우 메시지 삭제와 모든 유저 강퇴가 즉시 일어납니다.</li>
</ul>
<p>이 과정에서 다루는 기술 스택은 Next.js 16(App Router), Tailwind CSS, 그리고 백엔드로는 표준 Next.js API 라우트 대신 <strong>ElysiaJS</strong>를 사용합니다. ElysiaJS는 타입 세이프하고 빠른 Next.js 백엔드를 작성할 수 있게 해주는 오픈소스 프로젝트로, 미들웨어 작성이나 프론트엔드-백엔드 간 타입 안전한 호출을 표준 API 라우트보다 훨씬 쾌적하게 처리할 수 있다는 점이 특징입니다. 결과물은 Vercel에 바로 배포 가능한 형태로 만들어집니다.</p>
<p>단순히 기능 구현만 보여주는 게 아니라, <code>lib</code> 폴더를 왜 두는지, 상수를 왜 대문자로 쓰는지 같은 실무 컨벤션도 함께 설명하는 것이 이 프로젝트의 차별점입니다.</p>
<h3>프로젝트 초기 세팅</h3>
<p>먼저 원하는 디렉터리로 이동한 뒤, 패키지 매니저로 <code>bun</code>을 사용해 프로젝트를 생성합니다. npm, yarn 등 어떤 패키지 매니저를 쓰든 상관없습니다.</p>
<pre><code class="language-bash">cd desktop
bunx create-next-app@latest</code></pre>
<p>프로젝트 이름은 <code>real-time-chat</code>으로 지정하고, 설치 과정에서 &quot;추천 기본값을 쓸 것인지&quot; 묻는 질문에는 <strong>No</strong>를 선택해 직접 옵션을 커스터마이징합니다. 기본값 중 한 가지(소스 디렉터리 설정)가 마음에 들지 않기 때문입니다. 선택한 옵션은 다음과 같습니다.</p>
<ul>
<li>TypeScript: Yes</li>
<li>ESLint: Yes</li>
<li>React Compiler: Yes</li>
<li>Tailwind: Yes</li>
<li><code>src/</code> 디렉터리 사용: Yes (기본값은 No지만, 코드베이스가 더 깔끔해지므로 Yes로 설정)</li>
<li>App Router: Yes</li>
<li>import alias 커스터마이징: No</li>
</ul>
<p>설치가 끝나면 해당 디렉터리로 이동해 에디터(Cursor 또는 VS Code)로 엽니다.</p>
<pre><code class="language-bash">cd real-time-chat
cursor .</code></pre>
<p>패키지는 생성 시점에 이미 설치되어 있으므로 바로 개발 서버를 띄울 수 있습니다.</p>
<pre><code class="language-bash">bun dev</code></pre>
<p><code>localhost</code>에 접속하면 Next.js 기본 시작 페이지가 뜨는데, 이걸로 프로젝트 셋업이 정상적으로 끝났음을 확인할 수 있습니다.</p>
<h3>폰트 교체: JetBrains Mono 적용</h3>
<p>기본으로 깔리는 Geist 폰트 대신, 모노스페이스 계열의 <strong>JetBrains Mono</strong>를 적용합니다. <code>src/app/layout.tsx</code>에서 기존 Geist Sans/Geist Mono 임포트를 제거하고, <code>next/font/google</code>에서 <code>JetBrains_Mono</code>를 직접 불러옵니다.</p>
<pre><code class="language-tsx">import { JetBrains_Mono } from &quot;next/font/google&quot;;

const jetBrainsMono = JetBrains_Mono({
  variable: &quot;--font-jetbrains-mono&quot;,
  subsets: [&quot;latin&quot;],
});</code></pre>
<p>여기서 <code>variable</code>은 CSS 변수명을 지정하는 컨벤션이고, <code>subsets</code>는 어떤 문자셋을 로드할지 지정하는 옵션입니다. 이렇게 생성한 폰트 객체의 <code>variable</code> 클래스명을 <code>&lt;body&gt;</code>에 적용하면 됩니다(기존 Geist 클래스명 자리에 교체).</p>
<p>다만 이것만으로는 폰트가 바로 적용되지 않는데, <code>globals.css</code>의 <code>body</code> 셀렉터에 지정된 <code>font-family</code>가 여전히 기본값을 가리키고 있기 때문입니다. 이 부분을 레이아웃에서 정의한 CSS 변수(<code>--font-jetbrains-mono</code>)를 참조하도록 수정해야 실제로 폰트가 반영됩니다. 저장 후 브라우저를 새로고침하면 전체 페이지에 모노스페이스 폰트가 적용된 걸 확인할 수 있습니다.</p>
<h3>레이아웃/스타일링 시작하기</h3>
<p>폰트 설정이 끝난 뒤에는 실제 메인 페이지 레이아웃 작업으로 넘어갑니다. 여기서 에디터 생산성을 높이는 두 가지 팁이 소개됩니다.</p>
<ul>
<li><strong>Emmet Balance Outward</strong>: 커서가 위치한 div의 시작부터 끝까지 한 번에 선택할 수 있는 단축키입니다. 영상에서는 <code>Cmd+M</code>으로 바인딩해서 사용합니다. (키보드 설정에서 &quot;Emmet: Balance Outward&quot;를 원하는 키로 매핑하면 됩니다.)</li>
<li><strong>Shift+Alt+O</strong>: 사용하지 않는 import를 제거하고 import 순서를 정리해주는 단축키입니다.</li>
</ul>
<p>이 단축키들을 활용해 기존 Next.js 기본 페이지의 루트 <code>div</code>를 선택한 뒤 <code>main</code> 태그로 교체합니다. <code>main</code> 태그에는 다음과 같은 Tailwind 클래스를 적용합니다.</p>
<pre><code>flex min-h-screen flex-col items-center justify-center p-4</code></pre>
<p><code>min-h-screen</code>은 <code>100vh</code>에 대응하는 유틸리티이고, 세로 방향 flex 정렬로 화면 중앙에 콘텐츠를 배치합니다.</p>
<p>그 안에 로비 폼을 감쌀 컨테이너 <code>div</code>를 하나 추가하고 다음 클래스를 줍니다.</p>
<pre><code>w-full max-w-md space-y-8</code></pre>
<p>그 내부에 실제 &quot;방 만들기&quot; 폼 영역이 들어갈 카드형 <code>div</code>를 배치하는데, 다음과 같이 테두리와 반투명 배경, 블러 효과를 적용합니다.</p>
<pre><code>border border-zinc-800 bg-zinc-900/50 p-6 backdrop-blur-md</code></pre>
<p>여기서 <code>/50</code>은 배경색의 투명도를 지정하는 표기법이고, <code>backdrop-blur-md</code>는 카드 뒤 배경에 블러 효과를 줘서 글래스모피즘 느낌을 냅니다.</p>
<p>이 카드 내부에는 <code>space-y-5</code>와 <code>space-y-2</code> 클래스를 가진 중첩 <code>div</code>로 섹션 간 세로 여백을 정리하고, 임시로 &quot;Create Room&quot; 같은 텍스트를 넣어 레이아웃이 의도대로 잡히는지 확인합니다. 이후 단순 텍스트 대신 실제 <code>label</code> 요소로 교체하면서 <code>flex items-center text-zinc-500</code> 클래스와 &quot;your identity&quot; 같은 안내 문구(사용자가 어떤 이름으로 연결되는지 설명)를 넣는 작업으로 이어집니다.</p>
<p>작업 중간에 Tailwind IntelliSense 확장을 일시적으로 꺼서, 클래스명에 마우스를 올릴 때마다 뜨는 큰 미리보기 팝업이 화면을 가리는 걸 방지하는 팁도 함께 소개됩니다.</p>
<h3>정리</h3>
<ul>
<li>이 프로젝트는 Next.js 16 + Tailwind CSS + Redis + ElysiaJS 조합으로, 방을 만들면 자동으로 사용자명을 부여받고 1:1로만 입장 가능한 실시간 채팅 앱을 만드는 것이 목표입니다. 방은 10분 TTL로 자동 파기되거나 버튼으로 즉시 파기할 수 있으며, 메시지는 실시간으로 동기화됩니다.</li>
<li>프로젝트 생성 시 <code>create-next-app</code>의 추천 기본값을 그대로 쓰지 않고, TypeScript·ESLint·React Compiler·Tailwind는 Yes, <code>src/</code> 디렉터리도 Yes로 직접 커스터마이징하는 것이 실무적으로 더 깔끔한 코드베이스를 만든다는 포인트가 있습니다.</li>
<li><code>next/font/google</code>의 <code>JetBrains_Mono</code>를 CSS 변수로 등록하고 <code>globals.css</code>의 <code>body</code> font-family를 해당 변수로 연결하는 방식으로 전역 폰트를 손쉽게 교체할 수 있습니다.</li>
<li>Emmet Balance Outward(div 전체 선택), Shift+Alt+O(import 정리) 같은 에디터 단축키는 반복적인 마크업 작업 속도를 크게 높여줍니다.</li>
