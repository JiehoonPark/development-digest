React Server Components의 치명적 보안 취약점(CVE-2025-55182), 지금 바로 업그레이드하세요
via React Blog
frontend

React Server Function 엔드포인트의 페이로드 디코딩 과정에서 CVSS 10.0 등급의 인증 없는 원격 코드 실행 취약점(CVE-2025-55182)이 발견되었습니다. react-server-dom-webpack, react-server-dom-parcel, react-server-dom-turbopack의 19.0~19.2.0 버전이 영향을 받으며, Next.js·React Router·Waku 등 RSC를 지원하는 주요 프레임워크도 함께 영향을 받습니다. React 팀은 19.0.1, 19.1.2, 19.2.1로 수정 사항을 배포했으며, 이후 추가 DoS 및 소스 코드 노출 취약점도 발견되어 가이드가 계속 갱신되고 있습니다.

💡
CVSS 10.0은 사실상 최고 위험도로, React Server Components 기반 서비스를 운영 중인 프론트엔드/풀스택 개발자라면 즉시 버전 확인과 업그레이드 조치를 취해야 하는 사안입니다.

미디어 쿼리에서 min-width 대신 범위 문법을 써야 하는 이유
via Kevin Powell (CSS)
▶영상frontend

Bootstrap 코드에서 자주 보이는 767.98px 같은 어색한 숫자는 고해상도 디스플레이와 브라우저 줌으로 인한 구간 간극 문제를 피하기 위한 임시방편이었습니다. 2023년 3월부터 모든 브라우저에 베이스라인으로 자리잡은 CSS 미디어 쿼리 범위 문법을 쓰면 width > 600px, width >= 600px처럼 직관적인 부등호 표기로 min-width/max-width를 대체할 수 있습니다. 범위 지정과 and 조건 결합 방법, 그리고 컨테이너 쿼리에서도 동일하게 쓸 수 있다는 점까지 함께 정리했습니다.

💡
반응형 레이아웃의 기본 도구인 미디어 쿼리를 더 읽기 쉽고 유지보수하기 쉬운 문법으로 작성할 수 있게 되었으며, 이제 브라우저 지원이 충분해져 실무에 바로 도입해도 되는 시점이라는 점에서 프론트엔드 개발자가 알아둘 가치가 있습니다.
