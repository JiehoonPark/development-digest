Cloudflare, TypeScript 컴파일러를 Rust로 포팅하는 'tsrs' 공개
via Hacker News (Top)
🔥오늘의 화제

Cloudflare가 VoidZero, Owner.com의 Max Schwenk와 함께 TypeScript 컴파일러의 Rust 포트인 tsrs를 공개했습니다. TypeScript 7.0 대비 최대 8배 빠르고 메모리 사용량은 약 70% 적으며, TypeScript를 포크하지 않고 TypeScript 팀의 설계 결정을 충실히 따르는 방식으로 개발됩니다. Rust를 택한 이유는 Go와 달리 가비지 컬렉터 부담 없이 WebAssembly 환경에 적합하기 때문이며, 이를 통해 브라우저·엣지·IoT 등 더 많은 곳에서 완전한 개발 환경을 구동할 수 있게 됩니다.

💡
TypeScript 타입 체크 속도와 메모리 효율은 대규모 코드베이스의 개발 경험과 CI 비용에 직결되며, Wasm 친화적인 Rust 포트는 브라우저나 엣지 환경에서도 완전한 TypeScript 개발 환경을 구동할 수 있는 새로운 가능성을 열어줍니다.

React 컴포넌트 상태를 URL로 공유할 때 생기는 버그와 올바른 해법
via Sam Selikoff
▶영상frontend

검색 가능한 테이블을 URL로 공유하기 위해 useEffect로 React state와 URL을 동기화하면 뒤로 가기 버튼이 작동하지 않는 버그가 생깁니다. 원인은 검색어에 대한 source of truth가 React state와 URL 두 곳으로 중복되었기 때문입니다. 해결책은 React state를 완전히 제거하고 useSearchParams로 URL에서 값을 직접 파생시키는 것이며, 이는 URL뿐 아니라 다크모드·온라인 상태·localStorage 등 외부 상태 전반에 적용되는 원칙입니다.

💡
검색, 필터, 탭 같은 공유 가능한 UI 상태를 다룰 때 흔히 겪는 버그의 근본 원인과 React 공식 문서가 권장하는 '중복 state 제거' 원칙을 실제 코드로 체득할 수 있다.
