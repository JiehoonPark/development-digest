Apple Foundation Models framework: 온디바이스부터 Claude·Gemini까지 하나의 Swift API로
via Hacker News (Top)
ai

Apple이 공개한 Foundation Models framework는 온디바이스 Apple Intelligence 모델, Private Cloud Compute, Claude·Gemini 같은 서드파티 서버 모델까지 하나의 Swift API로 통합할 수 있는 프레임워크입니다. 이미지 이해, Dynamic Profiles, Evaluations framework, fm CLI, Python SDK 등 신규 기능이 함께 공개됐습니다. Language Model protocol을 통해 모델 제공자가 자유롭게 패키지를 만들어 생태계에 참여할 수 있다는 점이 특징입니다.

💡
iOS/macOS 앱에 AI 기능을 넣을 때 모델 벤더에 종속되지 않고 온디바이스·클라우드·서드파티 모델을 하나의 API로 유연하게 전환할 수 있는 실무적 선택지를 제공하기 때문입니다.

12칼럼 그리드를 넘어서: 개성 있는 레이아웃 디자인하기
via CSS-Tricks
frontend

12칼럼 그리드는 Blueprint CSS와 960 Grid System을 거쳐 Bootstrap 등으로 이어지며 웹 레이아웃의 사실상 표준이 되었지만, 저자는 이것이 콘텐츠와 브랜드 개성을 고려하기 전에 습관적으로 선택되는 점을 문제로 지적합니다. 가상의 회사 Wheelman을 예로 들어, 콘텐츠의 위계와 관계를 먼저 분석한 뒤 모듈러 그리드와 복합 그리드로 더 독창적이고 브랜드에 맞는 레이아웃을 만드는 과정을 보여줍니다. 칼럼에 행을 더해 만든 모듈을 다양한 크기로 조합하거나, 서로 다른 칼럼 수의 그리드를 겹쳐 복합 그리드를 구성하면 일관성을 유지하면서도 예측 불가능한 디자인을 만들 수 있다고 설명합니다.

💡
프레임워크의 기본 그리드 시스템에 무의식적으로 의존하는 습관에서 벗어나, 콘텐츠와 브랜드 특성에서 출발해 CSS Grid의 유연성을 적극 활용하면 더 차별화되고 기억에 남는 웹 레이아웃을 설계할 수 있습니다.
