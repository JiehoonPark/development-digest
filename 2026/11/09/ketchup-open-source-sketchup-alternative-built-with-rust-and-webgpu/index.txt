18:T1664,<h2>KetchUp: Rust와 WebGPU로 만든 오픈소스 SketchUp 대안</h2>
<p>목공 및 가구 설계자를 위한 무료 오픈소스 3D 모델링 앱 &quot;KetchUp&quot;이 공개됐습니다. SketchUp과 유사한 워크플로우를 지향하면서도 Rust와 WebGPU 기반으로 새롭게 작성된 점이 특징인데요, 웹 브라우저에서 바로 쓸 수 있을 뿐 아니라 Windows, macOS, Linux용 네이티브 앱으로도 배포됩니다.</p>
<h3>무엇을 위한 도구인가</h3>
<p>KetchUp은 선반, 테이블, 캐비닛, 작업대 같은 가구를 실제 작업에 들어가기 전에 정확한 치수로 설계해볼 수 있도록 만든 3D 모델링 앱입니다. 타깃 사용자는 목공 작업자, 가구 제작자, DIY 빌더로, 작업장에 들어가기 전 3D 상에서 프로젝트를 미리 검토해보는 용도에 초점을 맞추고 있습니다.</p>
<p>설치 없이 바로 접근 가능한 브라우저 버전과 함께, 데스크톱 환경을 위한 설치형 배포본도 제공합니다.</p>
<ul>
<li>Windows: x64용 .exe 인스톨러</li>
<li>macOS: Apple Silicon용 .pkg 인스톨러</li>
<li>Linux: x64용 AppImage</li>
</ul>
<p>데스크톱 브라우저와 마우스 사용을 전제로 설계되었으며, 계정 가입이나 클라우드 연동 없이 바로 사용할 수 있습니다.</p>
<h3>모델링 워크플로우</h3>
<p>KetchUp의 기본 모델링 흐름은 SketchUp 사용자에게 익숙한 방식입니다.</p>
<p><strong>형태 그리기</strong>: 선, 사각형, 원, 자유 곡선으로 외곽선을 스케치하고, Push/Pull 도구로 면(face)을 입체(form)로 바꿀 수 있습니다. 이후 이동, 스케일, 오프셋, 페인트 같은 도구로 다듬습니다.</p>
<p><strong>정확한 치수 작업</strong>: 지오메트리와 축에 스냅하고, 정확한 길이를 직접 입력하거나 치수선을 추가할 수 있습니다. 그룹, 컴포넌트, 태그를 활용해 복잡한 모델을 체계적으로 관리합니다.</p>
<p><strong>작업 보존 및 내보내기</strong>: 로컬에 자동 저장되며, 이식 가능한 <code>.ketchup</code> 프로젝트 파일로 다운로드할 수 있습니다. 기존 SketchUp(.skp) 지오메트리를 가져오거나, OBJ 포맷으로 내보내 다른 3D 워크플로우로 연결할 수도 있습니다.</p>
<p>실제 가구 설계 과정에서는 이 세 단계가 다음과 같이 적용됩니다. 먼저 사각형과 선으로 판재 외곽선을 그리고 Push/Pull로 두께를 부여해 부품을 모델링합니다. 다음으로 정확한 길이 입력, 지오메트리·축 스냅, 줄자(Tape Measure)와 치수(Dimensions) 도구로 설계를 검사하고, 어셈블리 주위를 돌려보며(Orbit) 비율을 점검합니다. 마지막으로 그룹과 재사용 가능한 컴포넌트, 태그로 부품을 정리하고 프로젝트를 저장합니다.</p>
<h3>처음 시작하는 법</h3>
<p>튜토리얼은 단 세 단계로 구성됩니다.</p>
<ul>
<li><strong>사각형 그리기</strong>: 한쪽 모서리를 클릭한 뒤 반대쪽 모서리를 클릭해 첫 번째 면을 만듭니다.</li>
<li><strong>깊이 부여하기</strong>: Push/Pull 도구를 선택하고 면을 클릭한 다음 마우스를 움직여 클릭으로 완료합니다.</li>
<li><strong>시점 전환하기</strong>: Orbit 도구로 드래그해 모델을 둘러보고, 스크롤로 확대·축소하며, F 키로 모델에 맞춰 화면을 맞출 수 있습니다.</li>
</ul>
<h3>실행 환경과 저장 방식</h3>
<p>KetchUp을 실행하려면 하드웨어 가속과 WebGPU 또는 WebGL2를 지원하는 데스크톱 브라우저가 필요하며, 마우스와 키보드로 모델링하는 것을 전제로 합니다. 물론 Windows, macOS, Linux용 네이티브 앱으로도 동일하게 실행할 수 있습니다.</p>
<p>작업물은 해당 브라우저·디바이스에 자동 저장되지만, 클라우드 저장소나 계정 시스템은 따로 없습니다. 따라서 브라우저 데이터를 지우면 자동 저장된 작업이 사라질 수 있어, 보존하고 싶은 작업은 File → Save로 <code>.ketchup</code> 프로젝트 파일을 다운로드해야 합니다.</p>
<p>기존 모델 호환성과 관련해서는, File → Import/Export 메뉴를 통해 SketchUp(.skp) 지오메트리를 가져오거나 Wavefront OBJ(.obj)로 내보낼 수 있습니다. 가져오기는 로컬에서 처리되며, SketchUp의 텍스처·씬·일부 모델 기능은 지원되지 않습니다. OBJ 내보내기 역시 지오메트리만 포함하고 재질(materials) 정보는 담기지 않습니다.</p>
<h3>라이선스와 기술 스택</h3>
<p>KetchUp은 MIT 라이선스로 공개된 오픈소스 프로젝트이며 Rust로 작성되었습니다. GitHub를 통해 코드를 확인하거나 기여할 수 있고, 전체 가이드 문서도 함께 제공됩니다.</p>
<h3>정리</h3>
<p>KetchUp은 목공 및 가구 설계라는 명확한 타깃을 두고 만들어진 가벼운 3D 모델링 도구로, SketchUp과 비슷한 스케치-Push/Pull 기반 워크플로우를 Rust와 WebGPU/WebGL2 기반으로 재구현했다는 점이 핵심입니다. 브라우저에서 설치 없이 바로 써볼 수 있고, 데스크톱 앱으로도 배포되며, 계정이나 클라우드 없이 로컬 자동 저장과 <code>.ketchup</code>/<code>OBJ</code> 파일 기반 워크플로우를 지향합니다. 프론트엔드 개발자 입장에서는 WebGPU/WebGL2를 활용한 브라우저 네이티브 3D 모델링 앱이 실제 프로덕션 수준으로 동작하는 사례로서, 오픈소스 코드를 통해 Rust 기반 웹 그래픽스 애플리케이션 아키텍처를 참고해볼 만한 프로젝트입니다.</p>d:[["$","$L17",null,{"crumbs":[{"label":"Dev Digest","icon":"📬","href":"/"},{"label":"2026-11-09","icon":"📅","href":"/2026/11/09/"},{"label":"KetchUp: Rust와 WebGPU로 만든 오픈소스 SketchUp 대안"}]}],["$","div",null,{"className":"PageContainer_container__5iuf3","children":[["$","header",null,{"className":"ArticleDetailView_header__axaMu","children":[["$","h1",null,{"className":"ArticleDetailView_title__f_QTa","children":"KetchUp: Rust와 WebGPU로 만든 오픈소스 SketchUp 대안"}],["$","p",null,{"className":"ArticleDetailView_originalTitle__sUtWS","children":"KetchUp – Open-source SketchUp alternative built with Rust and WebGPU"}],["$","div",null,{"className":"ArticleDetailView_meta__ypIUL","children":[["$","span",null,{"children":["📅 ","2026-11-09"]}],["$","span",null,{"children":["📰 ","Hacker News (Top)"]}],null]}],["$","div",null,{"className":"ArticleDetailView_badges__G8q4T","children":[["$","span","frontend",{"className":"LabelBadge_badge__ZAfPv LabelBadge_frontend__x8P2I","children":"frontend"}]]}]]}],[["$","section",null,{"className":"ArticleDetailView_section__DaSgJ","children":["$","div",null,{"className":"ArticleDetailView_translated__8ZNqk","dangerouslySetInnerHTML":{"__html":"$18"}}]}],"$L19"],"$L1a"]}]]
