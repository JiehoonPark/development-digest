Modern Web Guidance 1.0: 코딩 에이전트에게 부족한 웹 플랫폼 전문성을 채워주다
via Hacker News (Top)
frontend

Chrome이 발표한 Modern Web Guidance 1.0은 코딩 에이전트에 웹 플랫폼 전문 지식과 Baseline 호환성 데이터를 주입하는 스킬 모음으로, 모더나이제이션 워크플로와 확장된 가이드 데이터베이스, 전문가 검토, 공개 평가 대시보드를 새로 추가했습니다. Firefox와 Edge도 합류해 크로스 브라우저 프로젝트로 확장되었으며, Chrome DevTools for agents와 함께 사용하면 사전 지식 제공과 런타임 검증을 결합해 더 나은 코드를 더 빠르게 만들 수 있습니다. Pensionbazaar, Policybazaar, WeTV 등의 실제 도입 사례에서 작업 시간 90% 이상 단축, 디버깅 시간 87% 절감 등의 성과가 보고되었습니다.

💡
AI 코딩 에이전트가 만든 코드의 품질 격차(접근성, 성능, 보안)를 줄여주는 실무 도구이자, 코딩 에이전트 워크플로에 웹 표준 전문성을 체계적으로 통합하는 방법을 보여주기 때문에 프런트엔드 개발자에게 중요합니다.

Node.js 26.13.1(LTS) 보안 릴리스 — HTTP/2·TLS 관련 High 등급 CVE 다수 패치
via Node.js Blog
backend

Node.js 26.13.1 LTS는 HTTP/2, TLS, HTTP 모듈을 중심으로 총 18건의 CVE(High 9건, Medium 7건, Low 2건)를 수정한 보안 릴리스입니다. 특히 TLS 세션 재개·재협상 과정에서 SNI가 변조될 수 있는 취약점과 원격 TLS 서버 크래시 취약점이 포함되어 있어 주의가 필요합니다. llhttp, undici, brotli, sqlite 등 핵심 의존성도 함께 업데이트됐습니다.

💡
HTTP/2와 TLS는 거의 모든 Node.js 서버가 사용하는 핵심 모듈이므로, 이번 다수의 High 등급 보안 패치는 프로덕션 환경의 DoS·인증 우회 리스크를 직접적으로 줄여줍니다.

GitHub Actions 워크플로우, 이제 Lockfile로 잠그세요
via Hacker News (Top)
devops

GitHub Actions가 워크플로우 lockfile 기능을 공식 지원하면서, 보안을 위해 긴 SHA 값으로 action을 고정하던 기존 관행 대신 사람이 읽기 쉬운 태그와 별도의 lockfile을 조합하는 방식이 가능해졌습니다. gh-actions-lock CLI 확장으로 워크플로우를 잠그고, Renovate/Dependabot으로 자동 갱신하며, CI에서 gh actions-lock --verify와 zizmor로 검증하는 전체 흐름을 소개합니다.

💡
CI/CD 파이프라인의 보안과 가독성을 동시에 챙겨야 하는 프론트엔드 개발자에게, SHA 고정 없이도 공급망 공격을 방어하면서 워크플로우 코드를 깔끔하게 유지하는 실질적인 방법을 제시합니다.
