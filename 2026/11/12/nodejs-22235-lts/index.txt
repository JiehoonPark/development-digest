18:T1124,<p>Node.js 22.23.5 LTS('Jod') 버전이 보안 릴리스로 공개됐습니다. 이번 릴리스에는 High 등급 7건을 포함해 총 17개의 CVE가 패치되었는데요, 특히 HTTP/2와 TLS 관련 취약점이 다수를 차지하고 있어 해당 모듈을 사용하는 서버 환경에서는 업데이트를 서둘러야 할 것으로 보입니다.</p>
<h3>왜 이번 릴리스가 중요한가</h3>
<p>Node.js 22.x LTS 라인을 운영 환경에서 사용 중이라면, 이번 패치는 단순 버그 수정이 아니라 보안 취약점 대응 릴리스라는 점을 분명히 인지해야 합니다. 총 17개의 CVE가 한 번에 패치되었고, 이 중 7개가 High 심각도, 6개가 Medium, 3개가 Low로 분류됩니다. HTTP/2, TLS, HTTP 모듈 전반에 걸쳐 광범위하게 수정이 이뤄졌기 때문에, 해당 프로토콜을 다루는 Node.js 서버라면 거의 예외 없이 영향권에 들어갑니다.</p>
<h3>High 등급 취약점: HTTP/2와 TLS에 집중</h3>
<p>가장 심각도가 높은 7개의 취약점 중 4개가 HTTP/2 구현에서 발견됐습니다.</p>
<ul>
<li><strong>CVE-2026-123863</strong>: 스트림이 제거될 때 헤더를 해제하지 않던 문제 (http2)</li>
<li><strong>CVE-2026-123865</strong>: nghttp2가 포기한 스트림을 감지하지 못하던 문제 (http2)</li>
<li><strong>CVE-2026-123866</strong>: 소켓 쓰기가 끝나기 전에 버퍼가 해제되던 문제 (http2)</li>
<li><strong>CVE-2026-123874</strong>: 쓰기 작업이 대기 중일 때 스트림이 유지되지 않던 문제 (http2)</li>
</ul>
<p>나머지 3개는 TLS 관련입니다.</p>
<ul>
<li><strong>CVE-2026-123864</strong>: 빈 쓰기(empty write)로 인해 파서가 중첩 실행되는 문제 (tls, http)</li>
<li><strong>CVE-2026-123872</strong>: mTLS에서 세션 ID 컨텍스트가 없을 때 세션 재개(resumption)를 막지 않던 문제. 같은 CVE 번호로 재협상(renegotiation)이나 HRR, TLS 세션 재개 과정에서 SNI가 변경되는 것을 허용하던 세 가지 관련 결함도 함께 수정됐습니다.</li>
</ul>
<p>이 중 SNI 관련 결함들은 TLS 핸드셰이크 도중 서버명 지시자(SNI)가 예상치 못하게 바뀌는 상황을 악용할 경우 인증서 검증 로직을 우회할 수 있는 종류의 문제로 볼 수 있어, 상호 TLS 인증을 사용하는 서비스에서는 특히 주의가 필요합니다.</p>
<h3>Medium·Low 등급 수정 사항</h3>
<p>Medium 등급으로는 ALTSVC 버퍼 오버플로(CVE-2026-123828), 인증서 없는 SNI 컨텍스트에 CA 적용 문제(CVE-2026-123867), 스트림이 보유한 인바운드 DATA를 maxSessionMemory에 반영하지 않던 문제(CVE-2026-123868), 잘못된 프록시 URL 에러 메시지에 프록시 자격증명이 노출되던 문제(CVE-2026-123871), 취소된 스트림에서 null 쓰기 요청에 대한 방어 누락(CVE-2026-123875), Agent의 TLS 정책 키가 격리되지 않던 문제(CVE-2026-123877)가 수정됐습니다.</p>
<p>Low 등급으로는 Permission Model 하에서 재귀적 fs.watch 사용 시 차단된 하위 항목이 노출되던 문제(CVE-2026-123829), destroy 이후 zlib 콜백 처리 문제(CVE-2026-123862), 힙 스냅샷 저장 경로를 검증하지 않던 문제(CVE-2026-123873)가 포함됐습니다.</p>
<h3>의존성 업데이트</h3>
<p>보안 패치 외에 다음 두 가지 의존성 업데이트도 함께 반영됐습니다.</p>
<ul>
<li><code>llhttp</code>를 9.4.4로 업데이트</li>
<li><code>sqlite</code>를 3.54.1로 업데이트 (커밋 로그상 3.54.0을 거쳐 3.54.1로 순차 반영)</li>
</ul>
<h3>정리</h3>
<ul>
<li>Node.js 22.23.5는 LTS 'Jod' 라인의 보안 릴리스로, High 7건을 포함한 17개 CVE를 패치했습니다.</li>
<li>가장 큰 비중을 차지하는 영역은 HTTP/2 스트림/버퍼 관리와 TLS 세션 재개·SNI 처리 로직으로, 둘 다 네트워크 서버의 핵심 경로에 해당합니다.</li>
<li>프록시 자격증명 노출, Permission Model의 디렉터리 노출 등 부가적인 정보 유출 취약점도 함께 수정됐으니 프록시나 Permission Model을 활용 중인 환경도 점검이 필요합니다.</li>
<li>실무에서는 Node.js 22.x LTS를 운영 중인 서비스, 특히 HTTP/2나 mTLS를 사용하는 서버는 가급적 빠르게 22.23.5로 업그레이드하는 것이 안전합니다.</li>
