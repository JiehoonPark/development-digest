구글이 AI 코드 생성의 고질병을 해결하는 방법

AI가 생성하는 웹 코드는 늘 한 가지 문제를 안고 있습니다. CSS와 JavaScript는 지난 몇 년간 엄청나게 발전했지만, AI는 여전히 오래되고 구식인 방법으로 코드를 작성한다는 점인데요. 구글이 내놓은 "Modern Web Guidance"라는 완전 무료 도구는 이 문제를 아주 간단하게 해결해줍니다. AI 코딩 에이전트가 항상 최신 모던 코드를 작성하도록 보강해주는 도구인데, 직접 설치해서 테스트해본 결과를 가감 없이 공유해보겠습니다.

Modern Web Guidance란 무엇인가

설치는 정말 간단합니다. 다음 명령어 하나만 실행하면 됩니다.

npx modern-web-guidance@latest

이 명령어를 실행하면 설치 과정이 자동으로 진행되면서, 현재 어떤 코딩 에이전트를 사용 중인지 감지하고 그에 맞춰 "스킬(skill)"을 생성해줍니다.

이 라이브러리는 크게 두 가지 방식으로 동작합니다.

  • 스킬 기반 방식: AI 코딩 에이전트에 스킬을 설치해서 자동으로 활용하는 방식
  • 결정론적(deterministic) 쿼리 방식: 커맨드라인에서 직접 라이브러리에 정보를 물어보는 방식

설치하면 CSS, JavaScript, HTML 등 웹 스택 전반에 걸쳐 특정 기능을 모던하게 구현하는 방법을 담은 마크다운 가이드 파일들이 생성됩니다. 이 가이드들은 실제 모던 웹 개발 전문가들이 AI가 어디서 부족한지 테스트하고, 모던 도구를 제대로 사용하도록 수작업으로 작성한 것입니다.

이 모든 가이드는 "modern web guidance"라는 단 하나의 스킬로 묶여 있습니다. 코딩 에이전트 안에서 직접 이 스킬을 호출할 수도 있지만, 실제로는 백그라운드에서 자동으로 동작하는 것이 이상적입니다. 즉 AI가 애플리케이션을 만들다가 "이 상황에서는 이 스킬을 참고해야겠다"는 걸 스스로 판단해서, 손으로 작성된 가이드를 찾아 적용하는 방식입니다.

실험: 같은 프롬프트, 스킬 유무만 다르게

이 도구의 효과를 검증하기 위해 동일한 프롬프트로 세 가지 프로젝트를 테스트했습니다. 프롬프트 내용은 다음과 같습니다.

  • 가짜 사용자 데이터를 테이블로 보여주고, 각 사용자 옆에 수정 버튼을 추가
  • 수정 버튼 클릭 시 모달에서 폼으로 사용자 정보 편집
  • bio 필드는 텍스트 양에 맞춰 세로로 자동 크기 조절(최대 10줄, 최소 3줄)
  • 테이블에서 사용자를 위/아래로 재정렬할 수 있는 버튼
  • 사용자 이름 클릭 시 이름 옆에 팝업으로 전체 정보 표시, 닫기 버튼이나 다른 모달/팝업을 열어야만 닫힘
  • 이 팝업은 사용자가 위/아래로 이동해도 항상 해당 사용자 위치를 따라다녀야 함

여기에는 일부러 특정 모던 기술을 명시하지 않은 채 힌트만 심어뒀습니다. 모달에는 <dialog> HTML 엘리먼트, bio 필드 자동 크기 조절에는 field-sizing: content CSS 속성, 팝업 위치 추적에는 CSS Anchor Positioning을 쓰도록 유도한 것입니다. 모두 오랫동안 존재해왔고 브라우저 지원도 훌륭한 기능들입니다.

베이스라인: 스킬 없이 Claude Code + Opus 4.5

스킬을 설치하지 않은 순수 Claude Code(Opus 4.5)로 동일한 프롬프트를 실행한 결과는 이렇습니다.

  • 재정렬 기능은 정상 동작
  • 팝오버가 열리고 해당 사용자를 따라다니긴 하지만, 화면 하단에 있는 사용자의 팝오버는 화면 밖으로 넘쳐버림 (Anchor Positioning 미사용)
  • bio 편집 필드는 10줄까지 자동 확장되는 것처럼 보이지만...
  • 화면을 확대해서 스크롤이 생기는 상황을 만들면, 모달이 열려 있는데도 배경 페이지가 스크롤되는 버그 발생

실제 코드를 살펴보면 문제의 원인이 명확합니다.

  • CSS에서 field-sizing을 검색하면 결과가 전혀 없음 — JavaScript로 clamp 계산과 높이 조절을 수동으로 처리
  • CSS에서 anchor를 검색해도 결과 없음 — 팝업 위치를 전부 수동 계산
  • script.js를 보면 팝업 열기/닫기, 위치 계산 등 거의 모든 것이 수작업으로 구현되어 있음
  • 유일하게 제대로 쓰인 것은 <dialog>와 popover API 정도. 오래전부터 지원된 기능들만 간신히 사용

즉, 오랜 기간 브라우저 지원이 보장된 CSS/HTML의 원라인짜리 해결책을 놔두고, AI가 전부 JavaScript로 수동 구현하고 있었던 것입니다.

스킬 설치 후: 완전히 새로운 대화로 재실행

이번엔 완전히 새로운 Claude Code 인스턴스를 시작하고 (이전 대화 기록 전혀 없음), Modern Web Guidance 스킬만 설치한 뒤 똑같은 프롬프트를 똑같이 입력했습니다.

결과는 확연히 달랐습니다.

  • 편집 필드 클릭 시 bio 필드가 정상적으로 최대/최소 크기 제한을 지키며 리사이징
  • 모달이 열려 있을 때 배경 스크롤 문제가 해결됨 — 모달 안에서는 스크롤되지만 배경은 전혀 스크롤되지 않음
  • 다만 화면 하단 팝오버가 화면 밖으로 넘치는 문제는 여전히 남아있음

하지만 이 남은 문제도 모던 CSS 도구를 쓰고 있기 때문에 고치기가 훨씬 쉬웠습니다. styles.css에서 anchor-position을 검색하면 바로 결과가 나오고, flip-inline을 flip-block으로 한 줄만 바꿔주니 팝업이 올바른 위치에 뜨게 됐습니다. 커스텀 로직이 전혀 필요 없었던 것입니다.

더 인상적인 부분은 폴리필 처리였습니다. JavaScript 코드 하단을 보면 CSS 지원 여부를 체크하고, 지원하지 않는 브라우저에서는 자동으로 폴리필을 로드하는 코드가 들어가 있었습니다. 덕분에 구형 브라우저 사용자를 위한 폴백까지 스킬이 알아서 처리해준 셈입니다.

field-sizing: content 역시 제대로 적용되어 있었고, min-block-size와 max-block-size까지 함께 설정되어 있었습니다. (다만 이 부분은 기대했던 만큼 완벽하게 모던한 방식은 아니어서 약간의 가이드 보완 여지는 남아있다고 밝혔습니다.)

전체적으로 봤을 때, 이 스킬 하나만으로 기존에 겪었던 구식 CSS/JavaScript 문제의 95% 정도가 해결됐다는 평가입니다. 그리고 가장 중요한 점은, 프롬프트에서 모던 기능을 명시적으로 언급하지 않았는데도 AI가 스킬을 통해 스스로 추론해서 적절한 기능을 선택했다는 것입니다.

내부적으로 어떻게 동작하는가: 4가지 도구

스킬 모드 말고, Modern Web Guidance가 API 레벨에서 어떻게 동작하는지도 살펴볼 수 있습니다. 이 시스템에는 기본적으로 4가지 도구가 내장되어 있고, 설치(install) 명령 외에 검색(search) 명령도 사용할 수 있습니다.

npx modern-web-guidance@latest

install 명령 대신 search 명령을 사용하면, 하고 싶은 작업을 다소 모호하게 입력해도 관련된 모던 웹 가이드를 찾아줍니다. (원문 트랜스크립트가 이 지점에서 끊겨, 나머지 세 가지 도구와 레거시 코드베이스를 업데이트하는 세 번째 예시에 대한 구체적인 설명은 다루지 않았습니다.)

정리

  • AI 코딩 에이전트는 CSS/JavaScript의 최신 기능을 거의 활용하지 않고, 오래되고 수동적인 방식으로 문제를 해결하는 경향이 강합니다. 구글의 Modern Web Guidance는 이 문제를 해결하기 위해 만들어진 무료 도구입니다.
  • 설치는 npx modern-web-guidance@latest 한 줄이면 끝나며, 코딩 에이전트에 맞춰 마크다운 기반의 스킬을 자동 생성해줍니다.
  • 동일한 프롬프트로 비교했을 때, 스킬이 없는 Claude Code(Opus 4.5)는 field-sizing, CSS Anchor Positioning 같은 모던 기능을 전혀 쓰지 않고 JavaScript로 수동 구현했으며 스크롤 버그까지 있었습니다.
  • 스킬을 설치한 후에는 같은 프롬프트에서도 Anchor Positioning, field-sizing: content가 자동으로 적용됐고, 지원하지 않는 브라우저를 위한 폴리필 로딩까지 알아서 처리됐습니다. 남은 버그도 모던 CSS 속성값 하나만 바꾸면 해결될 정도로 수정이 쉬워졌습니다.
  • 프롬프트에 모던 기능을 명시적으로 언급하지 않아도 AI가 스킬을 통해 적절한 기능을 추론해서 사용했다는 점이 핵심입니다. 실무에서 AI를 활용해 프런트엔드 코드를 작성한다면, 이런 가이드 레이어를 붙여주는 것만으로 결과물의 코드 품질과 브라우저 호환성을 크게 끌어올릴 수 있습니다.
💡
AI로 프런트엔드 코드를 생성할 때 흔히 발생하는 구식·비효율적 구현 문제를 간단한 설치만으로 해결할 수 있어, AI 보조 개발의 코드 품질을 실질적으로 높일 수 있는 방법을 제시한다.
