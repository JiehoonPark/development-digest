Sashay: WebOS Enyo에서 영감을 받은 리사이저블 패널 React 라이브러리

데스크톱 파일 탐색기나 IDE에서 패널 경계선을 드래그해 레이아웃을 조정해본 경험은 다들 있으실 겁니다. Hacker News에 공개된 Sashay는 이런 "패널(pane)" 기반 UI를 React에서 손쉽게 구현할 수 있도록 만든 라이브러리인데요, 과거 WebOS의 Enyo 프레임워크에서 영감을 받았다고 합니다. 패널 사이 경계선을 드래그하면 크기가 조정되고, 공간이 부족해진 패널은 옆으로 접혀 들어가며, 이 레이아웃 상태를 URL에 저장할 수 있다는 점이 핵심입니다.

왜 패널 방식인가

Sashay가 내세우는 지향점은 "파워 유저가 자신의 작업 방식대로 화면을 배치할 수 있게 하되, 인터페이스를 복잡하게 만들지 않는 것"입니다. 각 패널은 평범한 뷰일 뿐이고, 사용자에게 새로 주어지는 컨트롤은 패널 사이의 경계선 하나뿐입니다.

이는 두 극단의 중간 지점을 노리는 설계입니다. 한쪽 끝에는 어떤 패널이든 어디로든 옮길 수 있는 완전히 커스터마이징 가능한 UI가 있고, 반대쪽 끝에는 모든 것을 자동으로 결정해버리는 단순한 반응형 레이아웃이 있습니다. Sashay는 그 사이에서 적당한 자유도를 제공하려는 접근입니다.

기본 사용법

React에서는 @vcarl/sashay/react 패키지를 통해 Sashay와 Pane 컴포넌트로 레이아웃을 구성합니다.

// @vcarl/sashay/react
<Sashay
  onLayoutChange={save}>
  <Pane id="list"
    title="List"
    focus={1/3}>…</Pane>
  <Pane id="detail"
    title="Detail"
    focus={1/2}>…</Pane>
</Sashay>

focus prop으로 패널이 차지할 비율을 지정하고, onLayoutChange 콜백으로 레이아웃 변경 시점을 감지해 저장할 수 있습니다. 라이브러리는 ESM만 지원하며, React 19 이상이 필요하고, 핵심 코어는 의존성이 0개(0-dep core)입니다. 라이선스는 MIT입니다.

모바일 환경에서는 패널 사이 경계선이 탭(tab)으로 바뀌어, 탭을 눌러 패널을 전환하는 방식으로 동작합니다.

분할선은 단순한 분수 비율에 고정된다

패널을 나누는 구분선(divider)은 분모가 6 이하인 단순한 분수 비율 지점에 스냅됩니다. 예를 들어 1/2, 1/3, 2/3 같은 지점에 자연스럽게 정렬되는 것인데요, 덕분에 노트북에서 저장한 레이아웃을 모니터에서 열어도 여전히 말이 되는 배치로 보입니다. 화면(frame)이 넓어질수록 그리드는 더 촘촘해져서, 큰 화면에서는 더 세밀한 비율 조정이 가능합니다.

던지기(throw) 제스처 지원

구분선을 빠르게 드래그한 뒤 놓으면, 단순히 손을 뗀 지점이 아니라 한두 스냅 지점을 더 지나간 곳에 자리를 잡습니다. 이 "던지기" 동작을 판단하기 위해 마지막 90ms 동안의 놓는 속도(release speed)를 읽어들이는데요, 반대로 느리게 드래그하면 손을 뗀 바로 그 지점에 정확히 자리 잡습니다.

패널 하단 바(bottom bar)

모든 패널은 하단에 필터, 설정, 목차 등을 위한 바를 가질 수 있습니다. 이 바는 패널 위로 확장되는 방식으로 펼쳐지며, 모바일에서도 동일하게 동작합니다.

깊은 스택은 스파인(spine)으로 접힌다

드릴다운(drill-down) 방식으로 패널을 계속 깊게 파고들 수 있는데, 더 이상 화면에 들어갈 공간이 없는 패널들은 얇은 스파인 형태로 접혀 들어가고, 각 패널마다 탭 하나씩이 남습니다. 이 구조의 장점은 성능인데, 1,000단계 깊이까지 들어가도 드래그 비용(drag cost)이 평탄하게 유지된다고 소개하고 있습니다.

URL에 저장되는 레이아웃

어떤 패널이 열려 있는지, 폭은 얼마인지, 어떤 바가 펼쳐져 있는지 등 레이아웃 전체 상태가 짧은 코드 형태로 압축되어 URL에 담길 수 있습니다. 이 링크를 공유하면 받는 사람도 동일한 배치를 그대로 볼 수 있습니다. 실제 데모 페이지에서는 ?layout=69.0 같은 쿼리 파라미터 형태로 이를 확인할 수 있습니다.

데모로 확인하는 실사용 예시

공식 페이지에는 두 가지 데모가 소스 코드와 함께 제공됩니다.

  • Houseplants: 창문 방향(북/동/서/남)을 고르고 차트에서 식물을 선택하면, 창문·차트·근처 식물(Nearby Plant) 패널이 서로 연동되어 동작하는 3단 패널 구성 예시입니다. 차트를 좁혀도 선택한 식물은 계속 화면에 남아 있습니다.
  • The house: 집 → 방(응접실, 부엌, 다락, 서재, 욕실, 침실) → 서랍장 → 서랍 → 통 같은 식으로 끝없이 드릴다운할 수 있는 예시로, 이전 단계들은 스파인으로 접혀 들어갑니다.

성능 및 기술 스펙

공식 페이지가 밝힌 수치는 다음과 같습니다.

  • 런타임 의존성: 0개
  • 1,000개 패널 환경에서 드래그 프레임 처리: 2ms 미만
  • 모든 경계선에서 키보드 조작 지원, aria-valuenow 등 접근성 속성 포함
  • 현재 버전: 1.2.1
  • React 19 이상 또는 vanilla 코어로 사용 가능
  • 라이선스: MIT

정리

Sashay는 패널 사이 경계선 드래그만으로 레이아웃을 조정하는 단순한 인터랙션 모델을 제공하면서도, 분수 비율 스냅·던지기 제스처·깊은 스택의 스파인 폴딩·URL 레이아웃 공유 등 세부 디테일에 공을 들인 라이브러리입니다. IDE나 파일 탐색기처럼 여러 뷰를 동시에 띄워놓고 작업하는 "파워 유저용" 대시보드, 관리자 도구, 탐색형 UI를 만들 때 참고할 만합니다. React 19 이상이 필요하고 의존성이 없는 가벼운 코어로 설계되어 있어, 기존 프로젝트에 부담 없이 도입을 검토해볼 수 있는 선택지입니다.

💡
대시보드, 관리자 도구, IDE형 인터페이스처럼 여러 뷰를 동시에 다뤄야 하는 프로젝트에서 복잡한 커스텀 드래그 리사이징 로직을 직접 구현하지 않고도 성능과 접근성을 갖춘 패널 레이아웃을 빠르게 도입할 수 있습니다.
