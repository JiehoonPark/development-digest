Sashay: WebOS Enyo에서 영감을 받은 리사이저블 패널 React 라이브러리
via Hacker News (Top)
frontend

Sashay는 패널 사이 경계선 드래그로 레이아웃을 조정하는 React UI 라이브러리로, 구분선이 단순 분수 비율에 스냅되고 던지기 제스처를 지원하며, 공간이 부족한 패널은 스파인 형태로 접혀 들어갑니다. 레이아웃 상태는 URL에 저장해 공유할 수 있고, 1,000개 패널에서도 드래그 프레임 처리가 2ms 미만으로 유지됩니다. React 19 이상이 필요하며 런타임 의존성이 없는 가벼운 코어로 제공됩니다.

💡
대시보드, 관리자 도구, IDE형 인터페이스처럼 여러 뷰를 동시에 다뤄야 하는 프로젝트에서 복잡한 커스텀 드래그 리사이징 로직을 직접 구현하지 않고도 성능과 접근성을 갖춘 패널 레이아웃을 빠르게 도입할 수 있습니다.
