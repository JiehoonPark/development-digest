독자 엔진 브라우저 Ladybird, 알파 버전 공개
via Hacker News (Top)
🔥오늘의 화제frontend

Chromium, Firefox, Safari 어느 엔진도 포크하지 않고 처음부터 새로 만든 브라우저 Ladybird가 macOS와 Linux용 알파 버전을 공개했습니다. 아직 호환성 문제와 크래시가 있을 수 있지만 브라우저 내장 리포트 기능과 롤링 자동 업데이트를 제공하며, WebDriver와 Firefox DevTools 프로토콜을 지원해 개발자들이 직접 사이트 호환성을 테스트해볼 수 있습니다.

💡
세 번째 계열의 독자 브라우저 엔진이 실사용 가능한 수준에 이르렀다는 것은 웹 표준 호환성 테스트 범위가 넓어진다는 의미이며, 프론트엔드 개발자는 지금부터 자신의 서비스가 새 엔진에서도 정상 동작하는지 점검할 필요가 있습니다.

브라우저에서 대용량 파일 해싱하기: SHA-256 스트리밍과 WASM 활용법
via DEV Community
frontend

crypto.subtle.digest()는 파일 전체를 메모리에 올려야 해서 대용량 파일 해싱에 적합하지 않습니다. 이 글은 Blob.slice()로 파일을 청크 단위로 잘라 읽고 hash-wasm의 증분 해셔에 순차적으로 먹여 메모리 피크를 일정하게 유지하는 체크섬 검증 도구 구현기를 다룹니다. 해시 길이로 알고리즘을 추측하는 방법, 다양한 포맷의 SHA256SUMS 목록을 파싱하는 전략, 파일-해시 매칭 로직까지 실전에서 겪은 디테일을 정리했습니다.

💡
브라우저에서 파일 업로드 없이 체크섬을 검증하거나 대용량 파일을 다뤄야 하는 프론트엔드 개발자에게, 메모리 제약을 우회하는 스트리밍 해싱 패턴과 실전 파싱 디테일을 구체적으로 보여주기 때문입니다.

via Hacker News (Top)
frontend

💡

Auto Agent Protocol 4.0 - MCP·A2A·PAP를 하나로 묶는 자동차 거래 표준 계약
via Echo JS
frontendai

Auto Agent Protocol(AAP) 4.0은 자동차 대리점 발견, 재고 검색, 차량 정보·가격 검증, 리드 제출 같은 자동차 거래 업무를 MCP, A2A, PAP(Personal Agent Protocol) 세 인터페이스 위에서 동일한 계약으로 제공하는 오픈 스펙입니다. 다섯 개 핵심 스킬과 중고차 보상 판매·신용 신청이라는 두 개 선택 스킬을 정의하며, 디스커버리 문서(agent-card.json, poppy.json, llms.txt)를 통해 에이전트가 딜러의 실제 역량을 확인할 수 있게 합니다. 4.0에서는 PAP 1.0 도입, 스네이크 케이스 네이밍 통일, 리베이트 필드 추가 등 주요 변경이 이뤄졌습니다.

💡
여러 에이전트 프로토콜(MCP, A2A 등)이 동시에 쓰이는 환경에서, 특정 도메인에 맞춘 공통 계약과 디스커버리 구조를 설계하는 방식을 보여주는 실제 사례로서 참고 가치가 있다.
