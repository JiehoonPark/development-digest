1980년대부터 현재까지, 사라진 UI 스타일 가이드를 모은 아카이브
via Hacker News (Top)
💡알면 좋은 정보frontend

aresluna.org가 1980년대부터 현재까지 발행된 각종 플랫폼의 UI 스타일 가이드(인터페이스 가이드라인)를 한곳에 모아 보존하는 프로젝트를 공개했습니다. Amiga, GEM, CUA, NeXTSTEP 같은 데스크톱/UNIX 계열부터 iOS, Android, Palm OS, webOS, Windows Mobile 같은 모바일 계열까지 폭넓게 수록되어 있습니다. 단순 링크 모음이 아니라 이미지 정리, 임베드 복구 등 열람 편의 작업을 거쳤으며 전체 아카이브 다운로드도 지원합니다.

💡
현재 당연하게 쓰는 UI 컨벤션과 인터랙션 패턴이 어떤 역사적 디자인 철학과 제약에서 비롯됐는지 추적할 수 있는 1차 자료라서, UI/UX 설계의 맥락을 이해하려는 프론트엔드 개발자와 디자이너에게 유용합니다.
