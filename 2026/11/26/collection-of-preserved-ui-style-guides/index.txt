18:T1a24,<h2>1980년대부터 지금까지, UI 스타일 가이드의 타임캡슐</h2>
<p>GUI(그래픽 사용자 인터페이스)의 역사를 돌아보면 각 플랫폼마다 &quot;우리 제품은 이렇게 디자인하라&quot;는 공식 인터페이스 가이드라인이 존재했습니다. 문제는 이런 문서들이 회사가 망하거나 제품이 단종되면 함께 사라져버린다는 점인데요. aresluna.org에서는 1980년대 초반부터 현재까지 발행된 각종 UI 스타일 가이드(인터페이스 가이드라인)를 한곳에 모아 보존하는 아카이브 프로젝트를 공개했습니다. 단순한 링크 모음이 아니라, 이미지 픽셀화 개선이나 이미지 인라인 처리, 유튜브 임베드 복구 등 실제로 열람하기 편하도록 가벼운 정리 작업까지 거친 것이 특징입니다.</p>
<h3>아카이브에 담긴 플랫폼들</h3>
<p>이 컬렉션은 PC, 모바일, UNIX 계열 운영체제를 가리지 않고 폭넓게 수집한 것이 특징입니다. 주요 항목을 정리하면 다음과 같습니다.</p>
<p><strong>데스크톱 / PC 계열</strong></p>
<ul>
<li><strong>Commodore Amiga (Workbench)</strong> — 1980~90년대 유럽에서 인기 있던 멀티미디어 PC의 GUI</li>
<li><strong>GEM(Graphics Environment Manager)</strong> — 1980년대 OS/GUI로, Atari ST 사용자들에게는 TOS로 잘 알려진 시스템</li>
<li><strong>Common User Access(CUA)</strong> — 1980년대 후반 등장해 Windows와 OS/2에 영향을 준 UI 표준</li>
<li><strong>Common Desktop Environment(CDE)</strong> — Unix용 데스크톱 환경으로, OSF/Motif 위젯을 사용하다 결국 이와 통합됨</li>
<li><strong>OPEN LOOK</strong> — Sun과 AT&amp;T가 시작한 UNIX GUI</li>
<li><strong>SGI(Silicon Graphics Inc.)</strong> — CDE와 마찬가지로 Motif 위젯 기반의 UNIX 계열 OS들을 위한 가이드</li>
<li><strong>RISC OS</strong> — 원래 Acorn 컴퓨터용으로 개발됐고 지금도 커뮤니티 프로젝트로 이어지는 영국산 OS/GUI</li>
<li><strong>GNOME</strong> — Linux/BSD용 데스크톱 환경으로, 버전 넘버링이 상당히 혼란스럽다고 저자는 지적합니다</li>
<li><strong>Windows</strong> — 별도 설명이 필요 없는 그 Windows. 다만 1990년 전후에는 Microsoft가 IBM과 함께 CUA 프레임워크에 집중하느라 공백기가 있었다고 합니다</li>
<li><strong>Microsoft Office</strong> — 특히 리본 UI 사용법을 다루는 전용 가이드라인</li>
<li><strong>NeXTSTEP</strong> — NeXT의 영향력 있는 OS/GUI로, 한쪽으로는 OpenStep으로, 다른 한쪽으로는 현대의 Mac OS X로 이어짐</li>
</ul>
<p><strong>Apple 계열</strong></p>
<ul>
<li>Lisa(1980년대)부터 &quot;클래식&quot; Mac OS, Apple II까지 아우르는 초기 Apple GUI 가이드</li>
<li>Mac OS X/Aqua 이후를 다루는 보다 현대적인 Mac 스타일 가이드</li>
</ul>
<p><strong>모바일 / PDA</strong></p>
<ul>
<li><strong>iOS(구 iPhone OS)</strong> — Apple의 모바일 OS</li>
<li><strong>Android</strong> — iOS의 경쟁자로, 저자가 찾을 수 있었던 가장 오래된 가이드는 2012년 버전</li>
<li><strong>BlackBerry</strong> — 한때 고전하던 휴대폰 제조사</li>
<li><strong>Nokia</strong> — Symbian OS를 포함한 초기 스마트폰용 각종 가이드</li>
<li><strong>Palm OS</strong> — Palm 모바일 기기용 초기 그래픽 OS. 이후 webOS로 전환</li>
<li><strong>webOS</strong> — Palm OS의 후속작으로, HP에 인수됐다가 이후 LG전자로 넘어감. 현재는 스마트 TV, 냉장고, 프로젝터 등에 쓰임</li>
<li><strong>Apple Newton</strong> — 1993년 출시, 1998년 단종된 Apple의 PDA</li>
<li><strong>PenPoint</strong> — GO Corporation이 개발한 초기 태블릿 OS(성공하지 못한 기기 라인용)</li>
<li><strong>General Magic의 모바일 OS</strong> — 지금은 잊힌 General Magic 설계의 모바일 운영체제</li>
<li><strong>Windows Mobile / Windows Phone</strong> — Windows Mobile 6부터 Windows Phone 7까지 이어진, 결국 실패로 끝난 Microsoft의 모바일 시도들</li>
</ul>
<p><strong>기타</strong></p>
<ul>
<li><strong>Java(JFC/Swing)</strong> — 프로그래밍 언어 Java에 포함된 Java Foundation Classes와 Swing GUI 컴포넌트 가이드</li>
<li><strong>Taligent</strong> — Apple과 IBM의 합작사로 설립됐던 문제 많은 소프트웨어 회사. CommonPoint라는 애플리케이션 프레임워크를 남김</li>
</ul>
<h3>왜 이런 아카이브가 의미 있을까</h3>
<p>이 프로젝트의 가치는 단순한 레트로 취향을 넘어섭니다. 각 플랫폼의 스타일 가이드는 당시 디자이너들이 어떤 제약과 철학 속에서 인터페이스를 설계했는지를 보여주는 1차 사료입니다. 예를 들어 CUA가 Windows와 OS/2 모두에 영향을 미쳤다는 사실이나, NeXTSTEP이 OpenStep과 Mac OS X 양쪽으로 갈라져 나간 계보, CDE와 SGI가 공통으로 Motif 위젯을 썼다는 연결고리는 단편적인 링크만으로는 쉽게 파악하기 어려운 디자인 역사의 흐름입니다. 이런 문서가 보존되지 않으면 &quot;왜 지금의 UI 컨벤션이 이런 형태를 띠게 됐는가&quot;를 추적할 방법이 사라지게 됩니다.</p>
<p>저자는 이 컬렉션이 여러 기여자들의 개인 아카이브를 취합한 결과물이라고 밝히고 있으며, 누락된 스타일 가이드가 있다면 제보해달라고 요청하고 있습니다. 전체 자료는 압축 파일 형태로 일괄 다운로드도 가능합니다.</p>

<li>aresluna.org는 1980년대부터 현재까지의 UI 스타일 가이드(인터페이스 가이드라인)를 수집·보존하는 아카이브 프로젝트입니다.</li>
<li>Amiga Workbench, GEM/TOS, CUA, CDE, OPEN LOOK, SGI, RISC OS, GNOME, Windows/Office, NeXTSTEP 같은 데스크톱·UNIX 계열부터, iOS·Android·BlackBerry·Nokia·Palm OS·webOS·Newton·PenPoint·Windows Mobile/Phone 같은 모바일/PDA 계열, 그리고 Java Swing, Taligent CommonPoint까지 폭넓게 망라합니다.</li>
<li>단순 링크 모음이 아니라 이미지 품질 개선, 인라인 처리, 깨진 임베드 수정 등 열람 편의를 위한 정리 작업을 거쳤고, 전체 아카이브를 한 번에 내려받을 수도 있습니다.</li>
