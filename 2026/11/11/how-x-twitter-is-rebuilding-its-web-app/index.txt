18:T1d2d,<h2>자바스크립트 생태계 위클리 브리핑: X의 웹앱 재구축부터 Parcel 3 알파까지</h2>
<p>JavaScript Weekly 810호에서는 X(구 트위터)가 자사 웹 클라이언트를 어떻게 다시 지었는지에 대한 이야기가 가장 눈길을 끕니다. 여기에 더해 Rust로 완전히 새로 쓰인 Parcel 3 번들러 알파 소식, Vite와 Next.js의 보안 패치, 그리고 멀티스레드 자바스크립트 실험 등 프론트엔드 개발자가 챙겨볼 만한 소식들을 한 번에 정리해보겠습니다.</p>
<h3>X(트위터), 서버 3개를 1개의 앱으로 통합하다</h3>
<p>X 엔지니어링 블로그에 올라온 글에 따르면, X는 기존에 운영하던 3개의 서버를 React, Vite, Fastify 기반의 단일 애플리케이션으로 대체하는 작업을 진행하고 있습니다. 이 글을 쓴 Yagiz Nizipli는 Node.js 성능 최적화 작업으로 잘 알려진 엔지니어인데요, 이번 재구축의 핵심인 스트리밍 아키텍처를 설명하면서 실제로 맞닥뜨린 병목 현상들도 함께 공유했습니다.</p>
<p>특히 흥미로운 지점은 수백 개의 작은 자바스크립트 파일이 앱 시작 속도를 느리게 만들었다는 부분입니다. 파일을 잘게 쪼개는 것이 항상 번들링 전략상 유리한 것은 아니며, 오히려 초기 구동 시점에는 파일 개수 자체가 오버헤드로 작용할 수 있다는 점을 보여주는 사례입니다. 대규모 서비스에서 서버 구조를 단순화하면서도 스트리밍 렌더링을 통해 성능을 끌어올리려는 시도라는 점에서, 비슷한 규모의 아키텍처 고민을 하는 팀이라면 참고할 만한 사례입니다.</p>
<h3>Parcel 3 알파: Rust로 완전히 새로 쓴 번들러</h3>
<p>Parcel 팀은 인기 번들러 Parcel을 Rust로 처음부터 다시 작성한 Parcel 3 알파를 공개했습니다. 팀 측 발표에 따르면 React Spectrum의 콜드 빌드 기준으로 Parcel 2 대비 최대 100배 빠른 성능을 낸다고 합니다.</p>
<p>Parcel 3는 Node.js 없이 독립 실행형 바이너리로 동작하며, Rust·Go·Swift로 작성된 네이티브 플러그인을 지원합니다. 자바스크립트로 작성된 플러그인은 내장된 QuickJS 런타임 위에서 실행되는 구조입니다. 번들러 생태계가 Rust 기반으로 재편되는 흐름(Rolldown, Rspack 등) 속에서 Parcel도 같은 방향으로 움직이고 있다는 신호로 볼 수 있습니다.</p>
<h3>짧게 보는 주요 소식</h3>
<ul>
<li><strong>State of JavaScript 2026 설문</strong>이 시작되었습니다. 평소 쓰는 기능, 라이브러리, 도구에 대한 응답을 받고 있으며 결과는 추후 공개될 예정입니다.</li>
<li><strong>TypeScript 7</strong>의 Go 기반 컴파일러가 실험적인 WebAssembly 빌드를 내놓았고, 이는 초기 버전의 TypeScript Playground v2를 구동하는 데 쓰이고 있습니다.</li>
<li><strong>ESLint</strong>가 <code>@eslint/shell</code> 플러그인을 통해 Bash, sh, mksh 같은 셸 스크립트를 공식적으로 린팅할 수 있게 됐습니다. ShellCheck과 유사한 규칙을 제공합니다.</li>
</ul>
<h4>릴리스 소식</h4>
<ul>
<li><strong>Playwright 1.65</strong>: 테스트 러너가 이제 Bun 위에서도 실행 가능해졌고, 새로운 실패 리포터가 추가됐습니다.</li>
<li><strong>Storybook 11 Beta</strong>: 공식 스킬, Claude/Codex 플러그인, 헤드리스 CLI 도구 등 에이전트 친화적인 기능이 강화됐습니다.</li>
<li>🔒 <strong>Vite</strong>: <code>--host</code>나 <code>server.host</code>로 네트워크에 노출된 개발 서버에 영향을 주는 치명적인 원격 코드 실행(RCE) 취약점이 공개됐습니다. 8.3.7, 8.2.5, 8.1.7, 7.3.8, 6.4.6 버전으로 즉시 업그레이드가 권장됩니다.</li>
<li>🔒 <strong>Next.js 16.4.5 / 15.5.29</strong>: 크로스 테넌트 캐시 유출을 포함한 7건의 보안 이슈가 수정됐습니다.</li>
<li>🔒 <strong>Node.js</strong>: 26.x, 24.x, 22.x 라인에 대한 보안 릴리스가 예정되어 있었습니다.</li>
</ul>
<h4>아티클 &amp; 영상</h4>
<ul>

<h3>정리</h3>
