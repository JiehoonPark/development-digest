React 드롭다운 INP를 1,256ms에서 96ms로 줄인 방법: 가상화로 마운팅 비용 해결하기
via Echo JS
frontend

Subito의 커스텀 MultiSelect 컴포넌트는 브랜드 필터처럼 옵션이 1,175개나 되는 경우 드롭다운을 열 때 INP가 1,256ms까지 치솟는 문제가 있었습니다. 원인은 메뉴를 열 때마다 1,175개 Option 컴포넌트를 한 번에 동기적으로 마운트하는 구조였고, 실제 화면에는 6개 행 정도만 보이는 상황이었습니다. 보이는 영역의 행만 마운트하는 90줄짜리 useVirtualScroll 훅을 직접 구현해 INP를 96ms로, 마운트되는 DOM 노드를 1,175개에서 13개로 줄였습니다. 단, 이 단순한 해법은 모든 행의 높이가 동일해야 한다는 전제가 있으며, 그렇지 않다면 디자인 변경이나 TanStack Virtual 같은 라이브러리가 필요합니다.

💡
대량의 옵션을 가진 리스트/드롭다운은 흔한 UI 패턴이지만 무심코 전체를 렌더링하면 INP 같은 핵심 웹 바이탈을 심각하게 해칠 수 있어, 무거운 라이브러리 없이도 표준 React API만으로 해결 가능한 윈도잉 기법과 그 적용 조건을 아는 것이 실무에서 중요하다.
