15:T175d,<h3>개발자들이 또 하나의 클라우드 플랫폼에 주목하는 이유</h3>
<p>Hacker News에 새로운 클라우드 플랫폼 하나가 소개되어 화제가 되고 있습니다. 이름은 Kedge. &quot;정적 사이트부터 서버리스 함수, 풀스택 앱과 데이터베이스까지 사용자와 가까운 곳에 배포한다&quot;는 슬로건을 내걸고 있는데요, 특히 눈길을 끄는 부분은 배포 방식의 간결함과 과금 모델입니다. 이 글에서는 Kedge가 공식 페이지를 통해 공개한 핵심 기능과 가격 정책을 정리해보겠습니다.</p>
<h3>터미널 한 줄로 배포하기</h3>
<p>Kedge가 강조하는 첫인상은 배포 과정의 단순함입니다. 별도의 대시보드나 복잡한 설정 없이, 터미널에서 다음 한 줄이면 배포가 끝납니다.</p>
<pre><code>echo '# Hello, world!' | ssh kedge.dev</code></pre>
<p>SSH 연결 자체를 배포 파이프라인으로 활용하는 방식인데요, CLI에 익숙한 개발자나 AI 에이전트가 스크립트로 배포를 자동화하기에 특히 유리한 구조입니다. 더 복잡한 사용 사례는 공식 quickstart 문서에서 다루고 있다고 안내하고 있습니다.</p>
<h3>핵심 기능들</h3>
<p>Kedge가 공개한 기능 목록을 하나씩 살펴보면 다음과 같습니다.</p>
<ul>
<li><strong>하드웨어 격리 VM</strong>: 완전한 Linux 커널을 갖춘 VM을 하드웨어 수준에서 격리해 보안성을 확보합니다.</li>
<li><strong>즉시 실행되는 샌드박스와 스케일아웃</strong>: 인스턴스를 빠르게 띄우고 필요에 따라 수평 확장이 가능합니다.</li>
<li><strong>글로벌 SQLite 데이터베이스와 공유 파일시스템</strong>: 모든 앱에 기본으로 내장되어 있어 별도의 DB 프로비저닝 없이 바로 사용할 수 있습니다.</li>
<li><strong>오브젝트 스토리지 기반 영속 볼륨</strong>: 로컬 볼륨을 지속적으로 오브젝트 스토리지에 백업해 데이터 유실 위험을 낮춥니다.</li>
<li><strong>퍼블릭 HTTPS 엔드포인트, 프라이빗 네트워킹, 커스텀 도메인</strong> 지원.</li>
<li><strong>오토스케일링</strong>: 사용자와 가까운 위치에 인스턴스를 자동으로 띄우고, 유휴 상태에서는 0까지 스케일 다운합니다.</li>
<li><strong>내장 CDN</strong>: 캐시된 콘텐츠와 정적 자산을 엣지에서 서빙합니다.</li>
<li><strong>SSH, Git, HTTP API</strong> 지원으로 CLI 파워유저와 AI 에이전트 모두를 겨냥.</li>
<li><strong>GitHub 연동</strong>: push-to-deploy 방식으로 PR별 프리뷰 환경을 자동 생성합니다.</li>
</ul>
<p>전반적으로 정적 사이트부터 서버리스 함수, 상태를 가진 풀스택 애플리케이션까지 하나의 플랫폼에서 다루려는 구성인데요, &quot;global SQLite&quot;와 &quot;shared filesystem&quot;이 모든 앱에 기본 내장되어 있다는 점이 Fly.io나 Vercel류 플랫폼과 차별화 포인트로 제시되고 있습니다.</p>
<h3>사용한 만큼만 내는 과금 모델</h3>
<p>Kedge의 가격 정책은 '초 단위 과금(billed per-second)'을 핵심으로 내세웁니다. 할당된 용량(allocated capacity)이 아니라 실제로 소비한 리소스(actual resources consumed) 기준으로만 요금을 매긴다는 점이 특징입니다.</p>
<ul>
<li>CPU는 실제로 스케줄링된 밀리초 단위로만 과금</li>
<li>메모리는 활성 상주 페이지(active resident pages) 기준으로 추적</li>
<li>스토리지는 실제 사용된 바이트만큼만 과금</li>
<li>유휴 상태의 앱은 0으로 스케일 다운되며, 이때는 스토리지 비용만 발생</li>
</ul>
<p>구체적인 요금표는 다음과 같습니다.</p>
<div class="table-wrapper"><table><thead><tr><th>리소스</th><th>단가</th></tr></thead><tbody><tr><td>CPU</td><td>$15 / vCPU-month</td></tr><tr><td>Memory</td><td>$5 / GB-month</td></tr><tr><td>Storage</td><td>$0.05 / GB-month</td></tr><tr><td>Egress</td><td>$0.01 / GB</td></tr></tbody></table></div>
<p>과금은 크레딧 기반으로 이루어지며, 월 $5 상당의 무료 티어를 제공합니다. 작은 웹사이트나 개발용 박스 하나를 무료로 운영하기에는 충분한 수준이라고 안내하고 있습니다. 자세한 내용은 공식 pricing 페이지에서 확인할 수 있습니다.</p>
<p>가입 및 사용은 GitHub 로그인 또는 터미널에서 <code>ssh kedge.dev</code> 명령으로 바로 시작할 수 있습니다.</p>
