15:T11f7,<p>Hacker News를 즐겨 읽는 개발자라면 누구나 공감할 만한 불편함이 있습니다. 흥미로운 글의 링크를 클릭해서 원문을 읽다 보면, 그 아래 달린 코멘트도 궁금해지죠. 결국 탭을 하나 더 열어서 HN 디스커션 페이지로 이동하고, 원문과 코멘트 탭을 번갈아 오가며 읽는 상황이 반복됩니다. 이런 반복적인 불편함을 해결하기 위해 만들어진 것이 바로 오늘 소개할 유저스크립트 <strong>HNewhere</strong>입니다.</p>
<h3>왜 만들었나</h3>
<p>HN에서 링크를 눌러 아티클로 이동하면, 그 글에 대한 토론은 원래 탭에 남아있는 HN 페이지에만 존재합니다. 그래서 글을 읽는 동안 다른 사람들의 반응이 궁금하면 탭을 전환해야 하고, 다시 원문으로 돌아오려면 또 탭을 전환해야 합니다. 개발자는 이 &quot;탭 2개 열기&quot; 패턴이 반복되는 게 번거로워서, 아예 이 과정을 자동화하는 브라우저 유저스크립트를 만들었습니다.</p>
<h3>HNewhere가 하는 일</h3>
<p>HNewhere는 현재 보고 있는 페이지가 HN에 올라온 적이 있는 아티클인지 자동으로 감지합니다. 매칭되는 스토리를 찾으면 해당 HN 디스커션의 코멘트를 사이드바 형태로 페이지에 붙여줍니다. 즉, 탭을 전환할 필요 없이 원문을 읽으면서 동시에 HN 코멘트를 스크롤해서 볼 수 있는 구조입니다.</p>
<h3>주요 기능</h3>
<p>README에 명시된 기능은 다음과 같습니다.</p>
<ul>
<li><strong>아티클 옆에 HN 디스커션 표시</strong>: 원문 페이지 자체에 사이드바로 코멘트를 붙여줌</li>
<li><strong>매칭되는 HN 스토리 자동 감지</strong>: 현재 URL과 일치하는 HN 포스트를 자동으로 찾아 연결</li>
<li><strong>HN에서 열린 링크 추적</strong>: HN을 거쳐 들어온 링크인지를 인식해서 처리</li>
<li><strong>크기 조절 가능한 사이드바</strong>: 사이드바 너비를 원하는 대로 조절 가능</li>
<li><strong>코멘트 접기/펼치기</strong>: 긴 스레드를 접어서 필요한 부분만 볼 수 있음</li>
<li><strong>사이드바 너비 유지</strong>: 한 번 설정한 너비가 다음에도 유지됨</li>
<li><strong>답글 링크는 HN으로 직접 연결</strong>: 코멘트에 답글을 달고 싶으면 해당 링크가 HN 원본 페이지로 바로 연결됨</li>
</ul>
<h3>설치 방법</h3>
<p>HNewhere는 브라우저 확장이 아니라 유저스크립트이기 때문에, 먼저 유저스크립트 매니저가 필요합니다. 지원되는 매니저는 다음과 같습니다.</p>
<ul>
<li>Safari: <strong>Userscripts</strong></li>
<li>크로미움 계열 브라우저: <strong>Tampermonkey</strong></li>
<li><strong>Violentmonkey</strong></li>
</ul>
<p>매니저를 설치한 후에는 <code>HNewhere.user.js</code> 파일을 설치하거나 스크립트 내용을 직접 붙여넣으면 됩니다. 이후 HN에 디스커션이 존재하는 아티클 페이지를 방문하면 자동으로 동작합니다.</p>
<h3>동작 요구사항</h3>
<p>HNewhere가 정상적으로 작동하려면 다음이 필요합니다.</p>
<ul>
<li>유저스크립트를 지원하는 브라우저</li>
<li>Hacker News API 접근</li>
<li>HN Algolia 검색 API 접근</li>
</ul>
<p>HN 자체 API만으로는 현재 보고 있는 아티클 URL과 매칭되는 HN 스토리를 찾기 어렵기 때문에, 검색 기능이 강력한 Algolia의 HN 검색 API를 함께 활용하는 것으로 보입니다.</p>
<h3>라이선스</h3>
<p>이 프로젝트는 MIT 라이선스로 공개되어 있어, 자유롭게 가져다 쓰거나 수정해서 배포할 수 있습니다.</p>
