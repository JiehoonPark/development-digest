HN 링크마다 탭 2개 열기 지겨워서 만든 유저스크립트, HNewhere

Show HN: I was tired of opening 2 tabs for every HN link, so I made a userscript

📅 2026-07-28📰 Hacker News (Top)
frontend

Hacker News를 즐겨 읽는 개발자라면 누구나 공감할 만한 불편함이 있습니다. 흥미로운 글의 링크를 클릭해서 원문을 읽다 보면, 그 아래 달린 코멘트도 궁금해지죠. 결국 탭을 하나 더 열어서 HN 디스커션 페이지로 이동하고, 원문과 코멘트 탭을 번갈아 오가며 읽는 상황이 반복됩니다. 이런 반복적인 불편함을 해결하기 위해 만들어진 것이 바로 오늘 소개할 유저스크립트 HNewhere입니다.

왜 만들었나

HN에서 링크를 눌러 아티클로 이동하면, 그 글에 대한 토론은 원래 탭에 남아있는 HN 페이지에만 존재합니다. 그래서 글을 읽는 동안 다른 사람들의 반응이 궁금하면 탭을 전환해야 하고, 다시 원문으로 돌아오려면 또 탭을 전환해야 합니다. 개발자는 이 "탭 2개 열기" 패턴이 반복되는 게 번거로워서, 아예 이 과정을 자동화하는 브라우저 유저스크립트를 만들었습니다.

HNewhere가 하는 일

HNewhere는 현재 보고 있는 페이지가 HN에 올라온 적이 있는 아티클인지 자동으로 감지합니다. 매칭되는 스토리를 찾으면 해당 HN 디스커션의 코멘트를 사이드바 형태로 페이지에 붙여줍니다. 즉, 탭을 전환할 필요 없이 원문을 읽으면서 동시에 HN 코멘트를 스크롤해서 볼 수 있는 구조입니다.

주요 기능

README에 명시된 기능은 다음과 같습니다.

  • 아티클 옆에 HN 디스커션 표시: 원문 페이지 자체에 사이드바로 코멘트를 붙여줌
  • 매칭되는 HN 스토리 자동 감지: 현재 URL과 일치하는 HN 포스트를 자동으로 찾아 연결
  • HN에서 열린 링크 추적: HN을 거쳐 들어온 링크인지를 인식해서 처리
  • 크기 조절 가능한 사이드바: 사이드바 너비를 원하는 대로 조절 가능
  • 코멘트 접기/펼치기: 긴 스레드를 접어서 필요한 부분만 볼 수 있음
  • 사이드바 너비 유지: 한 번 설정한 너비가 다음에도 유지됨
  • 답글 링크는 HN으로 직접 연결: 코멘트에 답글을 달고 싶으면 해당 링크가 HN 원본 페이지로 바로 연결됨

설치 방법

HNewhere는 브라우저 확장이 아니라 유저스크립트이기 때문에, 먼저 유저스크립트 매니저가 필요합니다. 지원되는 매니저는 다음과 같습니다.

  • Safari: Userscripts
  • 크로미움 계열 브라우저: Tampermonkey
  • Violentmonkey

매니저를 설치한 후에는 HNewhere.user.js 파일을 설치하거나 스크립트 내용을 직접 붙여넣으면 됩니다. 이후 HN에 디스커션이 존재하는 아티클 페이지를 방문하면 자동으로 동작합니다.

동작 요구사항

HNewhere가 정상적으로 작동하려면 다음이 필요합니다.

  • 유저스크립트를 지원하는 브라우저
  • Hacker News API 접근
  • HN Algolia 검색 API 접근

HN 자체 API만으로는 현재 보고 있는 아티클 URL과 매칭되는 HN 스토리를 찾기 어렵기 때문에, 검색 기능이 강력한 Algolia의 HN 검색 API를 함께 활용하는 것으로 보입니다.

라이선스

이 프로젝트는 MIT 라이선스로 공개되어 있어, 자유롭게 가져다 쓰거나 수정해서 배포할 수 있습니다.

정리

HNewhere는 거창한 기능보다 일상적인 불편함 하나를 정확히 겨냥해 해결한 작은 도구입니다. HN 링크를 클릭할 때마다 탭을 두 개 띄우고 왔다 갔다 하던 습관이 있다면, 유저스크립트 매니저 하나 설치하는 것만으로 이 워크플로우를 상당히 단순화할 수 있습니다. 특히 원문 감지와 사이드바 렌더링에 HN API와 Algolia 검색 API를 조합해서 쓴다는 점은, 비슷한 브라우저 확장이나 유저스크립트를 직접 만들어보고 싶은 개발자에게 참고할 만한 구조입니다. 사이드바 UI, 코멘트 트리 렌더링, 상태(너비, 접힘 여부) 유지 같은 부분은 다른 "페이지에 오버레이를 붙이는" 형태의 프로젝트에도 응용할 수 있는 패턴입니다.

💡
브라우저에 오버레이 UI를 붙이는 유저스크립트 패턴과 외부 API(HN API, Algolia)를 조합해 실용적인 도구를 만드는 사례로, 프론트엔드 개발자가 작은 아이디어를 빠르게 도구화하는 방법을 참고할 수 있습니다.
