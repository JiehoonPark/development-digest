React Native로 만든 우리 집 포치 조명 시스템, Amazon Vega로 구현하기

집에 있는 3D 프린팅 행성 모형과 LED 조명을 스마트TV 앱으로 제어하는 개인 프로젝트를 진행하면서, Amazon의 새 TV 플랫폼 Vega를 사용해본 경험을 정리했습니다. React와 React Native에 익숙한 개발자라면 생각보다 훨씬 쉽게 대형 화면용 앱을 만들 수 있다는 걸 확인할 수 있었습니다.

프로젝트 배경: 포치 위의 태양계

집안 식구들이 천문학에 관심이 많아서, 3D 프린터로 출력한 행성 모형들을 포치 뒤편에 쭉 늘어놓고 제어 가능한 LED로 조명을 넣었습니다. 영화를 볼 때 분위기를 살려주는 용도였는데, 여기서 한 발 더 나가 포치의 행성 조명과 거실의 대형 프로젝션 스크린을 서로 연결하고 싶었습니다.

이 목표를 위해 플랫폼을 찾아보다가 Amazon의 Fire Stick용 Vega를 선택했습니다. 결정적인 이유는 Vega의 UI가 React Native 기반이라는 점이었고, 평소 React와 React Native를 다뤄온 경험이 있어서 자연스럽게 손이 갔습니다.

Vega 개발 경험: 예상보다 쉬웠던 온보딩

실제로 사용해보니 예상했던 것보다 훨씬 수월했습니다. Vega는 VS Code용 확장 프로그램을 제공하는데, 여기에 로컬 시뮬레이터가 포함되어 있어 실제 기기 없이도 코드를 손쉽게 디버깅할 수 있었습니다.

또한 요즘 널리 쓰이는 AI 코딩 에이전트들이 React Native에 이미 익숙하기 때문에, Vega 공식 문서 링크만 던져주면 세부적인 API나 설정 관련 내용을 알아서 참고해가며 코드를 작성해줬습니다. 여기에 프로젝트를 빠르게 초기화할 수 있는 CLI 도구까지 제공되어, 처음 시작하는 진입장벽이 낮았습니다.

만든 것: 태양계 지도 앱과 LED 연동

이렇게 만든 결과물은 손님이 놀러 왔을 때 화면에 태양계 지도를 띄우고, 각 행성에 대한 정보를 함께 보여주는 앱입니다. 리모컨의 D-pad를 이용해 지도를 이리저리 탐색하면서 조명과 행성 모형 사이를 오갈 수 있습니다.

LED 조명 제어는 WLED 컨트롤러를 사용했는데, Vega 앱 안에서 일반적인 fetch 호출로 HTTP 요청을 바로 보내는 방식으로 구현했습니다. 별도의 복잡한 통신 계층 없이, 웹 개발에서 흔히 쓰는 방식 그대로 하드웨어 제어까지 연결한 셈입니다.

마무리: 음성 제어로 완성도 높이기

프로젝트를 한 단계 더 완성도 있게 만들기 위해, 사용자가 행성 이름을 말하면 화면과 조명에 해당 행성이 표시되는 기능을 추가하고 싶었습니다. 이 작업은 놀라울 정도로 간단했는데, 컴포넌트에 aria label만 붙여주면 Vega가 음성 인식과 관련된 나머지 작업을 전부 알아서 처리해주고, 사용자가 이름을 말했을 때 press 이벤트를 자동으로 보내주는 방식이었습니다. 실제로 "Saturn"이라고 말하면 화면과 조명이 바로 반응하는데, 이 마지막 손질 하나로 프로젝트 전체의 완성도가 확 올라갔습니다.

정리

  • Amazon Vega는 React Native 기반 UI 프레임워크로, React/React Native 경험이 있는 개발자라면 별도의 큰 학습곡선 없이 Fire Stick용 앱을 만들 수 있습니다.
  • VS Code 확장과 로컬 시뮬레이터 덕분에 실기기 없이도 빠르게 개발·디버깅이 가능하고, CLI로 프로젝트 초기 설정도 간편합니다.
  • AI 코딩 에이전트가 React Native 생태계에 이미 익숙하기 때문에, Vega 공식 문서만 참조시켜도 세부 구현을 수월하게 도와줍니다.
  • 웹 개발에서 익숙한 fetch API로 외부 하드웨어(WLED 컨트롤러)를 그대로 제어할 수 있어, 별도의 통신 레이어 없이 IoT 연동이 가능합니다.
  • aria label만 추가하면 음성 명령 인식과 이벤트 처리를 Vega가 자동으로 담당해주므로, 접근성 속성이 곧 음성 제어 기능으로 이어지는 구조입니다.
💡
React/React Native 지식을 그대로 활용해 스마트TV·IoT 영역까지 확장할 수 있음을 보여주는 사례로, 웹 프론트엔드 개발자에게 새로운 플랫폼 진입 장벽이 얼마나 낮아졌는지를 시사합니다.
