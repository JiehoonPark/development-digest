We just shipped support for the ugliest part of HTTP: Vary
via Hacker News (Top)
💡알면 좋은 정보frontend

HTTP 표준 헤더 중 하나인 Vary는 "아직 개선하지 못한, HTTP에서 가장 지저분한 부분"이라는 말을 들을 정도로 악명이 높습니다. 중개 서버(intermediary) 간 상호운용성이 형편없다는 평가까지 받는 헤더인데요. 하지만 지저분하다고 해서 쓸모없다는 뜻은 아닙니다. Cloudflare는 최근 모든 플랜에서 Cache Rules를 통해 Vary 헤더를 제어할 수 있는 기능을 출시했습니다. 이 글에서는 Vary가 왜 다루기 까다로운 헤더인지, 그리고 Cloudflare가 이 문제를 어떻게 풀었는지 정리해봅니다.

JavaScript 대신 이 CSS 기능들을 써보세요
via Kevin Powell (CSS)
▶영상frontend

Kevin Powell이 소개하는, 이미 브라우저 지원이 탄탄한데도 여전히 JavaScript로 구현되는 CSS 기능들을 정리한 글입니다. scroll-margin으로 앵커 스크롤 겹침 문제 해결하기, scroll-snap-type으로 가로 스크롤러 만들기, :user-valid/:user-invalid로 폼 검증하기, :focus-visible로 접근성 지키기, lh 단위와 field-sizing으로 텍스트 영역 다루기까지 다룹니다. 각 기능 모두 한두 줄의 CSS로 복잡한 JavaScript 로직을 대체할 수 있습니다.

💡
이미 baseline widely available 수준으로 지원되는 CSS 기능들로 불필요한 JavaScript 의존성을 줄이면 코드는 간결해지고 성능과 접근성은 오히려 개선되므로, 실무 프론트엔드 개발자가 바로 적용할 수 있는 실용적인 지식이다.

Amazon Vega로 포치 행성 조명 만들기: React Native 개발자의 실전 후기
via Jack Herrington
▶영상frontend

React/React Native 개발자 Jack Herrington이 포치에 설치한 3D 프린팅 행성 조명을 Amazon의 Fire TV용 프레임워크 Vega로 제어하는 프로젝트를 소개합니다. Vega는 React Native 기반 UI를 사용해 기존 React 지식을 그대로 활용할 수 있었고, VS Code 확장과 로컬 시뮬레이터, CLI 도구 덕분에 개발이 예상보다 훨씬 수월했습니다. WLED 컨트롤러 제어는 fetch API로, 음성 명령 기능은 aria-label 속성만으로 구현할 수 있었다는 점이 인상적입니다.

💡
React/React Native 경험을 그대로 활용해 TV 앱과 IoT 제어까지 확장할 수 있다는 점에서, 웹 프론트엔드 개발자의 기술 스택이 얼마나 넓은 플랫폼으로 이어질 수 있는지 보여주는 실전 사례입니다.
