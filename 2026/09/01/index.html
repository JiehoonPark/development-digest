🔥오늘의 화제frontend

React Server Components의 react-server-dom-webpack/parcel/turbopack 패키지 19.0~19.2.0 버전에서 CVSS 10.0의 인증 없는 원격 코드 실행 취약점이 발견되어 각각 19.0.1, 19.1.2, 19.2.1로 긴급 패치되었습니다. Next.js, React Router, Waku, Redwood SDK 등 RSC를 지원하는 프레임워크와 번들러가 광범위하게 영향을 받으며, Server Function을 직접 쓰지 않아도 RSC 지원 환경이면 취약할 수 있습니다. React 팀은 프레임워크별 정확한 업그레이드 명령어를 제시하며 즉시 패치할 것을 권고했습니다.

💡
RSC 기반 프레임워크(Next.js, React Router 등)를 프로덕션에서 사용 중인 프론트엔드 개발자라면 CVSS 10.0의 이 취약점에 즉시 대응해야 서비스 침해를 막을 수 있습니다.
