13:T1ed6,<p>React Conf 2025가 지난 10월 7일부터 이틀간 네바다주 헨더슨에서 열렸습니다. 이번 컨퍼런스에서는 React Foundation 출범이 발표되었고, React와 React Native 진영에 추가될 다양한 신기능이 공개되었는데요. 이 글에서는 이틀간 진행된 키노트와 세션 내용을 정리해봅니다.</p>
<h3>Day 1 키노트: React 19.2와 Compiler v1.0</h3>
<p>Joe Savona는 지난 컨퍼런스 이후 팀과 커뮤니티의 진행 상황, 그리고 React 19.0과 19.1의 주요 내용을 돌아보며 첫날 키노트를 열었습니다.</p>
<p>이어서 Mofei Zhang이 <strong>React 19.2</strong>에 포함된 신기능들을 소개했습니다.</p>
<ul>
<li><code>&lt;Activity /&gt;</code> — 컴포넌트의 가시성(visibility)을 관리하는 새로운 컴포넌트</li>
<li><code>useEffectEvent</code> — Effect 안에서 이벤트를 발생시키는 훅</li>
<li><strong>Performance Tracks</strong> — DevTools에 새로 추가된 프로파일링 도구</li>
<li><strong>Partial Pre-Rendering</strong> — 앱의 일부를 미리 렌더링해두고 나중에 이어서 렌더링을 재개하는 기능</li>
</ul>
<p>Jack Pope는 현재 Canary 채널에서 사용 가능한 신규 기능들을 발표했습니다.</p>
<ul>
<li><code>&lt;ViewTransition /&gt;</code> — 페이지 전환 애니메이션을 위한 새로운 컴포넌트</li>
<li><strong>Fragment Refs</strong> — Fragment로 감싸진 DOM 노드에 접근하는 새로운 방식</li>
</ul>
<p>Lauren Tan은 <strong>React Compiler v1.0</strong>을 발표하며, 모든 애플리케이션에서 React Compiler를 사용할 것을 권장했습니다. 그 이유로 다음을 꼽았습니다.</p>
<ul>
<li>React 코드를 이해하고 자동으로 메모이제이션을 적용하는 기능</li>
<li>React Compiler 기반의 새로운 lint 규칙으로 베스트 프랙티스 학습 지원</li>
<li>Vite, Next.js, Expo에서 신규 프로젝트에 기본 지원</li>
<li>기존 앱을 React Compiler로 마이그레이션하기 위한 가이드 제공</li>
</ul>
<p>마지막으로 Seth Webster는 React의 오픈소스 개발과 커뮤니티를 관장할 <strong>React Foundation</strong> 설립을 발표했습니다.</p>
<h3>Day 2 키노트: React Native의 성장과 신규 아키텍처</h3>
<p>둘째 날은 Jorge Cohen과 Nicola Corti가 React Native의 놀라운 성장세를 소개하며 문을 열었습니다. 주간 다운로드 수는 400만 건으로 전년 대비 100% 성장했으며, Shopify, Zalando, HelloFresh 등의 주목할 만한 마이그레이션 사례, RISE·RUNNA·Partyful 같은 수상작 앱, 그리고 Mistral·Replit·v0 등의 AI 애플리케이션 사례가 공유되었습니다.</p>
<p>Riccardo Cipolleschi는 React Native 관련 두 가지 굵직한 발표를 전했습니다.</p>
<ul>
<li><strong>React Native 0.82부터는 New Architecture만 지원</strong></li>
<li><strong>Hermes V1 실험적 지원</strong> 시작</li>
</ul>
<p>이어서 Ruben Norte와 Alex Hunt가 다음 내용을 발표하며 키노트를 마무리했습니다.</p>
<ul>
<li>웹의 React와 호환성을 높이는 <strong>웹 표준 정렬 DOM API</strong> 신규 지원</li>
<li>새로운 네트워크 패널과 데스크톱 앱을 포함한 <strong>Performance API</strong> 신규 지원</li>
</ul>

<p>컨퍼런스 기간 동안 React 팀 멤버들의 다양한 세션도 진행되었습니다.</p>
<ul>
<li><strong>Async React Part I &amp; II</strong> (Ricky Hanlon) — 지난 10년간의 혁신을 바탕으로 가능해진 것들을 조명</li>
<li><strong>Exploring React Performance</strong> (Joe Savona) — React 성능 연구 결과 공유</li>

<li><strong>Profiling with React Performance tracks</strong> (Ruslan Lesiutin) — 새로운 React Performance Tracks로 성능 이슈를 디버깅하는 방법</li>
<li><strong>React Strict DOM</strong> (Nicolas Gallagher) — 웹 코드를 네이티브에서 사용하는 Meta의 접근 방식</li>
<li><strong>View Transitions and Activity</strong> (Chance Strickland) — React 팀과 협업해 <code>&lt;Activity /&gt;</code>와 <code>&lt;ViewTransition /&gt;</code>으로 빠르고 네이티브 같은 애니메이션을 구현하는 방법</li>

<h3>정리</h3>
<ul>
<li>React 19.2에서는 <code>&lt;Activity /&gt;</code>, <code>useEffectEvent</code>, Performance Tracks, Partial Pre-Rendering이 정식 추가되었고, Canary에서는 <code>&lt;ViewTransition /&gt;</code>과 Fragment Refs를 미리 사용해볼 수 있습니다.</li>
<li><strong>React Compiler v1.0</strong>이 정식 출시되면서, React 팀은 신규·기존 프로젝트 모두에 Compiler 도입을 적극 권장하고 있습니다. Vite, Next.js, Expo는 이미 기본 지원을 제공합니다.</li>
<li>React의 오픈소스 거버넌스를 담당할 <strong>React Foundation</strong>이 새로 설립되어, 커뮤니티 중심의 지속가능한 개발 체계를 구축합니다.</li>
<li>React Native는 주간 다운로드 400만 건(전년 대비 100% 성장)을 기록했으며, <strong>0.82부터 New Architecture만 지원</strong>하고 Hermes V1을 실험적으로 도입하는 등 아키텍처 전환이 본격화되고 있습니다.</li>
<li>리스트 렌더링을 위한 <strong>Virtual View</strong>, 웹 표준에 맞춘 DOM API, 새로운 네트워크 패널 기반 Performance API 등 React Native의 성능·호환성 개선 작업도 활발히 진행 중입니다.</li>
</ul>
