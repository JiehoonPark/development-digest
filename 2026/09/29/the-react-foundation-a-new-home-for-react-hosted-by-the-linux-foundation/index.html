React Foundation 공식 출범: 리눅스 재단 산하 새로운 보금자리

The React Foundation: A New Home for React Hosted by the Linux Foundation

📅 2026-09-29📰 React Blog
frontend

React 진영에 오래 몸담아온 개발자라면 "React는 Meta의 것"이라는 인식이 어느 순간부터 옅어지고 있다는 느낌을 받았을 겁니다. 지난해 10월 React Foundation 설립 의사가 처음 발표된 데 이어, 드디어 2026년 2월 24일 React Foundation이 리눅스 재단(Linux Foundation) 산하로 공식 출범했습니다. 이번 글에서는 이 발표의 핵심 내용과 앞으로의 변화 방향을 정리해봅니다.

React가 더 이상 Meta 소유가 아니다

이번 발표에서 가장 눈에 띄는 대목은 React, React Native 그리고 JSX 같은 관련 프로젝트들이 더 이상 Meta 소유가 아니라는 점입니다. 이제 이 프로젝트들은 독립 재단인 React Foundation이 소유하며, 이 재단은 리눅스 재단이 호스팅하는 형태로 운영됩니다. 자세한 내용은 리눅스 재단이 발표한 보도자료에서도 확인할 수 있습니다.

React가 특정 기업의 내부 프로젝트가 아니라 업계 전반이 함께 관리하는 공용 인프라로 성격이 바뀐 셈인데요, 이는 오픈소스 생태계에서 Kubernetes나 Node.js가 걸어온 길과 비슷한 궤적이라고 볼 수 있습니다.

창립 멤버와 거버넌스 구조

React Foundation의 플래티넘 창립 멤버는 총 8곳입니다: Amazon, Callstack, Expo, Huawei, Meta, Microsoft, Software Mansion, Vercel. 이 가운데 Huawei는 지난 10월 최초 발표 이후 새롭게 합류한 멤버입니다.

재단 운영은 각 멤버사의 대표로 구성된 이사회(board of directors)가 맡으며, Seth Webster가 사무총장(executive director) 역할을 맡습니다.

기술 거버넌스는 별도로 분리

여기서 중요한 부분은 재단의 조직 운영과 React의 기술적 방향성이 분리되어 있다는 점입니다. React Foundation 이사회가 재단 운영을 담당하더라도, React의 기술적 의사결정은 항상 재단 이사회로부터 독립적으로 유지될 예정입니다. 즉, React의 기술 방향은 앞으로도 실제로 React에 기여하고 유지보수하는 사람들이 결정한다는 원칙입니다.

이를 위해 현재는 잠정 리더십 위원회(provisional leadership council)가 구성되어 향후 기술 거버넌스 구조를 확정하는 작업을 진행 중이며, 관련 업데이트는 향후 수개월 내에 공유될 예정입니다.

앞으로의 계획

재단 전환 작업은 아직 완료되지 않았습니다. React Foundation은 다음 과제들을 앞으로 몇 달간 진행할 계획이라고 밝혔습니다.

  • React의 기술 거버넌스 구조 확정
  • 저장소(repository), 웹사이트 등 인프라를 React Foundation으로 이관
  • React 생태계를 지원하기 위한 프로그램 모색
  • 차기 React Conf 기획 착수

이러한 작업이 진행되는 대로 관련 소식을 계속 공유하겠다고 전했습니다.

정리

  • React, React Native, JSX 등 관련 프로젝트의 소유권이 Meta에서 리눅스 재단 산하 독립 기구인 React Foundation으로 이전되었습니다.
  • 창립 멤버는 Amazon, Callstack, Expo, Huawei, Meta, Microsoft, Software Mansion, Vercel 8곳이며, 이사회 체제로 운영되고 Seth Webster가 사무총장을 맡습니다.
  • 재단의 조직 운영과 별개로, React의 기술적 의사결정 권한은 독립성을 유지하며 잠정 리더십 위원회가 구체적인 거버넌스 구조를 마련 중입니다.
  • 저장소 이관, 생태계 지원 프로그램, 차기 React Conf 준비 등 실질적인 전환 작업이 향후 몇 달에 걸쳐 이어질 예정입니다.
  • 이번 변화는 React가 특정 기업 종속 프로젝트에서 벗어나 업계 전반이 함께 책임지는 공용 오픈소스 인프라로 자리매김하는 상징적 전환점으로 볼 수 있습니다.
💡
React가 단일 기업 종속에서 벗어나 다자간 거버넌스 체계로 전환됨에 따라, 생태계의 장기적 안정성과 중립성을 신뢰하고 React를 채택하려는 프론트엔드 개발자와 기업들에게 중요한 신호가 됩니다.
