포치를 밝히는 나만의 태양계, Amazon Vega로 만들어보기

집에 3D 프린터로 뽑은 행성 모형을 포치(porch)에 쭉 세워놓고 LED로 조명을 밝히는 취미 프로젝트를 진행하던 개발자가, 이 아날로그 설치물을 디지털 인터랙션과 연결하고 싶다는 생각에서 시작한 실험을 소개합니다. 천문학에 진심인 가족을 위해 만든 이 프로젝트는 결국 Amazon의 새로운 Fire TV 플랫폼인 Vega를 직접 써보는 계기가 되었는데요, React/React Native 개발자 입장에서 실제로 얼마나 쉽게 접근할 수 있었는지를 정리해봅니다.

프로젝트의 시작: 행성 조명과 프로젝터 화면 연결하기

집 뒤쪽 포치를 따라 3D 프린트한 행성들을 나란히 배치하고, 각 행성에 제어 가능한 LED 조명을 달아둔 상태였습니다. 영화를 볼 때 분위기를 내기엔 충분했지만, 여기서 한 걸음 더 나아가 실제 프로젝션 스크린과 이 행성 조명들을 서로 연동하고 싶었습니다. 즉, 화면에 태양계 정보를 띄우면서 동시에 실물 조명도 함께 반응하게 만들고 싶었던 것이죠.

이를 구현할 하드웨어를 찾아보다가 Amazon의 Fire Stick과 그 위에서 동작하는 새로운 UI 플랫폼인 Vega를 선택했습니다. 결정적인 이유는 Vega가 UI 레이어로 React Native를 사용한다는 점이었습니다. 이미 React와 React Native에 익숙했기 때문에 진입 장벽이 낮을 것으로 예상했고, 실제로도 예상보다 훨씬 수월했다고 밝히고 있습니다.

개발 경험: VS Code 확장과 로컬 시뮬레이터

Vega는 VS Code용 확장 프로그램을 제공하며, 여기에 로컬 시뮬레이터가 포함되어 있어 실제 기기 없이도 코드를 디버깅하기가 매우 쉬웠다고 합니다. 프로젝트를 처음 시작할 때 필요한 보일러플레이트를 잡아주는 CLI 도구도 별도로 제공되어, 초기 세팅 과정에서 겪을 법한 마찰을 크게 줄여줍니다.

여기에 더해 최근 코딩 에이전트들이 React Native에 대한 이해도가 높다는 점도 도움이 되었습니다. AI 코딩 에이전트에게 Vega 공식 문서 링크만 던져주면, React Native 관련 지식을 기반으로 Vega 특유의 세부 API나 컨벤션까지 빠르게 캐치해낸다는 것이죠. 결과적으로 별도의 학습 곡선 없이 기존 React 생태계 지식과 문서, AI 에이전트의 조합만으로 개발을 진행할 수 있었습니다.

실제 구현: 태양계 지도, D-pad 내비게이션, WLED 연동

이렇게 만든 앱은 손님이 놀러 왔을 때 태양계 지도를 화면에 띄우고, 각 행성에 대한 정보를 함께 보여줍니다. 사용자는 Fire TV 리모컨의 D-pad를 이용해 지도를 탐색하면서 동시에 실제 포치에 설치된 조명들도 함께 움직이며 반응하게 됩니다.

조명 제어는 WLED 컨트롤러를 통해 이루어지는데, Vega 앱에서 별도의 복잡한 통신 계층 없이 표준 fetch API로 HTTP 요청을 WLED 컨트롤러에 직접 보내는 방식으로 구현했습니다. 즉, React Native 환경에서 익숙한 네트워크 호출 방식을 그대로 활용해 물리적인 LED 하드웨어를 제어한 셈입니다.

마무리 터치: 음성 명령으로 행성 부르기

프로젝트의 완성도를 높이기 위해 추가한 기능은 음성 인식이었습니다. 사용자가 행성 이름을 말하면 해당 행성이 화면에 표시되고, 동시에 실제 조명도 반응하도록 만들고 싶었는데, 이 부분이 놀라울 정도로 간단했다고 합니다.

구현 방법은 단순히 UI 요소에 aria-label을 추가하는 것뿐이었습니다. 음성 인식과 관련된 복잡한 처리는 Vega 플랫폼이 전부 알아서 처리해주었고, 사용자가 특정 이름(예: "Saturn")을 말하면 해당 라벨에 대응하는 press 이벤트가 자동으로 발생하는 방식으로 동작했습니다. 별도의 음성 인식 SDK 통합이나 커스텀 로직 없이, 접근성을 위한 표준 속성 하나로 음성 제어 기능까지 확보한 셈입니다.

정리

  • 선택 이유: Amazon Vega는 UI 레이어에 React Native를 사용하기 때문에, 기존 React/React Native 지식을 그대로 재사용해 Fire TV용 앱을 만들 수 있습니다.
  • 개발 편의성: VS Code 확장과 로컬 시뮬레이터 덕분에 실기기 없이도 빠른 디버깅이 가능하며, CLI 도구로 프로젝트 초기 세팅도 간단합니다.
  • AI 에이전트 친화적: 코딩 에이전트가 이미 React Native에 익숙하기 때문에 Vega 공식 문서만 참고 자료로 던져주면 세부 API까지 무리 없이 다룰 수 있었습니다.
  • 하드웨어 연동은 표준 웹 API로: WLED 조명 컨트롤러 제어는 별도의 SDK 없이 평범한 fetch 호출로 HTTP 명령을 보내는 것만으로 충분했습니다.
  • 음성 제어는 접근성 속성만으로 해결: aria-label을 붙이는 것만으로 Vega가 음성 인식과 press 이벤트 매핑을 전부 처리해주어, 최소한의 코드로 음성 인터랙션을 구현할 수 있었습니다.

React나 React Native에 익숙한 프론트엔드 개발자라면, Amazon Vega는 별도의 학습 곡선 없이 TV 및 대형 스크린용 애플리케이션을 만들어볼 수 있는 실용적인 선택지가 될 수 있습니다.

💡
React/React Native 생태계 지식을 그대로 재사용해 TV 및 대형 스크린 애플리케이션까지 확장할 수 있다는 점에서, 프론트엔드 개발자의 기술 스택 활용 범위를 넓혀주는 사례입니다.
