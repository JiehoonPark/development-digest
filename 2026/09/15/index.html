React Server Components 치명적 보안 취약점(CVE-2025-55182) 발생, 즉시 업데이트 필요
via React Blog
🔥오늘의 화제frontend

React Server Components의 페이로드 디코딩 방식에서 CVSS 10.0의 인증되지 않은 원격 코드 실행 취약점(CVE-2025-55182)이 발견되었습니다. react-server-dom-webpack, react-server-dom-parcel, react-server-dom-turbopack의 19.0~19.2.0 버전이 영향을 받으며, Next.js, React Router, Waku 등 이를 사용하는 프레임워크도 함께 영향을 받습니다. 💡
React Server Components를 프로덕션에 사용 중인 모든 팀에게 즉각적인 조치가 필요한 최고 등급 보안 이슈이므로, 사용 중인 프레임워크와 패키지 버전을 지금 바로 점검해야 합니다.

Cloudflare AKE, 오리진 HelloRetryRequest 비율을 52%에서 3.7%로 낮추다
via Hacker News (Top)
frontenddevops

Cloudflare는 오리진 서버와의 TLS 1.3 연결에서 첫 키 교환 알고리즘을 고정적으로 추측하던 방식 대신, 각 오리진을 실제로 스캔해 지원 알고리즘을 파악하고 양자 내성 알고리즘을 우선 적용하는 Automatic Key Exchange를 출시했습니다. 이를 통해 HelloRetryRequest 비율이 52%에서 3.7%로 줄고 p90 핸드셰이크 지연이 150ms 이상 단축됐으며, 수십만 도메인이 별도 설정 없이 양자 내성 연결을 갖게 됐습니다. 이 기능은 기존 Automatic SSL/TLS 스캐닝 파이프라인을 재활용하며 모든 도메인에 기본 활성화되어 있습니다.

💡
웹사이트나 API 서버를 운영하는 개발자 입장에서 TLS 핸드셰이크 지연은 체감 성능에 직접 영향을 주며, 별도 설정 없이 양자 내성 암호화까지 자동 적용된다는 점은 향후 보안 컴플라이언스 대응 부담을 크게 줄여준다.
