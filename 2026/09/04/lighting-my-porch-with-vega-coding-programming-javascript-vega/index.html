React Native로 만든 우리 집 포치의 태양계

이번 글에서는 프론트엔드 개발자가 취미로 진행한 홈 IoT 프로젝트를 소개합니다. 3D 프린팅한 행성 모형과 LED 조명, 그리고 Amazon의 새로운 TV 앱 플랫폼 Vega를 결합해 포치(porch)를 태양계 전시 공간으로 바꾼 이야기인데요. React와 React Native에 익숙한 개발자라면 얼마나 손쉽게 이런 프로젝트를 완성할 수 있는지 보여주는 좋은 사례입니다.

프로젝트의 시작: 천체 덕질에서 나온 아이디어

작성자의 가족은 천문학에 관심이 많습니다. 그래서 3D 프린터로 출력한 행성 모형들을 포치 뒤편에 나란히 세워두고, 각 행성을 제어 가능한 LED로 조명했습니다. 영화를 볼 때 분위기를 살려주는 용도로는 충분했지만, 여기서 한 단계 더 나아가 포치에 있는 대형 프로젝션 스크린과 이 행성 조형물들을 연결하고 싶었다고 합니다.

왜 Amazon Vega를 선택했나

여러 옵션을 살펴보던 중 Fire Stick과 Amazon의 Vega를 선택했습니다. 결정적인 이유는 Vega의 UI 레이어가 React Native로 만들어져 있다는 점이었습니다. React와 React Native에 이미 익숙했기 때문에 학습 곡선이 거의 없었고, 실제로 예상했던 것보다 훨씬 쉽게 개발할 수 있었다고 언급합니다.

Vega 개발 환경도 꽤 잘 갖춰져 있었습니다.

  • VS Code용 Vega 확장 프로그램이 제공되어 개발 편의성이 높았고
  • 로컬 시뮬레이터가 내장되어 있어서 실제 Fire TV 기기 없이도 코드를 디버깅하기 편했습니다
  • 프로젝트를 처음 세팅할 수 있는 CLI 툴도 제공됩니다

또 하나 흥미로운 포인트는 AI 코딩 에이전트들이 React Native 코드를 다루는 데 이미 능숙하다는 점입니다. 여기에 Vega 공식 문서를 추가로 참고시키기만 하면, 세부적인 플랫폼 API까지도 에이전트가 큰 어려움 없이 다룰 수 있었다고 합니다.

결과물: 태양계 지도와 D-pad 내비게이션

이렇게 만든 앱을 실행하면, 손님이 왔을 때 태양계 지도를 화면에 띄우고 각 행성에 대한 정보를 함께 보여줄 수 있습니다. 리모컨의 D-pad를 이용해 지도 위에서 행성들 사이를 이동하며 탐색할 수 있는 UI를 구성했습니다.

LED 제어: WLED와 fetch로 끝내는 하드웨어 연동

포치에 설치된 LED 조명은 WLED 컨트롤러로 제어됩니다. Vega 앱에서 별도의 복잡한 통신 레이어를 만들 필요 없이, 그냥 일반적인 fetch를 사용해 HTTP 명령을 WLED 컨트롤러에 직접 전송하는 방식으로 구현했습니다. 웹 개발자에게 익숙한 API 하나로 물리적인 조명까지 제어할 수 있다는 점이 인상적인 부분입니다.

마지막 디테일: 음성으로 행성 호출하기

프로젝트에 화룡점정을 찍기 위해, 사람이 행성 이름을 말하면 화면과 조명에 해당 행성이 표시되는 기능을 추가했습니다. 이 부분이 놀라울 정도로 간단했는데, UI 요소에 aria label만 추가해주면 Vega가 음성 인식과 관련된 나머지 작업을 전부 처리해줍니다. 사용자가 행성 이름을 말하면 Vega가 이를 인식해서 해당 요소에 대한 press 이벤트를 자동으로 발생시켜주는 구조입니다. 실제로 "Saturn"이라고 말하면 화면과 LED에 토성이 반응하는 모습을 시연했고, 이 기능 하나로 프로젝트의 완성도가 크게 올라갔다고 평가합니다.

정리

  • 이 프로젝트는 3D 프린팅 행성 모형 + 제어형 LED + 대형 프로젝션 스크린을 Amazon Vega 기반 Fire TV 앱으로 연동한 홈 IoT 사례입니다.
  • Vega의 UI 레이어가 React Native로 되어 있어, 기존 React/React Native 지식을 그대로 재사용할 수 있었고 개발 난이도가 예상보다 낮았습니다.
  • VS Code 확장, 로컬 시뮬레이터, CLI 프로젝트 생성 도구 등 개발 편의 기능이 잘 갖춰져 있으며, AI 코딩 에이전트도 React Native 문법에 익숙해 Vega 문서만 추가로 참고시키면 손쉽게 활용 가능합니다.
  • 하드웨어 제어는 WLED 컨트롤러에 일반 fetch로 HTTP 요청을 보내는 단순한 방식으로 구현했습니다.
  • 음성 제어는 별도의 음성 인식 로직 구현 없이 aria label만 붙이면 Vega가 자동으로 처리해주는 것이 핵심 편의 기능입니다.
  • React/React Native에 익숙한 프론트엔드 개발자라면 Vega를 통해 별도의 러닝커브 없이 TV 앱, 나아가 이런 스마트홈/IoT 프로젝트까지 확장할 수 있다는 것이 이 영상의 결론입니다.
💡
React/React Native 지식을 그대로 재사용해 TV 앱과 IoT 프로젝트까지 영역을 넓힐 수 있다는 점에서, 프론트엔드 개발자의 스킬셋 활용 범위가 얼마나 넓어질 수 있는지 보여주는 사례입니다.
