via React Blog
🔥오늘의 화제frontend

React Server Components의 페이로드 디코딩 결함으로 인해 인증 없이 원격 코드 실행이 가능한 취약점(CVE-2025-55182, CVSS 10.0)이 공개되었습니다. react-server-dom-webpack, parcel, turbopack의 19.0~19.2.0 버전이 영향을 받으며, Next.js, React Router, Waku, Redwood SDK 등 주요 RSC 프레임워크도 함께 영향을 받습니다. React 팀은 즉시 패치된 버전으로 업그레이드할 것을 권고했으며, 이후 DoS 및 소스 코드 노출 관련 취약점도 추가로 발견되었습니다.

💡
React Server Components 기반 프레임워크를 사용하는 프로덕션 서비스라면 인증 없이 원격 코드 실행이 가능한 최고 위험도 취약점에 노출될 수 있으므로, 사용 중인 패키지와 프레임워크 버전을 즉시 점검하고 업그레이드해야 합니다.

via Kevin Powell (CSS)
▶영상frontend

폰트는 악센트와 디센더를 위한 여유 공간을 상하에 내장하고 있어, 동일한 패딩을 줘도 위아래 여백이 다르게 느껴지고 폰트마다 그 차이도 다릅니다. Figma의 Vertical Trim 옵션 때문에 디자이너 스펙과 실제 CSS 구현 사이에 괴리도 자주 생겼습니다. 이제 Firefox까지 지원하면서 모든 주요 브라우저에 탑재된 text-box-trim(및 text-box-edge, 축약형 text-box)을 사용하면 캡 높이와 알파벳 베이스라인 기준으로 폰트 메트릭 여백을 직접 잘라낼 수 있습니다.

💡
매직 넘버로 여백을 맞추거나 폰트 변경 때마다 패딩을 재조정해야 했던 고질적인 문제를, 표준 CSS 속성 하나로 근본적으로 해결할 수 있어 디자인 스펙 재현 정확도와 유지보수성이 크게 개선됩니다.

via Jack Herrington
▶영상frontend

저자는 3D 프린팅한 행성 모형과 제어형 LED로 포치를 태양계 전시 공간으로 꾸미고, 이를 대형 프로젝션 스크린과 연동하기 위해 Amazon의 Vega(React Native 기반 Fire TV 플랫폼)를 활용했습니다. VS Code 확장과 로컬 시뮬레이터, CLI 툴 덕분에 개발이 예상보다 쉬웠고, WLED 컨트롤러에 HTTP fetch로 LED를 제어했습니다. 음성으로 행성 이름을 부르면 화면과 조명이 반응하는 기능은 aria label만 추가하는 것으로 간단히 구현됐습니다.

💡
