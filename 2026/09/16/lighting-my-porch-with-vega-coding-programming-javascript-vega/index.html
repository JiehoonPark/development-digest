React Native로 포치 조명 제어하기: Amazon Vega로 만든 태양계 프로젝트

Lighting My Porch With Vega #coding #programming #javascript #vega

📅 2026-09-16📰 Jack Herrington🎬 Video
frontend

천체에 진심인 가족을 위해 직접 3D 프린팅한 행성 모형들을 포치 뒤편에 줄지어 세우고, 제어 가능한 LED로 조명까지 연출한 개인 프로젝트를 소개합니다. 여기에 거실의 대형 프로젝션 스크린까지 연동하고 싶었던 저자가 Amazon Vega를 선택하게 된 계기와 실제 개발 경험을 짧게 정리했습니다.

왜 Vega였나

영화를 볼 때 포치의 행성 조명들이 켜져 있으면 분위기가 정말 좋았는데, 여기에 만족하지 않고 대형 프로젝션 스크린과 행성 조명을 연동하고 싶었다고 합니다. 그래서 여러 옵션을 찾아보다가 Amazon Fire Stick용 플랫폼인 Vega를 선택했는데, 이유는 단순합니다. Vega의 UI가 React Native 기반이기 때문입니다. 평소 React와 React Native에 익숙했던 저자 입장에서는 자연스러운 선택이었습니다.

실제로 써보니 예상보다 훨씬 수월했다고 합니다.

개발 경험: VS Code 확장과 로컬 시뮬레이터

Vega는 VS Code용 확장 프로그램을 제공하는데, 여기에 포함된 로컬 시뮬레이터 덕분에 코드를 디버깅하기가 굉장히 쉬웠다고 합니다. 별도의 실기기 없이도 개발 사이클을 빠르게 돌릴 수 있었던 셈입니다.

여기에 더해 AI 코딩 에이전트들이 React Native 코드를 다루는 데 이미 능숙하다는 점도 큰 도움이 됐습니다. Vega만의 특수한 부분은 공식 문서를 에이전트에게 그대로 참조시키는 것만으로 충분히 커버할 수 있었다고 합니다. 프로젝트 시작을 위한 CLI 도구도 제공되어 초기 세팅 과정 자체도 간단했습니다.

실제 구현: 태양계 지도와 LED 연동

이렇게 만든 앱으로 손님들이 놀러 오면 화면에 태양계 지도를 띄우고, 각 행성에 대한 정보를 함께 보여줄 수 있게 됐습니다. 리모컨의 D-pad로 화면 속 행성들과 포치의 실제 조명 사이를 오가며 탐색하는 방식입니다.

LED 제어에는 WLED 컨트롤러를 사용했고, Vega 앱에서 일반적인 fetch로 HTTP 요청을 직접 보내는 방식으로 조명을 제어했습니다. 별도의 복잡한 통신 계층 없이, 웹 개발에서 익숙한 방식 그대로 하드웨어 제어까지 연결한 것입니다.

화룡점정: 음성 인식

마지막으로 프로젝트를 한층 더 완성도 있게 만들어준 기능은 음성 제어였습니다. 사용자가 행성 이름을 말하면 화면과 조명에 해당 행성이 표시되도록 하고 싶었는데, 구현은 놀랍도록 간단했습니다. 컴포넌트에 aria label만 추가하면 나머지 음성 처리는 전부 Vega가 알아서 처리해주고, 사용자가 이름을 말하면 press 이벤트로 전달해줍니다. 예를 들어 "Saturn"이라고 말하면 실제로 해당 행성으로 포커스가 이동하는 식입니다. 이 기능 하나로 프로젝트 전체의 완성도가 크게 올라갔다고 합니다.

정리

  • Amazon Vega는 React Native 기반 UI를 사용하기 때문에, 기존 React/React Native 경험을 그대로 활용해 Fire Stick용 애플리케이션을 만들 수 있습니다.
  • VS Code 확장과 로컬 시뮬레이터가 제공되어 실기기 없이도 빠르게 디버깅할 수 있고, CLI로 프로젝트 초기 설정도 간단합니다.
  • AI 코딩 에이전트가 React Native에 익숙한 만큼, Vega 공식 문서만 추가로 참조시키면 개발 생산성을 그대로 이어갈 수 있습니다.
  • 하드웨어 제어(WLED)는 일반 fetch HTTP 요청으로, 음성 인식은 단순히 aria-label을 붙이는 것만으로 구현 가능해, 웹 표준에 가까운 접근 방식으로 확장 기능까지 손쉽게 붙일 수 있습니다.
  • React/React Native 경험이 있는 개발자라면 TV/대형 화면용 애플리케이션 제작에 Vega를 진입장벽 낮은 선택지로 고려해볼 만합니다.
