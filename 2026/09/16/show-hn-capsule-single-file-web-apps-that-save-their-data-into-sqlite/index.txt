15:T156d,<h3>도입</h3>
<p>클라우드 계정도, 서버도, 로그인도 없이 &quot;파일 하나&quot;로 완결되는 앱을 만들 수 있다면 어떨까요? Hacker News에 올라온 Capsule은 이 질문에 대한 실험적인 답을 내놓습니다. UI와 데이터를 하나의 <code>.capsule</code> 파일에 몽땅 담아, PDF나 워드 문서처럼 전송하고 실행할 수 있게 만든 프로젝트인데요. 여기에 AI 프롬프트로 앱을 즉석에서 생성하고 수정하는 기능까지 결합해, &quot;문서&quot;와 &quot;앱&quot;의 경계를 지우려 하고 있습니다.</p>
<h3><code>.capsule</code> 파일이란 무엇인가</h3>
<p>Capsule의 핵심 아이디어는 단순합니다. 앱을 구성하는 세 가지 요소 — HTML로 만든 UI, 로컬 SQLite 데이터베이스, 그리고 스키마 — 를 하나의 포터블 파일 컨테이너에 패키징하는 것입니다. 이렇게 만들어진 <code>.capsule</code> 파일은 서버나 클라우드 계정 없이도 그 자체로 완전한 애플리케이션으로 동작합니다.</p>
<p>사용 시나리오는 문서 공유와 다르지 않습니다. WhatsApp, AirDrop, 이메일 등 어떤 채널로 전송해도 되고, 수신자가 파일을 탭하면 곧바로 실행되면서 안에 담긴 데이터가 그대로 로드됩니다. 예시로 제공되는 &quot;Summer Recipes.capsule&quot;이나 &quot;Portfolio.capsule&quot; 같은 파일들이 이 개념을 잘 보여줍니다. 3.2MB 용량의 포트폴리오 파일 안에 24개의 프로젝트와 케이스 스터디, 에셋이 통째로 들어 있는 식입니다.</p>
<h3>AI로 앱을 생성하고 즉시 수정하기</h3>
<p>Capsule은 단순 실행기를 넘어, AI를 이용한 앱 생성 파이프라인을 제공합니다. 과정은 세 단계로 나뉩니다.</p>
<p><strong>1단계, 프롬프트로 아이디어 전달</strong> — 만들고 싶은 애플리케이션, 레이아웃, 기능을 자연어로 설명합니다.</p>
<p><strong>2단계, 즉시 Capsule 앱 생성</strong> — HTML UI, 스키마, 로컬 SQLite 데이터를 포함한 완전한 단일 파일 <code>.capsule</code> 컨테이너가 만들어집니다.</p>
<p><strong>3단계, 실시간 반복 수정</strong> — 다크 모드 추가, 스키마 변경 같은 기능 수정을 AI 프롬프트나 MCP 코딩 도구를 통해 즉석에서 적용할 수 있습니다.</p>
<p>이 과정은 ChatGPT, Claude, Gemini 등 원하는 AI 어시스턴트를 선택해 시작할 수 있으며, 별도의 클라우드 서버 구축이나 데이터베이스 설정, 복잡한 빌드 환경 구성 없이 결과물을 바로 얻을 수 있다는 점이 강조됩니다.</p>
<h3>완전한 프라이버시, 완전한 오프라인</h3>
<p>Capsule이 내세우는 또 다른 축은 프라이버시입니다. 앱에서 생성되는 모든 데이터 — 할 일 목록, 레시피 메모, 프로젝트 로그 등 — 는 파일 안에 직접 저장됩니다. 클라우드 저장소도, 계정 등록도, 네트워크 연결 요구사항도 없습니다.</p>
<p>이는 곧 완전한 오프라인 동작을 의미합니다. 비행기 안이든 지하철이든, 네트워크가 완전히 끊긴 환경에서도 앱에 접근할 수 있습니다. 데이터는 단일 파일 안에 안전하게 격리되어 있어 서버 침해(breach) 위험 자체가 존재하지 않는다는 점도 장점으로 제시됩니다.</p>
<h3>크로스플랫폼, 벤더 락인 없음</h3>
<p><code>.capsule</code> 파일은 기본적으로 크로스플랫폼을 지향합니다. 동일한 파일을 macOS, Windows, Linux에서 변환이나 별도 설정 없이 그대로 열 수 있고, 각 운영체제에서 네이티브 데스크톱 수준의 성능으로 실행됩니다. iOS와 Android 지원은 현재 준비 중(coming soon)입니다.</p>
<p>기술적으로도 Capsule은 표준 HTML과 CSS를 사용하기 때문에, 코드와 데이터에 대한 소유권이 전적으로 사용자에게 있고 특정 클라우드 사일로에 종속되지 않습니다. 즉 특정 벤더의 런타임이나 포맷에 갇히지 않는 구조를 지향한다는 것이 프로젝트 측의 설명입니다.</p>
<p>현재 macOS용 다운로드와 웹 프리뷰(Web Preview)를 통해 체험해볼 수 있으며, 다른 플랫폼용 다운로드도 별도로 제공되고 있습니다.</p>
<h3>정리</h3>
<ul>
<li>Capsule은 UI(HTML)와 로컬 SQLite 데이터베이스, 스키마를 하나의 <code>.capsule</code> 파일로 묶어 클라우드나 계정 없이 실행·공유할 수 있게 만든 프로젝트입니다.</li>
<li>ChatGPT, Claude, Gemini 같은 AI 어시스턴트에 프롬프트를 입력하면 완전한 단일 파일 앱이 생성되고, 이후 다크 모드나 스키마 변경 같은 수정도 AI 프롬프트나 MCP 도구로 실시간 반영됩니다.</li>
<li>데이터가 파일 내부에만 저장되므로 완전한 오프라인 동작과 서버 침해로부터 자유로운 프라이버시를 보장하며, macOS·Windows·Linux에서 변환 없이 동일 파일을 실행할 수 있는 크로스플랫폼 구조를 갖췄습니다(iOS/Android는 준비 중).</li>
<li>프론트엔드 개발자 입장에서는 &quot;웹 기술(HTML/CSS) + 로컬 DB(SQLite)&quot;만으로 서버리스 배포·공유가 가능한 애플리케이션 형태를 제시한다는 점에서, 문서처럼 가볍게 배포되는 미니 앱 아키텍처의 한 사례로 참고할 만합니다.</li>
