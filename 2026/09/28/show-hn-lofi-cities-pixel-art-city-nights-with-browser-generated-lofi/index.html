Show HN: 브라우저에서 실시간으로 로파이 음악을 생성하는 픽셀아트 도시 앱

Hacker News Top에 올라온 [Lofi Cities](https://loficities.com/)는 픽셀아트로 그린 도시 야경 애니메이션과, 브라우저에서 실시간으로 작곡되는 로파이 음악을 결합한 무료 웹앱입니다. 흔히 보는 "로파이 스트리밍 라디오"와 다른 점은 음악이 미리 녹음된 샘플이 아니라 Web Audio API로 그 자리에서 합성된다는 것인데요. 설치도, 계정도, 팝업도 없이 스터디/작업용 배경으로 쓸 수 있게 만든 이 프로젝트의 구조를 기술적인 관점에서 살펴보겠습니다.

4분 루프의 픽셀아트 씬

각 도시는 480×270 해상도의 픽셀 애니메이션으로, 4분마다 이음매 없이 루프됩니다. 파리의 아연 지붕 아래 화가의 다락방, 도쿄의 네온사인과 벚꽃, 브루클린 다리 옆의 눈 내리는 밤, 템스강의 안개와 웨스트민스터, 리우의 코파카바나 발코니 등 총 16개 도시가 제공됩니다(파리, 도쿄, 뉴욕, 런던, 리우데자네이루, 이스탄불, 홍콩, 시드니, 샌프란시스코, 함부르크, 암스테르담, 두바이, 마드리드, 로마, 프라하, 뮌헨). 각 씬마다 고유한 날씨, 랜드마크, 도시 소음이 붙어 있어 단순한 배경 이미지가 아니라 하나의 "장소"처럼 느껴지도록 설계되어 있습니다.

Web Audio API로 실시간 작곡하기

이 프로젝트의 핵심은 음악이 샘플이나 녹음본 없이 전부 실시간 합성된다는 점입니다. 트랙마다 다음 요소들을 그 자리에서 생성합니다.

  • 코드 진행(chord progression)
  • 드럼 그루브
  • 베이스 라인
  • (종종) 멜로디
  • 테이프 워블과 바이닐 크랙클 같은 텍스처 이펙트

이렇게 만들어지기 때문에 스트림이 절대 고갈되지 않습니다. Vibe 패널에서 스타일을 고를 수 있는데, 제공되는 프리셋은 다음과 같습니다.

  • jazzhop (기본값): 로즈 전자피아노, 재지한 코드, 68~88 BPM의 스윙 붐뱁 비트
  • piano: 나른한 펠트 피아노 + 부드러운 드럼
  • ambient: 거의 비트가 없는 느린 웜 패드 (수면/딥포커스용)
  • bossa: 나일론 기타 + 보사노바 그루브
  • synth: 80년대 시티팝 신스
  • house: 소프트한 four-on-the-floor 킥의 로파이 딥하우스
  • guitar: 나른한 비트 위 핑거피킹 클린 일렉기타
  • sad: 느린 마이너 코드 + 외로운 뮤트 트럼펫
  • medieval: 류트와 리코더 + 손드럼

스타일 전환은 즉시 반영되지 않고 다음 트랙부터 적용됩니다. 여기에 더해 무드(chill: 더 느리고 어둡게 / upbeat: 더 빠르고 밝게)와 밴드 구성(풀 밴드 / 드럼 없이 / 코드만)까지 조합할 수 있어, 실질적으로 상당히 많은 변주를 만들어낼 수 있는 구조입니다.

트랙 제목은 현재 화면의 도시에서 영감을 받아 지어지고, 별도의 앰비언스 레이어가 그 도시의 소리(비, 교통, 종소리 등)를 음악 아래 믹싱합니다. Up next 목록으로 다음 곡을 미리 보고 바로 재생할 수 있고, 음악과 도시 소리는 각각 독립된 볼륨 슬라이더를 가지며, 도시 소리 믹서는 한 단계 더 들어가 소리 종류별(비, 교통, 종소리 등) 슬라이더를 제공합니다. 이 설정은 같은 소리를 가진 다른 도시에도 그대로 이어집니다. Weather 칩(W)을 누르면 비/눈/낙엽/맑음을 어느 도시에나 적용할 수 있고, 도시 소리와 트랙 제목도 여기에 맞춰 따라갑니다.

인터랙션과 실시간 소셜 기능

키보드 단축키가 상당히 풍부하게 설계되어 있습니다.

  • F: 전체화면
  • H: UI 숨기기
  • P: 미니 플레이어 (Picture-in-Picture로 다른 앱 위에 씬을 띄움, 지원 브라우저 한정)
  • V: Vibe 변경
  • C: Tour(도시 자동 전환) 토글
  • W: 날씨 변경
  • T: 타이머
  • L: 종이 초롱 띄우기
  • Enter: 채팅
  • S: 스크린샷 저장
  • /: 도시 선택기

컨트롤은 마우스가 멈추면 자동으로 페이드아웃됩니다. Tour 기능은 5/10/15/30분마다 다음 도시로 넘어가거나, "night" 모드로 설정하면 현지시각 새벽 1시에 가장 가까운 도시를 자동으로 보여주며 시드니에서 샌프란시스코로 서쪽으로 이동합니다. 파리·함부르크·암스테르담처럼 같은 시간대 도시는 서로 순번을 바꿔가며 노출됩니다.

흥미로운 부분은 익명 기반의 실시간 소셜 레이어입니다. 도시 이름 아래 알약 모양 인디케이터에 "23 here now · 5 in Tokyo · 480 today · 12,345 all time" 같은 형태로 실시간 접속자, 현재 도시 접속자, 오늘 방문자, 누적 방문자를 보여줍니다. 같은 도시에 있는 사람들과는 하트/노트/별/달 아이콘으로 반응을 남기거나(Together 버튼, G), 씬을 탭해 아이콘을 띄우거나, 종이 초롱(L)을 날려 약 1분간 도시 위에 떠 있게 할 수 있습니다. 이 초롱은 모두에게 같은 위치에서 보이고, 떠 있는 동안 새로 들어온 사람에게도 보입니다. 채팅은 80자 이내, 링크 불가, "sleepy fox" 같은 랜덤 두 단어 닉네임으로 이루어집니다.

프라이버시 설계

계정도 쿠키도 없습니다. 브라우저의 로컬 스토리지(쿠키 아님)에 랜덤 ID를 저장해 같은 브라우저의 여러 탭을 한 사람으로 카운트하고, 서버는 마지막 방문 후 약 25시간이 지나면 이 ID를 잊습니다. 다른 사람에게는 오직 두 단어 닉네임만 보입니다. 누적 방문자 수는 단일 숫자로만 집계되어 누가 언제 방문했는지는 서버가 알 수 없는 구조입니다. "오늘" 기준은 클라이언트가 서버에 전달하는 로컬 자정 기준이며, 이 정보 역시 세션 종료 시 사라집니다. 서버가 유지하는 건 공중에 떠 있는 초롱과 도시별 최근 30개 채팅 메시지(최대 1시간) 정도입니다. Do Not Track을 보내는 브라우저는 통계 집계에서 제외됩니다(단 실시간 접속자 수에는 익명으로 카운트됨).

PWA, 오프라인, OBS 연동

한 번 온라인 상태에서 열어두면 이후 오프라인에서도 동작합니다. 도시 씬과 음악 모두 브라우저에서 생성되는 것이라 별도의 미디어 파일을 스트리밍할 필요가 없기 때문인데요. 브라우저의 "설치" 또는 "홈 화면에 추가" 옵션으로 앱처럼 설치할 수도 있습니다.

방송 도구용 연동도 지원합니다. OBS의 브라우저 소스를 1920×1080으로 설정하고 도시 페이지 주소 뒤에 ?obs를 붙이면(예: https://loficities.com/tokyo/?obs), UI가 자동으로 숨겨지고 음악이 바로 재생됩니다. "Control audio via OBS"를 체크하면 오디오를 믹스에 포함시킬 수 있고, 화살표 키로 도시 전환, N으로 트랙 스킵, W로 날씨 변경, 혹은 URL에 &weather=snow 같은 쿼리를 추가해 제어할 수 있습니다.

모바일 세로 화면에서는 랜드마크와 광고판이 항상 보이도록 배치되고, 씬을 좌우로 드래그해 둘러보거나 끝까지 스와이프하면 다음 도시로 전환됩니다.

비즈니스 모델: 광고판과 영상 판매

무료 웹 서비스지만 두 가지 수익화 지점이 있습니다.

  • 광고판 임대: 각 도시 씬에는 렌트 가능한 광고판이 있고, 비어 있는 동안은 가상의 지역 광고가 걸립니다. 원하는 브랜드는 짧은 폼(tally.so)을 통해 신청하면 같은 픽셀아트 스타일로 손으로 그려서 넣어줍니다.
  • 영상 루프 판매: Gumroad를 통해 16개 도시 전체를 AI 보조로 제작한 4분 길이, 1920×1080, 60fps MP4 루프(오디오 없음)로 구매할 수 있습니다. 개인 사용 및 유튜브/라이브스트림 배경(수익화 콘텐츠 포함)으로 사용 가능하며, 제품 페이지에 명시된 대로 Lofi Cities 크레딧 표기가 조건입니다. 사이트에서 실제로 들리는 음악과 도시 소리는 이 다운로드에는 포함되지 않습니다.

제작자는 Safa Elmali이며, Buy Me a Coffee로 후원을 받고 있고 X(트위터)를 통해 신규 도시 요청을 받습니다. 실제로 초기 6개 도시 이후 홍콩, 시드니, 샌프란시스코, 함부르크, 암스테르담이 추가되었고, 이어서 두바이, 마드리드, 로마, 프라하, 뮌헨이 합류하며 지속적으로 라인업이 늘고 있습니다.

정리

Lofi Cities는 겉으로 보면 흔한 "로파이 배경음악 사이트"처럼 보이지만, 몇 가지 지점에서 프론트엔드 엔지니어링 관점의 재미있는 포인트가 있습니다.

  • 오디오 합성의 완전한 클라이언트 사이드화: 미디어 파일 스트리밍 없이 Web Audio API만으로 코드/드럼/베이스/멜로디를 실시간 생성해, 무한한 트랙과 오프라인 동작을 동시에 확보한 구조입니다.
  • 프라이버시 우선 실시간 기능: 계정·쿠키 없이 로컬 스토리지의 랜덤 ID와 서버 측 TTL(25시간, 1시간 등)만으로 실시간 접속자 수, 채팅, 리액션 같은 소셜 기능을 구현했습니다. 익명성과 상호작용을 동시에 만족시키려는 설계가 눈에 띕니다.
  • PWA + OBS 연동을 통한 배포 다변화: 오프라인 캐싱, 홈 화면 설치, PIP 미니 플레이어, OBS 브라우저 소스 파라미터(?obs, &weather=)까지 지원해 스트리머·크리에이터 워크플로우까지 겨냥하고 있습니다.
  • 수익화와 무료 서비스의 분리: 핵심 웹 경험은 완전 무료로 유지하면서, 광고판 삽입과 오디오 없는 영상 루프 판매(Gumroad)로 별도 수익원을 분리한 구조는 사이드 프로젝트를 지속 가능하게 만드는 참고할 만한 모델입니다.

프론트엔드 개발자 입장에서는 "브라우저에서 무엇을, 어디까지 실시간 생성할 수 있는가"를 실험해보는 좋은 레퍼런스로 볼 만한 프로젝트입니다.

💡
미디어 파일 없이 브라우저만으로 무한한 음악을 실시간 생성하고, 계정 없이 프라이버시를 지키면서도 실시간 소셜 기능을 구현한 사례로, Web Audio API와 로컬 스토리지 기반 아키텍처 설계에 관심 있는 프론트엔드 개발자에게 좋은 참고가 됩니다.
