OpenAI fights back

📅 2026-09-30📰 Theo (t3.gg)🎬 Video
frontendai

앤트로픽이 지난주 Opus 5.5를 내놓으며 업계를 뒤흔들자, OpenAI는 GPT6 Soul과 GPT6 Luna를 서둘러 출시했습니다. 하지만 두 모델 모두 인상적이지 않았고, 별다른 반응을 이끌어내지 못했습니다. 그런데 여기서 끝이 아니었습니다. 필자가 우연히 얼리 액세스로 미리 사용해본 세 번째 모델, GPT 6.1 Soul이 등장했고, 이 모델이 지금까지의 흐름을 완전히 뒤집어놓았습니다. 저렴하면서도 강력하고, 심지어 Astra보다도 낫다는 평가가 나올 정도입니다. 이 글에서는 GPT 6.1 Soul의 벤치마크 성능, 파격적인 가격 정책, 그리고 그 이면에 숨은 출시 배경을 정리해봅니다.

(참고로 필자는 얼리 액세스 권한을 받았지만 어떤 형태로든 대가를 받지 않았고, OpenAI는 콘텐츠 내용에는 개입하지 않았습니다. 다만 공개 시점만큼은 모델 출시 전까지 기다려달라는 요청을 받았습니다.)

벤치마크: 사실상 역대 최고 점수

필자는 Terminal Bench를 직접 돌려봤는데, 벤치마크 환경 자체가 워낙 무거워서 세 번을 실행하고 나서야 제대로 된 결과를 얻을 수 있었다고 합니다. low, high, X-high, max 난이도로 테스트했고 medium은 초기에 빠뜨렸으며, max 실행은 8시간 이상 걸리는 탓에 여전히 진행 중이라 일부 점수는 X-high 결과로 임시 대체해둔 상태입니다. H100 GPU가 필요한 태스크 3개는 아예 벤치마크에서 제외했다고 밝혔습니다.

이런 한계에도 불구하고 결과는 명확했습니다. GPT 6.1 Soul은 Terminal Bench에서 사실상 역대 최고 점수를 기록했습니다. DeepSWE 벤치마크에서는 조금 특이한 패턴을 보였는데, X-high와 max 난이도에서는 점수가 오히려 떨어지고 low와 high에서는 점수가 유지되는 모습이었습니다. 그런데 이 low/high 점수가 Opus 5.5가 max 난이도에서 낸 점수와 비슷했다는 점이 핵심입니다. 문제는 비용인데, 로그 스케일 그래프로 보면 차이가 확연합니다.

  • GPT 6.1 Soul (low): 약 $0.21
  • Astra (low): $1.46
  • Opus 5.5 (max, 동일 점수): $14.65

즉 DeepSWE에서 Opus와 동일한 점수를 내면서 비용은 73배나 저렴했다는 이야기입니다. 물론 DeepSWE 하나로 모델의 실전 코딩 능력을 온전히 판단할 수는 없지만, 이 정도 비용 차이는 무시하기 어려운 수준입니다.

정체를 알 수 없는 출시 타이밍

GPT6 Soul이 지난주 화요일에 나왔는데, 이번 GPT 6.1 Soul도 화요일에 출시됩니다. 딱 일주일 간격입니다. 필자는 이 타이밍이 의미심장하다고 봅니다. 원래 6.1 Soul은 애초에 "6.1 Soul"이라는 이름으로 나올 예정이 아니었을 가능성이 높다는 것입니다.

근거는 몇 가지입니다. 첫째, 6.1은 GPT6 대비 확연히 더 똑똑해서 단순한 마이너 업데이트로 보기 어렵습니다. 둘째, 초당 토큰 생성 속도(TPS)가 눈에 띄게 느려졌는데, 이는 보통 모델 크기가 커졌다는 신호입니다. 즉 겉으로는 마이너 버전업처럼 보이지만 실제로는 근본적으로 다른, 더 큰 모델일 가능성이 있다는 뜻입니다.

여기에 결정적인 단서가 하나 더 있습니다. OpenAI의 Tibo가 모델 출시 직전에 올린 트윗인데, 핵심은 두 가지입니다. 하나는 $200짜리 Pro 구독제가 다시 돌아온다는 것이고, 더 중요한 건 구독 내 사용량 계산 방식을 바꾼다는 내용입니다. 계산해보면 기존 $200 Pro 플랜 대비 API 환산 사용량이 절반으로 줄어드는 셈입니다.

왜 하필 지금, 그것도 Opus 5.5가 워낙 뛰어나서 앤트로픽의 $200 Claude Code 플랜이 압도적인 가성비로 화제인 시점에 이런 조치를 취할까요? 필자의 추론은 이렇습니다. 새 모델의 마진이 예전만큼 좋지 않아서 보조금(subsidize)을 예전 수준으로 유지할 여력이 줄었다는 것입니다. 참고로 기존 $200 Claude Code 플랜에서는 한 달에 약 8,000~9,000달러어치 사용량을, $200 Codex 플랜에서는 12,000달러 이상의 사용량을 제공받을 수 있었습니다. 필자가 직접 계산해본 결과 Astra 쪽 사용량 한도도 약 8,000달러 수준으로 소폭 줄어든 것으로 보입니다.

파격적인 가격, 그리고 캐시 읽기 할인

GPT 6.1 Soul의 정가는 입력 토큰 100만 개당 $2, 출력 토큰 100만 개당 $10입니다. 이는 출시 당시 GPT 5.6 Soul보다 훨씬 저렴하고, 할인 적용 후 5.6 Soul 가격의 절반이며, GPT6 Soul과는 동일한 가격입니다. Astra와 비교하면 1/5 수준입니다.

하지만 진짜 이야기는 캐시 읽기(cache read) 가격에 있습니다. 이 모델의 캐시 읽기 가격은 100만 토큰당 10센트인데, OpenAI가 캐시 읽기 가격을 바꾼 건 이번이 처음입니다. 지금까지는 항상 일반 읽기 가격의 정확히 10%였는데(즉 90% 할인), 이번에는 그 절반인 5%(95% 할인)로 더 낮췄습니다. 실전 에이전트 워크로드에서는 캐시 읽기 비중이 압도적으로 크다는 점을 감안하면, 이는 실사용 비용을 대폭 낮추는 조치입니다.

이런 가격 인하는 자연스럽게 마진 축소로 이어집니다. 업계에서는 OpenAI의 마진율이 최대 95%에 달한다는 소문이 있습니다. 즉 $10을 받으면 실제 비용은 $0.50 수준이라는 것인데, 모델 훈련에 들어가는 막대한 비용을 생각하면 납득이 갑니다. 동시에 이 정도 마진이면 가격을 조정할 여유도 충분합니다. 만약 새 모델에서도 기존 구독 보조금 수준을 그대로 유지한다면, 구독료보다 실제 컴퓨팅(전기세에 비유한 표현) 비용이 더 커질 수 있다는 것이 필자의 추정입니다. 그래서 구독 사용량 계산 방식을 바꿀 수밖에 없었다는 논리입니다.

실전 코드 작업 비용으로 보면 차이는 더 직관적입니다. 필자가 실제로 돌려본 결과, GPT 6.1 Soul의 가장 비쌌던 실행이 태스크당 약 $1.38이었던 반면, Opus 5.5의 가장 저렴했던 실행은 $5.12였습니다. 즉 가장 저렴한 Opus와 가장 비싼 Soul 사이에도 4~5배의 비용 격차가 존재합니다.

GPT6 특유의 "똑똑한데 멍청한" 문제, 해결됐나

GPT6 Astra에 대해 필자가 가장 답답해했던 부분은 지능이 부족해서가 아니었습니다. 오히려 여러 면에서 앤트로픽의 최고 모델들보다 더 똑똑했습니다. 문제는 따로 있었습니다. Astra는 똑똑하면서 동시에 멍청했습니다. 잘 작동하다가도 갑자기 올해 본 것 중 가장 멍청한 실수를 저지르는 패턴이 반복됐고, 심지어 일부 소규모 오픈웨이트 모델보다도 못한 순간이 있었습니다. 잘할 때는 놀라울 정도로 잘하지만, 이런 스파이크성 오류 때문에 결국 실사용에서는 손을 뗄 수밖에 없었습니다. 그 결과 필자는 Codex 구독을 컴퓨터 사용(computer use) 용도로만 쓰고, 일상적인 코드 작업은 Fable 5.1과 Opus 5.5에 의존하게 됐다고 합니다.

그렇다면 GPT 6.1 Soul은 이 스파이크성 문제를 해결했을까요? 필자의 답은 "완전히는 아니지만, 대체로 그렇다"였습니다. 이전만큼 극단적인 오류 패턴은 줄어들었고, 전반적인 신뢰도가 개선됐다는 취지의 평가로 이어집니다.

정리

  • Anthropic의 Opus 5.5 출시 이후 OpenAI가 서둘러 내놓은 GPT6 Soul/Luna는 큰 반응을 얻지 못했지만, 뒤이어 나온 GPT 6.1 Soul은 Terminal Bench에서 사실상 역대 최고 점수를, DeepSWE에서는 Opus 5.5와 동급 점수를 73배 저렴한 비용으로 달성했습니다.
  • 출시 간격(1주일), 지능 향상 폭, 느려진 토큰 생성 속도를 종합하면 6.1 Soul은 단순한 스냅샷 업데이트가 아니라 근본적으로 다른(더 큰) 모델일 가능성이 높습니다.
  • 가격은 입력 $2/출력 $10 (100만 토큰당)로 책정됐고, 특히 캐시 읽기 가격을 사상 처음으로 절반(95% 할인)까지 낮춰 실전 에이전트 워크로드 비용을 크게 절감했습니다. 이는 OpenAI가 마진을 일부 포기하면서까지 가격 경쟁력을 확보하려는 신호로 해석됩니다.
  • 동시에 $200 구독 플랜의 사용량 계산 방식을 변경해 API 환산 가치가 절반으로 줄었는데, 이는 새 모델의 낮아진 마진과 맞물려 보조금 여력이 줄었기 때문으로 추정됩니다.
