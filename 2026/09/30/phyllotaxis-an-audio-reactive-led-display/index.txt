14:T337d,<p>자연에는 코드로 재현하고 싶어지는 패턴들이 있습니다. 해바라기나 다육식물 가운데에서 볼 수 있는 이중 나선 구조, 이른바 '필로탁시스(phyllotaxis)'도 그중 하나인데요. 이 글은 한 메이커가 이 수학적 패턴을 코드로 구현하는 데서 출발해, 실제로 만질 수 있는 오디오 반응형 LED 디스플레이로 완성해가는 과정을 담고 있습니다. Processing 스케치로 시작한 프로젝트가 CadQuery를 이용한 3D 모델링, STM32 기반 LED 드라이버, FFT 오디오 분석, 그리고 결국 PCB 설계와 Rust 펌웨어까지 이어지는 여정을 순서대로 살펴보겠습니다.</p>
<h3>필로탁시스 패턴을 코드로 그려보기</h3>
<p>필로탁시스는 원 위의 점들을 방사형으로 배치하되, 각 점을 황금비의 배수만큼씩 회전시켜 얻는 패턴입니다. 놀라울 만큼 단순한 코드로 구현할 수 있는데요.</p>
<pre><code>// Inner and outer are throw-away,
// just for spacing the cells that are used
float[][] points = new float[numCells + numOuter + numInner][2];
float outerRadius = width / 2;
final int total = numCells + numInner + numOuter;
for (int i = 0; i &lt; total; i++)
{
float f = i / float(total);
float a = i * 1.6180339887;
float distance = f * outerRadius;
float x = -cos(a * TWO_PI) * distance;
float y = sin(a * TWO_PI) * distance;
points[i][0] = x;
points[i][1] = y;
}</code></pre>
<p>원의 반지름 위에 놓인 일련의 점들을 골든 레이쇼(1.6180339887)의 증가하는 배수만큼 회전시키는 것이 핵심입니다. 이렇게 얻은 점 구름은 이미 해바라기와 매우 흡사한 모양을 이루고요, 여기에 Voronoi 테셀레이션을 적용하면 씨앗 꼬투리 같은 독특한 형태가 만들어집니다.</p>
<h3>디지털 패턴을 물리적 오브젝트로</h3>
<p>이 패턴을 한동안 가지고 놀던 저자는 문득 이런 생각을 떠올립니다. &quot;이걸 실제 물건으로 만들고, 각 셀마다 RGB 어드레서블 LED를 하나씩 넣으면 어떨까?&quot; 일종의 셀룰러 LED 매트릭스인 셈이죠. 고등학교 시절 사각형 네오픽셀 매트릭스를 만들어본 경험이 있었던 그는, 다음 프로젝트로 좀 더 흥미로운 형태를 찾고 있었다고 합니다.</p>
<p>Processing 스케치에서 셀 경계 데이터를 추출한 뒤, CadQuery 라이브러리를 사용하는 파이썬 스케치로 옮겨와 실제 물리적 형상을 만드는 코드를 작성했습니다.</p>
<pre><code># Create the negative space of a single cell
# shrunk with a negative offset-2d
cell_shape = (cq.Workplane(&quot;XY&quot;)
.polyline(vertices)
.close()
.offset2D(-wall_thickness/2, kind='intersection')
.extrude(total_height)
.translate((0, 0, base_height)))
# Cut it out of the total to create a shell with walls
total_shape = total_shape.cut(cell_shape)
# Cut the shape of the hole to fit the LED in the center of the cell
total_shape = total_shape.cut(
led_hole.rotate((0, 0, 0), (0, 0, 1), math.degrees(angle))
.translate((centerX, centerY, 0)))</code></pre>
<p>전체 Voronoi 셀을 합친 볼륨을 만든 다음, 각 셀을 살짝 줄인 형상을 빼내 벽이 있는 셸(shell) 구조를 만들고, 각 셀 중앙에는 LED가 들어갈 구멍을 뚫는 방식입니다. 이 작업을 모든 셀에 반복하면 완성된 노란색 형상을 얻게 됩니다. 이때 3D 프린터 베드에 맞도록 전체 형상을 대략 균등한 네 개의 조각으로 나눴다고 합니다.</p>
<p>STEP 파일로 내보낸 뒤 FreeCAD에서 나사 구멍을 추가하고, 그 아래 종이를 붙일 수 있도록 얇은 '페이스플레이트' 버전을 만드는 후처리 작업을 거쳤습니다. 얇은 버전 아래에 종이를 잘라 붙이고, 나사 구멍을 이용해 셀 벽에 나사로 고정하는 방식입니다. 빛을 잘 확산시키면서도 유기적이고 재미있는 느낌을 주는 반투명 종이를 찾다가 뽕나무 종이(mulberry paper)의 아름다운 섬유 질감에 반해 이를 사용했다고 합니다.</p>
<h3>LED 배선과 셰이더 스타일 패턴 코드</h3>
<p>89개의 LED를 손으로 납땜하는 작업은 다소 지루했지만, 어느 순간 몰입 상태(flow)에 들어가 오히려 편안했다고 회고합니다. 이렇게 완성한 회로를 여분으로 가지고 있던 STM32 블랙필(blackpill) 보드에 연결하고, SPI를 이용한 간단한 네오픽셀 드라이버를 직접 작성했습니다. 기본적인 테스트 패턴만으로도 이미 근사한 결과물이 나왔죠.</p>
<p>이어서 Processing 스타일의 '셰이더' 코드를 LED용으로 작성할 수 있는 간단한 스케치 프레임워크를 구축했습니다. 모든 LED의 위치를 단위원 위의 부동소수점 좌표로 미리 계산해둔 룩업 테이블을 이용해, 마치 프래그먼트 셰이더처럼 느껴지는 코드를 쓸 수 있게 되었는데요.</p>
<pre><code>void radial_spirals(LEDBuffer leds) {
for (int i = 0; i &lt; NUM_LEDS; i++) { // iterate every cell
// Get LED position from LUT
float x = led_positions[i][0];
float y = led_positions[i][1];
// Polar coordinates
float r = sqrtf(x*x + y*y);
float theta = atan2f(y, x); // Angle in radians [-π, π]
// Spiral pattern: combine angle and radius
float spiral = sinf(theta * 2.0f + r * 5.0f - seconds * 2.0f);
float brightness = (spiral + 1.0f) * 0.5f;
uint8_t level = (uint8_t)(brightness * 255.0f);
leds[i] = rgb(level, 0, 0);
}
}</code></pre>
<p>이런 식으로 여러 패턴을 실험하던 중, 중심에서 바깥으로 밝기가 맥동하듯 퍼져나가는 사인파 패턴이 가장 마음에 들었다고 합니다. 이 방사형 패턴은 이후 오디오 반응 스케치의 핵심 기능으로 쓰이게 됩니다.</p>
<h3>오디오 반응 기능 추가하기</h3>
<p>미리 정해진 패턴만 재생하는 대신, 방 안의 소리에 실시간으로 반응한다면 훨씬 생동감 있지 않을까 하는 생각으로 오디오 반응 기능을 추가하기로 합니다. 마침 LED를 구동하던 STM32 보드가 부동소수점 연산과 ARM DSP 명령어를 지원했기 때문에, 보드 자체에서 푸리에 변환과 오디오 분석을 수행할 수 있었습니다.</p>
<p>디지털 I2S 마이크인 INMP441을 브레드보드 회로에 추가했는데, 디지털 신호를 출력하는 마이크라 아날로그 노이즈 걱정 없이 쉽게 배선할 수 있었다고 합니다. ARM CMSIS 라이브러리를 활용해 오디오 신호를 처리하고 분석했으며, 오토게인 컨트롤과 멀티밴드 분할을 통해 서로 다른 주파수 대역의 에너지를 분석하는 기반을 마련했습니다.</p>
<p>전역 타이머와 복잡한 상태값이 뒤섞인, 다소 어수선한 스케치였지만 많은 튜닝을 거쳐 완성한 오디오 반응 프로그램은 지금까지도 보드에서 구동되는 기본 로직으로 남아 있습니다. Jon Hopkins의 'Neon Pattern Drum'을 재생했을 때 이 디스플레이가 비로소 살아 움직이는 듯한 느낌을 받았다고 합니다.</p>
<h3>마무리 작업</h3>
<p>이제 남은 건 몇 가지 디테일뿐이었습니다. 좀 더 견고한 마운트 표면이 필요했는데, 대나무 도마를 원형으로 라우팅해 사용했더니 천연 대나무 결이 유기적인 종이 질감과 잘 어우러졌습니다.</p>
<p>초기에는 컨트롤러 MCU와 마이크를 퍼프보드(perfboard)에 조립해 기타 페달 스위치가 달린 3D 프린트 박스에 넣었는데, 배선이 어수선해서 박스를 움직일 때마다 노이즈로 인한 LED 깜빡임이 발생했습니다. 이를 계기로 PCB 설계를 직접 배우기로 결심했고, 블랙필 보드와 마이크, 버튼을 장착하고 5V 신호를 제대로 뽑아내기 위한 로직 레벨 시프터 자리까지 마련한 제대로 된 PCB로 전환했습니다. 결과는 만족스러웠고, 이 정도 복잡도라면 PCB 제작이 예상보다 어렵지 않았다고 합니다.</p>
<h3>두 번째 버전 제작</h3>
<p>2026년 새해맞이 파티에서 이 작품을 선보였는데 반응이 좋았고, 친구들 중 몇몇은 자기도 하나 갖고 싶다고 말할 정도였습니다. 이에 힘입어 더 조립하기 쉽고 견고한 두 번째 버전 제작에 나섰습니다. 마침 PCB 설계를 갓 배운 참이라, LED를 고정하는 3D 프린트 판 대신 PCB를 백플레이트로 사용하는 방식으로 전환하기로 했습니다. PCB는 보통 5개 단위 배치로 주문하기 때문에, 형태를 조금 손봐서 5중 대칭(5-fold symmetry)을 적용했습니다. 이렇게 하면 서로 다른 네 조각을 3D 프린트하는 대신, 동일한 PCB 다섯 장을 주문해 링 형태로 조립할 수 있게 됩니다.</p>
<p>그런데 네오픽셀 LED를 인두로 손 납땜하는 작업이 생각보다 훨씬 더 악몽이었습니다. 개별 네오픽셀의 패드가 LED 아래에 숨어 있어서, 원래는 인두가 아니라 PCB 전체를 가열하는 방식으로 납땜하도록 설계되어 있었기 때문입니다. 결국 프로젝트는 잠시 중단됩니다.</p>
<p>2026년 여름, Recurse Center 프로그래밍 리트리트에 이 프로젝트 부품들을 챙겨갔고, 그곳에서 만난 한 친구가 열풍기(hot air) 납땜 스테이션 다루는 데 훨씬 능숙했던 덕분에 모든 납땜 작업을 마칠 수 있었습니다. 이어서 PCB에 클립처럼 끼워 나사로 조립할 수 있는 새로운 셀 벽을 설계하고 3D 프린트했습니다.</p>
<p>Recurse 배치 기간 동안 새 버전을 완성한 뒤, 저자는 이 작품을 Recurse Center에 설치물로 남기기로 결정합니다. 이를 위해 컨트롤러를 ESP32로 교체해 그곳 와이파이 네트워크에 연결할 수 있게 했고, 펌웨어도 Rust로 새로 작성했습니다. 이제 컨트롤러는 로컬 웹사이트를 서빙하며, Recurse Center 참가자들이 작은 웹어셈블리 백엔드와 최소한의 API를 통해 자신만의 스케치와 게임을 업로드할 수 있게 되었습니다.</p>
<h3>다음 단계는?</h3>
<p>저자는 아직 이 프로젝트에 완전히 만족하지 못하고 있습니다. 많은 사람들이 즐거워해준 만큼, 최소한 친구들에게 선물할 정도로는 더 만들어보고 싶고 나아가 판매까지도 고려하고 있지만, 지금까지의 제작 과정이 결코 이상적이지는 않았다고 말합니다. 두 버전 모두 납땜이 각기 다른 이유로 지루한 작업이었고, 종이를 부착하는 과정도 까다로운 데다 종이 자체가 부서지기 쉬워 파손 시 수리도 어렵습니다.</p>
<p>앞으로 실험해볼 만한 개선 아이디어로는 손 납땜하기 더 쉬운 다른 종류의 LED 사용, PCB 어셈블리 방식 도입, 종이를 보호할 투명 아크릴 레이어 테스트, 자석을 이용한 종이 페이스플레이트 부착 등을 꼽고 있습니다. 지금은 프로젝트에 잠시 휴식을 주되, 때가 되면 버전 3으로 이어갈 계획입니다.</p>
<h3>정리</h3>
<p>이 프로젝트는 순수 수학적 패턴(황금비 기반 필로탁시스)이 코드 → 3D 모델 → 실제 하드웨어 → 오디오 반응 인터랙티브 아트로 확장되는 전 과정을 보여줍니다. 핵심 포인트를 정리하면 다음과 같습니다.</p>
<ul>
<li>필로탁시스 패턴은 원 위의 점들을 황금비(1.618...)의 배수만큼 회전시키는 몇 줄 안 되는 코드로 구현 가능하며, Voronoi 테셀레이션을 적용하면 자연스러운 셀 구조를 얻을 수 있습니다.</li>
<li>CadQuery로 2D 셀 데이터를 3D 프린트 가능한 물리적 셸 구조로 변환하고, FreeCAD에서 나사 구멍과 페이스플레이트를 후처리하는 워크플로우를 사용했습니다.</li>
<li>STM32 보드의 부동소수점 연산과 ARM DSP 명령어를 활용해 룩업 테이블 기반의 '셰이더 스타일' LED 패턴 코드와, INMP441 I2S 마이크 + ARM CMSIS 기반의 실시간 오디오 분석(FFT, 오토게인, 멀티밴드 분석)을 구현했습니다.</li>
<li>버전이 거듭될수록 임시 배선에서 정식 PCB 설계로, STM32에서 ESP32(Rust 펌웨어)로 전환하며 안정성과 확장성(와이파이 연결, 웹어셈블리 기반 사용자 업로드)을 개선해나갔습니다.</li>
<li>네오픽셀 손 납땜, 종이 페이스플레이트의 내구성 등 실제 제작 과정에서 부딪힌 물리적 제약이 소프트웨어 설계 못지않게 프로젝트 완성도에 큰 영향을 미쳤다는 점이 인상적입니다.</li>
</ul>
