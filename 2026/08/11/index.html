React Server Components에서 발견된 심각한 보안 취약점 (CVSS 10.0)
via React Blog
🔥오늘의 화제frontend

React Server Components가 서버 페이로드를 디코딩하는 과정에서 인증 없이 원격 코드 실행이 가능한 CVSS 10.0 등급의 취약점(CVE-2025-55182)이 발견됐습니다. react-server-dom-webpack, -parcel, -turbopack의 19.0~19.2.0 버전이 영향을 받으며 19.0.1, 19.1.2, 19.2.1로 패치되었습니다. Next.js, React Router, Waku, Redwood SDK 등 RSC를 지원하는 주요 프레임워크도 영향을 받아 각각 패치 버전이 안내되었습니다.

💡
React Server Components를 사용하는 Next.js 등 프레임워크 기반 서비스를 운영 중이라면, 서버 액션을 직접 쓰지 않아도 원격 코드 실행 위험에 노출될 수 있어 즉각적인 버전 점검과 업그레이드가 필요합니다.

더 나은 텍스트 디자인을 위해 알아야 할 CSS 속성 5가지
via Hacker News (Top)
frontend

폰트 선택만으로는 부족한 순간, 텍스트를 눈에 띄게 만드는 CSS 속성 5가지를 정리했습니다. background-clip으로 텍스트 안에 이미지를 채우는 법, vertical-align과 align-content의 역할 차이, box-decoration-mode로 끊긴 텍스트 조각을 균일하게 스타일링하는 법, letter-spacing을 활용한 리빌 애니메이션, 동아시아 세로 쓰기용 text-combine-upright까지 다룹니다. 각 속성은 구현이 단순해서 기존 디자인에 쉽게 얹을 수 있습니다.

💡
이 속성들은 별도 라이브러리나 이미지 편집 없이 순수 CSS만으로 인상적인 타이포그래피 효과와 애니메이션을 구현할 수 있게 해주므로, 프론트엔드 개발자가 디자인 디테일을 직접 챙길 때 실질적인 도구가 됩니다.

Anthropic이 드디어 MCP를 고쳤다: Stateless 전환이 바꾼 것들
via Theo (t3.gg)
▶영상ai

Anthropic이 다섯 번째 MCP 스펙을 통해 프로토콜을 양방향 상태 유지 방식에서 요청-응답 기반 stateless core로 전환했습니다. 기존 MCP는 서브 에이전트마다 별도의 상태 유지 연결을 계속 붙잡아야 해서 리소스를 심하게 낭비했지만, 이번 개편으로 서버리스/엣지 배포와 단일 HTTP 요청 구조가 가능해졌습니다. Simon Willison은 이를 'stateless MCP'라 부르며 MCP에 대한 관심이 다시 살아났다고 평가했고, Theo(t3.gg) 역시 오랜 비판자였음에도 이번 변화를 긍정적으로 평가하면서 버전 네이밍 방식에는 여전히 아쉬움을 표합니다.

💡
MCP 서버를 구축·운영하는 프론트엔드/풀스택 개발자라면 인프라 복잡도와 리소스 비용을 크게 줄일 수 있는 구조 변화이며, AI 에이전트 도구 통합을 설계할 때 stateless 아키텍처가 표준이 될 가능성을 시사합니다.
