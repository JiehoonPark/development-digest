via React Blog
🔥오늘의 화제frontend

React 팀은 지난주 공개된 치명적 RCE 취약점(React2Shell) 패치를 검증하던 중, DoS 취약점 3건(CVE-2025-55184, CVE-2025-67779, CVE-2026-23864, CVSS 7.5)과 소스 코드 노출 취약점 1건(CVE-2025-55183, CVSS 5.3)을 추가로 공개했습니다. 이전 패치(19.0.3, 19.1.4, 19.2.3)는 불완전했으므로 이미 업데이트했더라도 19.0.4, 19.1.5, 19.2.4로 재업데이트가 필요합니다. RCE로 이어지지는 않지만 서버 크래시, CPU 과다 사용, Server Function 소스 코드 및 하드코딩된 시크릿 노출 위험이 있어 즉시 조치가 권고됩니다.

💡
React Server Components를 사용하는 Next.js, React Router, Waku 등 프레임워크 기반 프로덕션 서비스라면 서버 크래시와 시크릿 유출로 직접 이어질 수 있는 이슈이므로, 패치 버전과 자신의 의존성 트리를 즉시 확인해 재업데이트해야 합니다.

fx: 6.39MiB짜리 초경량 오픈소스 네이티브 코딩 에이전트
via Hacker News (Top)
ai

fx는 Zig로 작성된 6.39MiB 크기의 초경량 코딩 에이전트 CLI로, 무거워지는 'IDE형 TUI' 트렌드와 반대로 최소주의와 성능을 최우선으로 설계됐습니다. 10µs 콜드 스타트, 한 자릿수 MB 메모리 사용량, WebAssembly(JSPI) 브라우저 데모를 제공하며 스킬·플러그인·MCP로 확장 가능한 유닉스 철학을 따릅니다. Apache-2.0 오픈소스이며 로컬·클라우드 모델을 가리지 않는 model-agnostic 설계입니다.

💡
코딩 에이전트를 대량으로 실행하거나 CI/샌드박스처럼 리소스가 제한된 환경에 통합해야 하는 프론트엔드/인프라 개발자에게, 무겁지 않은 최소주의 에이전트 설계 패턴을 참고할 좋은 사례입니다.

ai

OneCLI는 팀원마다 격리된 샌드박스 AI 에이전트를 부여하고, Rust 게이트웨이를 통해 자격 증명 주입과 정책 강제를 중앙화하는 오픈소스 플랫폼입니다. 원래 Rust로 만든 자격 증명 볼트에서 출발했으나, 개인용 자율 에이전트를 팀 단위로 확장하려는 수요를 반영해 IdP 연동, 휴먼인더루프 승인, 전용 Slack 앱 등을 갖춘 v2로 발전했습니다. 웹 대시보드, API 서버, Rust 게이트웨이, 러너, 샌드박스 슈퍼바이저로 구성되며, 코어는 Apache-2.0, 일부 엔터프라이즈 기능은 별도 라이선스로 배포됩니다.

via Matt Pocock (TypeScript)
▶영상

『Clean Code』 저자 Robert C. Martin(Uncle Bob)이 Matt Pocock과의 대화에서 AI 코딩 에이전트를 실전에 투입하며 겪은 경험을 공유합니다. 에이전트도 지저분한 코드 앞에서는 사람처럼 헤매고 포기한다는 걸 목격한 그는, 2000년대 초 실용성이 없어 버려뒀던 CRAP 점수와 뮤테이션 테스팅을 에이전트와 결합해 되살렸습니다. 목표는 사람이 코드를 직접 검토하지 않아도 되는 워크플로를 만드는 것이며, 이를 위해 자연어 지침을 쌓는 '스티어링' 대신 결정론적 자동 검증 장치를 구축하는 방향을 택했습니다.

가장자리에 닿으면 사라지는 border-radius 만들기
via Kevin Powell (CSS)
▶영상frontend

요소가 뷰포트나 부모 컨테이너의 가장자리에 닿을 때 border-radius가 자동으로 0이 되는 CSS 트릭을 다룹니다. calc(100vw - 100%)를 이용한 역산 공식으로 방향을 뒤집고, clamp와 지수 연산으로 radius 폭주와 어중간한 전환 구간 문제를 해결하며, scrollbar-gutter와 컨테이너 쿼리 단위로 실전 이슈까지 보완하는 과정을 단계별로 설명합니다.

💡
