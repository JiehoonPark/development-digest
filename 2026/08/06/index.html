React Server Components, RCE 패치 이후 추가로 발견된 DoS 및 소스 코드 노출 취약점
via React Blog
frontend

지난주 공개된 React Server Components의 치명적 RCE 취약점(React2Shell) 패치를 검증하는 과정에서, 서비스 거부(DoS) 취약점 3건과 소스 코드 노출 취약점 1건이 추가로 발견되었습니다. 영향받는 패키지는 react-server-dom-webpack, react-server-dom-parcel, react-server-dom-turbopack이며 19.0.4, 19.1.5, 19.2.4로 즉시 업그레이드해야 합니다. 이전 패치(19.0.3/19.1.4/19.2.3)로 업데이트했더라도 불완전한 패치였으므로 재업데이트가 필요합니다.

💡
React Server Components를 사용하는 프로덕션 서비스라면 서버 크래시나 소스 코드·시크릿 유출로 이어질 수 있는 심각한 보안 이슈이므로, 프레임워크 종류와 관계없이 즉시 패키지 버전을 확인하고 업그레이드해야 합니다.

Meta, 터미널 코딩 에이전트 'Muse Code'와 코딩 특화 모델 'Muse Spark 1.2' 공개
via Hacker News (Top)
ai

Meta AI가 터미널 기반 코딩 에이전트 Muse Code(베타)와 이를 구동하는 신규 모델 Muse Spark 1.2를 발표했습니다. Muse Code는 지속형 비동기 백그라운드 서브에이전트와 재생 가능한 이벤트 로그 런타임을 통해 크래시에도 안전하게 장기 작업을 수행하며, Muse Spark 1.2는 Muse Code와의 공동 학습과 자기개선 루프를 통해 장기 코딩 과제 처리 능력을 강화했습니다. GPU 커널 최적화 케이스 스터디에서는 서드파티 라이브러리 없이 1,000회 이상의 도구 호출로 베이스라인 대비 유의미한 성능 개선을 달성했습니다.

💡
지속형 서브에이전트와 크래시 복구 가능한 런타임 설계는 대규모 리팩터링이나 장기 프로젝트처럼 여러 단계를 거치는 실제 개발 워크플로우에 AI 에이전트를 안정적으로 투입할 수 있는 방향을 제시합니다.

Amazon Vega로 포치 조명 만들기: React Native로 대형 화면 앱 뚝딱 만들기
via Jack Herrington
▶영상frontend

Jack Herrington이 3D 프린팅한 태양계 행성 모형과 LED 조명을 Amazon Vega 기반 Fire Stick 앱으로 제어한 경험을 소개합니다. Vega가 React Native 기반이라 기존 React 지식을 그대로 활용할 수 있었고, VS Code 확장·로컬 시뮬레이터·CLI 도구 덕분에 개발이 예상보다 수월했다고 밝힙니다. WLED 컨트롤러 제어는 일반 fetch HTTP 요청으로, 음성 제어는 aria-label만 추가하면 Vega가 알아서 처리해준다는 점이 인상적입니다.

💡
React/React Native 경험이 있는 프론트엔드 개발자에게 Vega는 별도의 학습 곡선 없이 TV·프로젝션 화면 같은 대형 스크린 앱을 만들 수 있는 진입 장벽 낮은 플랫폼임을 보여줍니다.
