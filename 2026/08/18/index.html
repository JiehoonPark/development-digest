Building App-like Experiences with Next.js 16.3
via Next.js Blog
frontend

Next.js 16.3에서는 Cache Components와 Partial Prefetching을 기반으로 한 Instant Navigations가 도입되었습니다. Cache Components는 라우트가 즉시 보여줄 수 있는 UI를 미리 준비해두고, Partial Prefetching은 그 UI를 사용자가 클릭하기 전에 브라우저로 미리 가져다 놓습니다. 이 둘의 조합은 Server Components의 이점을 그대로 유지하면서도 SPA(싱글 페이지 애플리케이션)에서 기대하는 수준의 반응성 있는 내비게이션을 제공합니다.

실제 초파리 뇌 커넥톰으로 구동되는 macOS 데스크톱 3D 파리
via Hacker News (Top)
frontend

DesktopFly는 FlyWire 커넥톰 프로젝트의 실제 초파리 뇌 데이터를 가져와 스파이킹 뉴런 시뮬레이션으로 macOS 데스크톱 위를 돌아다니는 3D 초파리를 구현한 오픈소스 프로젝트입니다. 23,210개 뉴런 위치를 뇌 창에 시각화하고, 그중 668개 뉴런·약 19,000개 시냅스로 구성된 회로를 1kHz LIF 시뮬레이션으로 실행해 마우스 커서 접근을 실제 도피 명령 뉴런(Giant Fiber)이 처리하도록 만들었습니다. 창문, 클릭, 타이핑, 일주기, 온도 등 macOS의 권한 없는 API만으로 그루밍·수면·도피 같은 행동 생태계를 구현했으며, 실측 데이터와 모델링 가정을 명확히 구분해 공개했습니다.

💡
실제 생물학적 뉴런 연결 데이터를 게임/데스크톱 소프트웨어에 결합한 창의적 사례로, 오픈 데이터셋을 활용한 시뮬레이션 설계와 macOS 권한 없는 API 활용법을 함께 참고할 수 있습니다.

fx: Zig로 만든 6MB짜리 초경량 오픈소스 코딩 에이전트
via Hacker News (Top)
aigeneral

fx는 Zig로 작성된 6.39MiB짜리 초경량 코딩 에이전트 CLI로, 콜드 스타트 10µs, 한 자릿수 MB 메모리 사용량을 내세웁니다. 무거운 TUI 대신 유닉스 셸에 가까운 UI를 채택했고, 시스템 프롬프트와 도구를 최소화해 토큰 비용과 TTFT를 최적화했습니다. WebAssembly 빌드를 통해 fx.sh에서 브라우저로 바로 체험할 수 있으며, Apache-2.0 오픈소스로 로컬·클라우드 모델을 가리지 않고 사용할 수 있습니다.

💡
대규모로 에이전트 인스턴스를 띄우거나 리소스 제약 환경에 코딩 에이전트를 임베딩해야 하는 개발자에게, 기존 무거운 도구들과 다른 경량·고성능 대안을 제시하기 때문입니다.
