실제 초파리 뇌 커넥톰으로 구동되는 macOS 데스크톱 3D 파리

A 3D fruit fly on macOS desktop powered by the real FlyWire connectome

📅 2026-08-18📰 Hacker News (Top)
frontend

macOS 데스크톱 위를 기어 다니는 초파리 한 마리를 만든 프로젝트가 Hacker News에서 화제입니다. 단순한 데스크톱 펫이 아니라, 실제 초파리의 전체 뇌 커넥톰(connectome) 데이터인 FlyWire를 그대로 가져와 스파이킹 뉴런 시뮬레이션으로 행동을 만들어낸다는 점이 독특한데요. 이 초파리는 화면 속 창문 위를 걷고, 몸을 단장하고, 잠을 자다가도 마우스 커서가 빠르게 다가오면 실제 초파리와 똑같은 뉴런 회로를 거쳐 도망칩니다. DenisSergeevitch/desktop-fly 저장소에 공개된 이 프로젝트의 구조를 자세히 살펴보겠습니다.

FlyWire 커넥톰이란

FlyWire는 성체 초파리 뇌 전체를 전자현미경으로 촬영해 재구성한 커넥톰 프로젝트로, 2024년 Nature에 발표된 데이터셋입니다. 이 프로젝트는 FlyWire v783 버전에서 139,255개 뉴런 중 23,210개의 뉴런 소마(soma, 세포체) 위치 좌표를 가져와 회전하는 3D "뇌 창"으로 렌더링합니다. 각 뉴런은 FlyWire가 분류한 대분류 세포 타입(super-class)에 따라 색이 다르게 표시되고, 실시간으로 발화(spike)하는 뉴런은 실제 위치에서 반짝입니다. 이 창에는 노란색으로 빛나는 두 개의 점이 있는데, 바로 "Giant Fiber"라 불리는 도피 명령 뉴런입니다. 뇌 창의 어느 영역이든 클릭하면 해당 부위를 자극할 수 있습니다.

668개 뉴런, 19,000개 시냅스로 구성된 실제 회로

전체 커넥톰 중 668개 뉴런과 이들 사이의 실제 시냅스 연결 약 19,000개(시냅스 개수를 신경전달물질 예측 부호로 표시)를 추출해, 1kHz로 동작하는 leaky-integrate-and-fire(LIF) 시뮬레이션으로 돌립니다. 여기 포함된 뉴런들은 다음과 같습니다.

  • LC4(104개) + LPLC2(210개): 루밍(looming, 다가오는 물체 감지) 시각 뉴런
  • DNp01 / Giant Fiber(GF, 2개): 도피 명령 뉴런
  • DNa01 + DNa02(4개): 조향 뉴런 · DNp09(2개): 전진 보행
  • DNg11(6개): 그루밍(몸단장) · MDN(4개): 후진 보행("문워크")
  • DNp02/DNp04/DNp11(6개): 도피 기동(날개) 뉴런
  • 이들과 강하게 연결된 나머지 330개 뉴런 — 자기수용감각(proprioceptive) 상행 뉴런과 바람을 감지하는 감각 뉴런 포함

여기서 핵심은 도피 행동이 스크립트로 작성된 게 아니라는 점입니다. 마우스 커서가 다가오는 움직임은 실제 LC4/LPLC2 세포에 루밍 입력으로 들어가고, Giant Fiber가 실제 시냅스를 거쳐 스파이크를 발생시켜야만 초파리가 날아오릅니다. 약 1,200개의 피드포워드 억제 시냅스가 반대로 작용하기 때문에 느리게 다가가면 초파리가 반응하지 않고, 빠르게 돌진하면 실제 동물과 마찬가지로 약 4ms 안에 도피 반응이 촉발됩니다.

몸체 자체는 절차적(procedural)으로 생성됩니다. FlyWire는 뇌 커넥톰이지 몸체 기하 데이터가 아니기 때문인데요. 그래서 트라이포드(삼각) 보행, 날갯짓, 고도에 따라 스케일링되는 비행, 그루밍과 수면 자세 등은 별도로 구현되었습니다.

설치 및 실행

요구 사항은 macOS 13 이상과 Xcode Command Line Tools(Swift 5.9 이상)입니다. 커서 위치, 창 프레임, 클릭(탭으로 취급), 열 상태 등 감지하는 모든 정보가 권한 없이 접근 가능한 것들이라 별도의 macOS 권한이나 엔타이틀먼트가 필요 없습니다.

git clone https://github.com/DenisSergeevitch/desktop-fly.git
cd desktop-fly
./build.sh
./DesktopFly

실행하면 메뉴바에 🪰 아이콘이 나타나며, 여기서 종료할 수 있습니다. 초파리는 투명하고 클릭 통과가 가능한 오버레이 위에서 돌아다니기 때문에 마우스나 키보드 입력을 가로채지 않습니다.

메뉴바에서는 다음 항목들을 제어할 수 있습니다.

항목효과
Pause / Resume세계를 정지/재개
Show/Hide Brain실시간 뇌 창 표시/숨김
Escape Test (loom)루밍 자극을 주입해 GF 발화 관찰
Move to Next Display여러 모니터 사이로 초파리 이동 (모니터가 2개 이상일 때 표시)
Add / Remove Fly초파리 추가(1번 초파리만 뇌를 가짐)
Scare Flies모든 초파리를 놀라게 함

뇌 창은 인터랙티브합니다. 마우스를 올리면 회전이 멈추고, 특정 영역을 클릭하면 근처 약 60개 뉴런을 400ms 동안 "광유전학적으로" 자극합니다. 이때 초파리의 반응은 실제 신경망이 하류에서 어떻게 처리하느냐에 달려 있습니다. Giant Fiber를 클릭하면 도망가고, DNg11을 클릭하면 몸단장을 하며, 한쪽의 DNa01/02를 클릭하면 그쪽으로 방향을 틉니다.

실제 뉴런이 몸을 움직이는 방식

시뮬레이션에서 나온 발화율이 그대로 몸의 행동으로 매핑됩니다.

몸의 행동구동 요인
도피 이륙DNp01 giant fiber 스파이크
걷기/휴식, 보행 속도DNp09 발화율
조향DNa01+DNa02 좌우 발화율 차이
그루밍DNg11 발화율
후진 스컷MDN 버스트
신경질적인 움직임LC4/LPLC2 집단 발화율
날갯짓 강도, 위협 시 날개 들기DNp02/04/11 발화율
자발적 이륙전체 집단의 각성도

여기서 흥미로운 점은 이 루프가 몸에서 뇌로도 닫혀 있다는 것입니다. 보행 리듬은 다리 움직임과 위상을 맞춰 회로의 실제 상행(자기수용감각) 뉴런에 입력으로 들어가고, 빠른 커서 움직임은 바람을 감지하는 감각 뉴런 파트너를 자극합니다.

권한 없이 구현한 데스크톱 생태계

macOS의 권한이 필요 없는 감지 기능만으로 다음과 같은 "생태계"를 구현했습니다.

  • 창 지형: 창의 위쪽 모서리는 마치 절벽 턱처럼 작동해서, 초파리가 그 위에 착륙하고 걸어 다니며, 드래그하는 창을 타고 이동하다가 발밑의 창이 닫히면 놀랍니다.
  • 창 루밍: 초파리 근처에 새 창이 나타나면 이는 루밍 경로로 입력되어, 회로가 대화상자를 피해 도망칠지 결정합니다.
  • 클릭은 지면 자극: 클릭은 발판을 두드리는 행위로 취급되며, 초파리 근처를 클릭하면 바람→GF 경로를 거쳐 놀라게 만듭니다. 타이핑은 진동으로 취급됩니다(유휴 시간 API를 사용해 키가 눌렸다는 사실만 알 뿐 어떤 키인지는 알 수 없음).
  • 일주기 리듬: 새벽/황혼에 활동이 최고조에 달하고, 한낮에는 낮잠을 자며, 밤에는 활동이 줄어듭니다. 밤에 컴퓨터가 유휴 상태이면 초파리는 잠을 자며 느리게 숨을 쉬고 각성 역치가 높아지며, 깨어난 뒤에는 몸단장을 합니다.
  • 온도: 초파리는 변온동물이므로, Mac이 뜨거워지면 초파리도 더 빨리 움직입니다.

데이터 재생성 및 진단 도구

data/ 폴더에는 이미 가공된 압축 파일들이 포함되어 있지만, 원본 FlyWire Codex 덤프(약 60MB)로부터 직접 다시 빌드할 수도 있습니다.

mkdir -p /tmp/flywire && cd /tmp/flywire
B=https://storage.googleapis.com/flywire-data/codex/data/fafb/783
curl -O "$B/classification.csv.gz" -O "$B/coordinates.csv.gz" \
-O "$B/connections.csv.gz" -O "$B/consolidated_cell_types.csv.gz"
cd - && python3 etl.py /tmp/flywire

진단용 커맨드도 제공됩니다.

./DesktopFly --simtest # circuit invariants: GF silent at rest, 4 ms loom latency, ...
./DesktopFly --behaviortest # 17 end-to-end checks: stimulate neurons -> body reacts
./DesktopFly --snapshot f.png # offscreen fly render
./DesktopFly --brainshot b.png # offscreen brain render

--simtest는 안정 상태에서 GF가 침묵하는지, 루밍 자극 후 4ms 지연으로 반응하는지 등 회로의 불변 조건을 검증하고, --behaviortest는 특정 뉴런을 자극했을 때 몸이 실제로 반응하는지를 17가지 엔드투엔드 테스트로 확인합니다.

모델링된 부분과 실측 데이터의 경계

프로젝트 저장소는 스스로 "정직한 섹션(Honesty section)"을 두어 어디까지가 실제 데이터고 어디부터가 모델링인지 명확히 구분합니다. 커넥톰이 제공하는 것은 배선(wiring) 정보이지 생리학적 특성이 아닙니다. LIF 동역학, 신경전달물질의 부호(ACh는 흥분성 +, GABA와 Glu는 억제성 −), LC→GF와 바람→GF 경로에 적용된 갭 정션(전기적 결합, 문헌으로 알려진 특성) 보정, 시냅스 지연, 그리고 커서 움직임을 루밍 값으로 변환하는 감각 변환 과정은 모두 실제 그래프 위에 얹은 표준적인 모델링 선택입니다. 반면 감각 뉴런 이후 하류의 모든 연결 관계와 그 강도는 FlyWire의 실측 데이터를 그대로 사용합니다.

라이선스와 인용

코드는 MIT 라이선스이며, data/ 폴더의 파일들은 FlyWire(FAFB v783)에서 파생된 것으로 CC BY-NC 4.0 라이선스를 따릅니다(data/DATA_LICENSE.md 참고). 이 프로젝트를 활용할 경우 다음 두 논문을 인용해야 합니다.

  • Dorkenwald, S. et al. Neuronal wiring diagram of an adult brain. Nature 634, 124–138 (2024).
  • Schlegel, P. et al. Whole-brain annotation and multi-connectome cell typing of Drosophila. Nature 634, 139–152 (2024).

정리

DesktopFly는 단순한 데스크톱 애완동물을 넘어, 실제 생물학적 뇌 커넥톰 데이터를 스파이킹 뉴런 시뮬레이션 엔진으로 구동해 macOS 데스크톱 환경과 상호작용시키는 흥미로운 실험입니다. 23,210개의 뉴런 위치를 시각화하고, 그중 668개 뉴런과 약 19,000개 시냅스로 구성된 실제 회로를 1kHz LIF 시뮬레이션으로 돌리며, 마우스 커서의 움직임을 루밍 자극으로 변환해 도피 반응이 실제 신경 회로를 거쳐 발생하도록 설계했습니다. 창문 모서리, 클릭, 타이핑, 일주기, 온도 등 macOS의 권한 없는 API만으로 풍부한 생태계적 상호작용을 구현했다는 점, 그리고 무엇이 실측 데이터고 무엇이 모델링 가정인지를 투명하게 밝힌 점이 이 프로젝트의 완성도를 보여줍니다. 신경과학 데이터를 실제 소프트웨어 프로덕트에 녹여낸 사례로서, 오픈소스 생물학 데이터를 재미있는 방식으로 활용하는 참고 사례가 될 만합니다.

💡
실제 생물학적 뉴런 연결 데이터를 게임/데스크톱 소프트웨어에 결합한 창의적 사례로, 오픈 데이터셋을 활용한 시뮬레이션 설계와 macOS 권한 없는 API 활용법을 함께 참고할 수 있습니다.
