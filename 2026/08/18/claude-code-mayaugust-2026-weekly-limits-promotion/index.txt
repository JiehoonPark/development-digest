18:T120f,<p>Anthropic이 Claude Code 사용자를 대상으로 한시적인 주간 사용 한도 상향 프로모션을 발표했습니다. 최근 Claude Code를 헤비하게 사용하면서 주간 한도에 자주 걸렸던 개발자라면 눈여겨볼 만한 소식인데요, 어떤 플랜이 대상이고 언제까지 적용되는지 정리해보겠습니다.</p>
<h3>프로모션 개요</h3>
<p>2026년 5월 13일부터 시작된 이번 프로모션은 Claude Code의 주간 사용 한도를 기존보다 50% 늘려주는 내용입니다. 원래는 종료 시점이 정해져 있었지만, Anthropic이 프로모션 기간을 연장하면서 현재는 2026년 8월 31일까지 적용됩니다.</p>
<p>여기서 중요한 포인트는 <strong>주간(weekly) 한도만</strong> 늘어난다는 점입니다. 5시간 단위로 적용되는 사용 한도(5-hour usage limit)는 이번 프로모션과 무관하며 그대로 유지됩니다.</p>
<h3>적용 대상</h3>
<p>이 혜택은 다음 플랜에 자동으로 적용됩니다.</p>
<ul>
<li>Pro 플랜</li>
<li>Max 플랜</li>
<li>Team 플랜</li>
<li>Enterprise 플랜 중 레거시 좌석 기반(legacy seat-based) 사용자</li>
</ul>
<p>반면 아래는 대상에서 제외됩니다.</p>
<ul>
<li>Free 플랜</li>
<li>Enterprise 플랜 중 사용량 기반(consumption-based) 좌석</li>
</ul>
<p>즉, 같은 Enterprise 플랜이라 하더라도 계약 형태에 따라 혜택 여부가 갈린다는 점을 확인해둘 필요가 있습니다.</p>
<h3>어디에서 적용되나</h3>
<p>50% 한도 증가는 Claude Code를 사용하는 모든 환경에 동일하게 적용됩니다. CLI, IDE 확장, 데스크톱 앱, 웹 어디에서 사용하든 늘어난 한도가 반영됩니다.</p>
<p>다만 이 프로모션은 어디까지나 Claude Code 전용입니다. 일반 Claude 제품(웹, 데스크톱, 모바일)이나 Claude Cowork의 사용 한도는 변동 없이 그대로 유지됩니다.</p>
<h3>사용자가 해야 할 일</h3>
<p>특별히 신청하거나 설정을 변경할 필요는 없습니다. 대상 플랜에 가입되어 있다면 늘어난 주간 한도가 계정에 자동으로 반영됩니다. 실제로 늘어난 한도를 확인하고 싶다면 CLI에서 <code>/usage</code> 명령어를 실행하면 현재 적용된 사용 한도를 볼 수 있습니다.</p>
<h3>자주 묻는 질문 정리</h3>
<ul>
<li><strong>추가 사용량을 받으려면 뭔가 해야 하나요?</strong> 아니요, 자동으로 적용됩니다. 계정 설정 변경 없이 Claude Code 사용 시 늘어난 주간 한도가 그대로 반영됩니다.</li>
<li><strong>5시간 사용 한도도 바뀌나요?</strong> 아니요. 이번 프로모션은 오직 주간 사용 한도에만 영향을 줍니다.</li>
<li><strong>Enterprise 플랜인데 저도 해당되나요?</strong> 레거시 좌석 기반 사용자는 포함되지만, 사용량 기반 좌석은 제외됩니다.</li>
<li><strong>프로모션이 끝나면 어떻게 되나요?</strong> 2026년 8월 31일 이후에는 Claude Code의 주간 사용 한도가 표준 수준으로 되돌아갑니다. 플랜이나 요금 청구에는 별도 변경이 없습니다.</li>
</ul>
