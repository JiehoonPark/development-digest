via Next.js Blog
frontend

Next.js가 v16.3.3(Active LTS)과 v15.5.24(Maintenance LTS)를 통해 두 건의 치명적(Critical) 보안 취약점을 패치했습니다. 하나는 sharp의 하위 의존성인 libheif 문제로 발생하는 AVIF 이미지 최적화 API의 인증되지 않은 원격 코드 실행이며, 다른 하나는 Windows 파일시스템 위에서 Pages Router와 App Router를 함께 사용(Cache Components 미사용)할 때 발생하는 원격 코드 실행입니다. 후자는 알려진 우회 방법이 없어 즉시 업그레이드가 필요합니다.

💡

Firefox 157, 모든 플랫폼에서 JPEG XL 기본 지원 선언... 무손실 성능 논쟁도 점화
via Hacker News (Top)
frontend

Mozilla가 Firefox 157부터 JPEG XL 디코딩을 모든 플랫폼에서 기본 활성화하겠다고 발표했습니다. Rust로 작성된 jxl-rs 디코더는 멀티스레드 지원 추가로 Safari의 C++ libjxl과 비슷하거나 앞서는 성능을 보이며, wpt 테스트와 자체 Gecko 테스트, 퍼징까지 검증을 마쳤습니다. 하지만 커뮤니티에서는 무손실 JPEG XL이 무손실 WebP보다 디코딩 속도가 30배 느리다는 실측 벤치마크를 근거로, 파일 크기 절감(약 10%) 대비 실효성에 의문을 제기하며 손실 포맷만 우선 출시하자는 반론도 나왔습니다.

💡
이미지 포맷 지원 현황은 웹 성능 최적화와 이미지 파이프라인 설계에 직결되므로, JPEG XL의 브라우저 지원 확대와 손실/무손실 모드별 디코딩 비용 차이를 미리 파악해두는 것이 중요합니다.

툴팁에는 딜레이가 필요하지만, 그다음엔 그 딜레이를 건너뛰어야 한다
via Hacker News (Top)
frontend

호버 툴팁에 딜레이 없이 열리게 하면 커서가 지나가기만 해도 툴팁이 계속 튀어나오는 문제가 생긴다. 반대로 200ms 딜레이를 걸면 인접한 여러 트리거를 오갈 때마다 매번 기다려야 해 UX가 답답해진다. 이 글은 '페이지가 warm/cold 상태'라는 개념을 도입해, 첫 호버는 200ms를 기다리게 하되 이후 300ms 안에 이어지는 호버는 즉시 열리게 만드는 React 패턴을 코드로 설명한다.

💡
호버 인터랙션의 딜레이 설계는 작지만 실제 제품의 체감 완성도를 크게 좌우하는 디테일이며, 라이브러리에 상관없이 적용 가능한 재사용 패턴이므로 프론트엔드 개발자가 UI 다듬기에 바로 적용할 수 있다.

브라우저에서 돌아가는 LaTeX 에디터, TeXbrain: WASM으로 pdfTeX을 그대로 옮기다
via Hacker News (Top)
frontend

TeXbrain은 서버나 계정 없이 브라우저 안에서만 동작하는 오픈소스 LaTeX 에디터로, SwiftLaTeX의 pdfTeX WebAssembly 포트로 PDF를 컴파일한다. isomorphic-git과 File System Access API를 활용해 로컬 git 워크플로우와 파일 접근을 브라우저에서 구현했고, CodeMirror 6 기반 에디터와 pdf.js 프리뷰, 오프라인 지원까지 갖췄다. pdfTeX만 지원하고 bibtex/biber는 지원하지 않는 등 한계도 명확히 밝히고 있다. MIT 라이선스로 공개되어 있으며 GitHub Pages에 정적으로 배포된다.

💡
서비스 워커 기반 리소스 캐싱 체인, 순수 JS git 구현체, 브라우저 파일시스템 API를 조합해 서버 없이도 데스크톱급 개발 워크플로우를 웹에서 구현하는 실전 패턴을 보여준다.

정답을 맞히면 지는 워드 게임, Don't Wordle
via Hacker News (Top)
frontend

Don't Wordle은 Wordle과 동일한 규칙과 힌트 시스템(초록/노란/회색)을 쓰지만, 목표가 정답을 맞히는 것이 아니라 '맞히지 않고 버티는 것'으로 뒤집힌 데일리 워드 게임입니다. 여섯 번의 시도 안에서 최대한 많은 후보 단어를 유효하게 남겨두면서 실수로 정답을 맞히지 않아야 합니다. 제한된 되돌리기 기능, 통계 추적, 결과 공유 등 기존 워들류 게임의 요소를 그대로 유지하면서 규칙 하나만 반전시킨 점이 특징입니다.

💡
단순한 규칙 반전 하나로 기존 게임의 경험을 완전히 새롭게 재구성한 사례로, 게임 메커닉과 UX 설계 관점에서 참고할 만한 미니멀 디자인 아이디어를 보여줍니다.
