React Server Components 치명적 보안 취약점(CVE-2025-55182) 대응 가이드
via React Blog
🔥오늘의 화제frontend

React Server Components 관련 패키지에서 CVSS 10.0의 인증 없는 원격 코드 실행 취약점이 발견되어 React 팀이 긴급 패치를 배포했습니다. react-server-dom-webpack, react-server-dom-parcel, react-server-dom-turbopack의 19.0~19.2.0 버전이 영향을 받으며, Next.js, React Router, Waku, Redwood SDK 등 RSC를 지원하는 프레임워크도 함께 영향을 받습니다. 이후 서비스 거부와 소스 코드 노출 관련 후속 취약점도 추가로 발견되어 패치가 이어졌습니다.

💡
RSC 기반 프레임워크(특히 Next.js)를 프로덕션에서 운영 중인 프론트엔드 개발자라면 인증 없이 서버가 완전히 장악당할 수 있는 최고 심각도 취약점이므로, 업그레이드 여부를 지금 바로 확인해야 합니다.

레이아웃 시스템, 생각보다 훨씬 어렵다: 즉시 모드 UI로 게임 UI 직접 만들기
via ThePrimeagen
▶영상frontend

게임 엔진 오딘으로 프로젝트를 진행하며 즉시 모드(immediate mode) 방식의 레이아웃 시스템을 직접 구현한 경험을 다룹니다. DOM 같은 리테인드 모드와의 차이, Clay 알고리즘을 참고해 만든 크기·위치 계산 로직, 그리고 즉시 모드 UI에서 까다로운 마우스 히트 테스트를 이전 프레임 정보로 해결한 방법을 설명합니다. 200줄 미만의 코드로 hover, drag 같은 상태 처리를 깔끔하게 구현한 사례를 통해 즉시 모드 UI의 장점을 보여줍니다.

💡
웹 프론트엔드 개발자에게 익숙한 리테인드 모드(DOM) 방식과 대비되는 즉시 모드 UI의 설계 철학과 레이아웃 알고리즘 구현 원리를 이해하면, Flexbox 같은 레이아웃 엔진의 내부 동작이나 게임/캔버스 기반 UI 시스템 설계에 대한 시야를 넓힐 수 있습니다.
