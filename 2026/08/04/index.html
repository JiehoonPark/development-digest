React Server Components 치명적 보안 취약점(CVE-2025-55182) 발생, 즉시 업그레이드 필요
via React Blog
🔥오늘의 화제frontend

React 팀이 React Server Components에서 CVSS 10.0에 달하는 인증 없는 원격 코드 실행 취약점(CVE-2025-55182)을 공개하고 긴급 업그레이드를 권고했습니다. react-server-dom-webpack, react-server-dom-parcel, react-server-dom-turbopack의 19.0~19.2.0 버전이 영향을 받으며, Next.js·React Router·Waku·Redwood SDK 등 주요 RSC 프레임워크도 함께 영향을 받습니다. 이후 DoS 및 소스 코드 노출 관련 추가 취약점도 발견되어 안내가 계속 갱신되고 있습니다.

💡
RSC 기반 프레임워크(Next.js 등)를 운영 중인 팀이라면 인증 절차 없이 서버가 완전히 장악될 수 있는 최고 등급 취약점이므로, 사용 여부를 즉시 확인하고 패치 버전으로 업그레이드하는 것이 최우선 과제입니다.

Next.js 16.3 출시: 메모리 90% 절감과 Instant Navigations로 SPA급 반응성 구현
via Next.js Blog
frontend

Next.js 16.3이 정식 출시되며 개발 서버 메모리 사용량 최대 90% 감소, 빌드 최대 5.5배 가속, TypeScript 7 지원, Node.js 네이티브 스트림을 통한 SSR 처리량 22% 증가 등 코드 수정 없이 적용되는 성능 개선을 대거 포함했습니다. 동시에 'use cache' 기반의 Instant Navigations 기능 세트(Instant Insights, Partial Prefetching, 개선된 ISR, Navigation Inspector)를 옵트인으로 제공해 서버 주도형 모델을 유지하면서도 SPA 수준의 반응성을 구현할 수 있게 했습니다. 이는 Next.js 16.0 출시 이후 가장 큰 규모의 업데이트로 평가됩니다.

💡
코드 변경 없이 업그레이드만으로 dev 경험과 프로덕션 성능이 크게 개선되며, Next.js가 지향하는 차세대 캐싱·내비게이션 모델을 미리 체험하고 대비할 수 있기 때문입니다.
