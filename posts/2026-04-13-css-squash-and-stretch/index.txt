16:T60c8,<h2 id="찌그러짐과-늘어남이란">찌그러짐과 늘어남이란</h2>
<p>찌그러짐과 늘어남(squash and stretch)은 움직이는 물체의 모양을 잠깐 바꿔 탄성과 속도를 표현하는 기법입니다. 1981년 디즈니 애니메이터 두 명이 정리한 12가지 애니메이션 원칙의 첫 번째 규칙이고, 원문 필자는 웹 개발자에게 쓸모 있는 몇 가지 원칙 가운데 이 규칙을 가장 좋아한다고 말합니다.<sup class="cite"><a href="#source-1" aria-label="출처 1">[1]</a></sup> 바닥에 닿은 공은 물풍선처럼 납작해지고, 다시 튀어 오를 때는 길쭉하고 가늘어집니다.<sup class="cite"><a href="#source-1" aria-label="출처 1">[1]</a></sup></p>
<p>핵심은 "한쪽으로 늘어나면 다른 쪽은 얇아진다"입니다. 크기만 커지면 그냥 확대입니다.</p>
<h3 id="축마다-따로-늘리기-scale-두-값">축마다 따로 늘리기: scale 두 값</h3>
<p><code>scale</code> 속성에 값을 하나 주면 두 축을 같은 비율로, 두 값을 주면 X축과 Y축을 따로 키웁니다.<sup class="cite"><a href="#source-2" aria-label="출처 2">[2]</a></sup> <code>transform</code>과 별도로 쓰는 개별 속성이고, 2022년 8월부터 주요 브라우저에서 쓸 수 있습니다.<sup class="cite"><a href="#source-2" aria-label="출처 2">[2]</a></sup></p>
<pre data-lang="css"><code class="hljs language-css"><span class="hljs-selector-class">.box</span> {
  <span class="hljs-attribute">transition</span>: scale <span class="hljs-number">0.5s</span> ease-in-out;
}

<span class="hljs-selector-class">.box</span><span class="hljs-selector-class">.grow</span><span class="hljs-selector-pseudo">:hover</span> {
  <span class="hljs-attribute">scale</span>: <span class="hljs-number">1.25</span>;       <span class="hljs-comment">/* 가로·세로 모두 1.25배 → 그냥 확대 */</span>
}

<span class="hljs-selector-class">.box</span><span class="hljs-selector-class">.stretch</span><span class="hljs-selector-pseudo">:hover</span> {
  <span class="hljs-attribute">scale</span>: <span class="hljs-number">1.25</span> <span class="hljs-number">0.8</span>;   <span class="hljs-comment">/* 가로 1.25배, 세로 0.8배 → 1.25 × 0.8 = 1 */</span>
}
</code></pre>
<p>두 비율의 곱이 1이면 면적이 그대로라서, 눈은 "커졌다"가 아니라 "눌렸다"로 읽습니다. 곱이 1에서 멀어질수록 부풀거나 쪼그라든 느낌이 섞입니다.</p>
<p>곱을 1로 고정하고 싶다면 한 축에 비율을, 다른 축에 그 역수를 <code>calc()</code>로 넣습니다.</p>
<pre data-lang="css"><code class="hljs language-css"><span class="hljs-selector-class">.ball</span> {
  <span class="hljs-attr">--squash</span>: <span class="hljs-number">1.4</span>;
  <span class="hljs-attribute">scale</span>: <span class="hljs-built_in">var</span>(--squash) <span class="hljs-built_in">calc</span>(<span class="hljs-number">1</span> / <span class="hljs-built_in">var</span>(--squash));
  <span class="hljs-comment">/* 가로 1.4배, 세로 약 0.714배 → 곱은 항상 1 */</span>
}
</code></pre>
<h4>자주 하는 실수: 값 하나만 주기</h4>
<p><code>scale: 1.2</code>처럼 값을 하나만 주면 두 축이 같은 비율로 커집니다.<sup class="cite"><a href="#source-2" aria-label="출처 2">[2]</a></sup> "말랑한" 버튼을 원했는데 단순히 커졌다 작아지는 흔한 원인입니다.</p>
<h3 id="어디를-기준으로-찌그러질까-transform-origin">어디를 기준으로 찌그러질까: transform-origin</h3>
<p><code>transform-origin</code>은 변형이 일어나는 기준점입니다. 기본값은 요소의 가운데(<code>center</code>, 초기값 <code>50% 50% 0</code>)입니다.<sup class="cite"><a href="#source-3" aria-label="출처 3">[3]</a></sup> MDN은 이 속성이 기준점을 원점으로 옮기고, 변형을 적용한 뒤, 다시 제자리로 되돌리는 이동 한 쌍과 같다고 설명합니다.<sup class="cite"><a href="#source-3" aria-label="출처 3">[3]</a></sup></p>
<pre data-lang="css"><code class="hljs language-css"><span class="hljs-selector-class">.ball</span> {
  <span class="hljs-attribute">scale</span>: <span class="hljs-number">1.4</span> <span class="hljs-built_in">calc</span>(<span class="hljs-number">1</span> / <span class="hljs-number">1.4</span>);
  <span class="hljs-comment">/* transform-origin: center (기본값)
     → 위아래가 함께 줄어 공이 바닥에서 떠 보임 */</span>
}

<span class="hljs-selector-class">.ball</span><span class="hljs-selector-class">.on-floor</span> {
  <span class="hljs-attribute">scale</span>: <span class="hljs-number">1.4</span> <span class="hljs-built_in">calc</span>(<span class="hljs-number">1</span> / <span class="hljs-number">1.4</span>);
  <span class="hljs-attribute">transform-origin</span>: center bottom;
  <span class="hljs-comment">/* 아래쪽 가운데가 고정 → 바닥에 붙은 채 납작해짐 */</span>
}
</code></pre>
<p>키워드는 백분율의 줄임말이라 <code>center bottom</code>은 <code>50% 100%</code>와 같습니다.<sup class="cite"><a href="#source-3" aria-label="출처 3">[3]</a></sup></p>
<h4>자주 하는 실수: SVG 요소의 기준점</h4>
<p>HTML 요소와 달리 SVG 요소는 <code>transform-origin</code> 초기값이 <code>0 0</code>입니다. 루트 <code>&#x3C;svg></code> 등 일부만 예외로 <code>50% 50%</code>입니다.<sup class="cite"><a href="#source-3" aria-label="출처 3">[3]</a></sup> <code>&#x3C;path></code>에 <code>scale</code>을 걸었더니 아이콘이 한쪽으로 미끄러진다면 기준점이 좌표 원점에 있기 때문이니, 기준점을 명시적으로 적습니다.</p>
<h2 id="키프레임으로-타이밍-짜기-튀는-공">키프레임으로 타이밍 짜기: 튀는 공</h2>
<p><code>@keyframes</code>는 애니메이션 중간 단계를 백분율 지점마다 정의하는 규칙으로, 전환(transition)보다 중간 과정을 세밀하게 다룹니다.<sup class="cite"><a href="#source-6" aria-label="출처 6">[6]</a></sup></p>
<h3 id="두-애니메이션을-겹치기">두 애니메이션을 겹치기</h3>
<p>원문의 공 예제는 이동과 변형을 두 키프레임으로 나눠 한 요소에 동시에 겁니다.<sup class="cite"><a href="#source-1" aria-label="출처 1">[1]</a></sup></p>
<pre data-lang="css"><code class="hljs language-css"><span class="hljs-keyword">@keyframes</span> bounce {
  <span class="hljs-number">0%</span>   { <span class="hljs-attribute">translate</span>: <span class="hljs-number">0</span> <span class="hljs-number">0</span>; }
  <span class="hljs-number">5%</span>   { <span class="hljs-attribute">translate</span>: <span class="hljs-number">0</span> <span class="hljs-number">0</span>; }      <span class="hljs-comment">/* 바닥에 잠깐 머무름 */</span>
  <span class="hljs-number">100%</span> { <span class="hljs-attribute">translate</span>: <span class="hljs-number">0</span> -<span class="hljs-number">100px</span>; } <span class="hljs-comment">/* 꼭대기 */</span>
}

<span class="hljs-keyword">@keyframes</span> squash {
  <span class="hljs-number">0%</span> {
    <span class="hljs-attribute">scale</span>:
      <span class="hljs-built_in">var</span>(--squash-ratio)
      <span class="hljs-built_in">calc</span>(<span class="hljs-number">1</span> / <span class="hljs-built_in">var</span>(--stretch-ratio));  <span class="hljs-comment">/* 바닥: 납작 */</span>
  }
  <span class="hljs-number">10%</span> {
    <span class="hljs-attribute">scale</span>:
      <span class="hljs-built_in">calc</span>(<span class="hljs-number">1</span> / <span class="hljs-built_in">var</span>(--squash-ratio))
      <span class="hljs-built_in">var</span>(--stretch-ratio);            <span class="hljs-comment">/* 떠오름: 길쭉 */</span>
  }
  <span class="hljs-number">100%</span> { <span class="hljs-attribute">scale</span>: <span class="hljs-number">1</span> <span class="hljs-number">1</span>; }                 <span class="hljs-comment">/* 원래 모양 */</span>
}

<span class="hljs-selector-class">.ball</span> {
  <span class="hljs-attr">--curve</span>: <span class="hljs-built_in">cubic-bezier</span>(<span class="hljs-number">0.123</span>, <span class="hljs-number">0.5</span>, <span class="hljs-number">0.5</span>, <span class="hljs-number">1</span>);
  <span class="hljs-attr">--stretch-ratio</span>: <span class="hljs-number">1.25</span>;
  <span class="hljs-attr">--squash-ratio</span>: <span class="hljs-number">1.5</span>;
  <span class="hljs-attribute">width</span>: <span class="hljs-number">50px</span>;
  <span class="hljs-attribute">height</span>: <span class="hljs-number">50px</span>;
  <span class="hljs-attribute">border-radius</span>: <span class="hljs-number">50%</span>;
  <span class="hljs-attribute">animation</span>:
    squash <span class="hljs-number">800ms</span> linear infinite,
    bounce <span class="hljs-number">400ms</span> <span class="hljs-built_in">var</span>(--curve) infinite alternate;
  <span class="hljs-attribute">transform-origin</span>: center bottom;
}
</code></pre>
<h3 id="숫자가-맞물리는-방식">숫자가 맞물리는 방식</h3>
<p><code>bounce</code>는 <code>alternate</code>로 반복합니다. <code>alternate</code>는 회차마다 방향을 바꾸며, 첫 회차는 정방향입니다.<sup class="cite"><a href="#source-7" aria-label="출처 7">[7]</a></sup> 그래서 400ms 동안 올라가고 다음 400ms 동안 같은 경로를 거꾸로 내려옵니다. 한 번 튀는 데 800ms가 걸리고, 이 길이가 <code>squash</code>의 800ms와 같아서 두 애니메이션의 주기가 맞습니다.<sup class="cite"><a href="#source-1" aria-label="출처 1">[1]</a></sup></p>
<ul>
<li><code>squash</code> 0%: 공이 바닥에 있는 순간이라 가로로 납작합니다.</li>
<li><code>squash</code> 10%(80ms): 막 튀어 오르는 순간이라 세로로 길쭉합니다.</li>
<li><code>squash</code> 100%: 떠 있는 동안 서서히 원래 모양으로 돌아옵니다.</li>
<li><code>bounce</code> 0~5%: 바닥에 머물러 찌그러진 모양이 눈에 남습니다.</li>
</ul>
<p>올라가는 곡선 <code>cubic-bezier(0.123, 0.5, 0.5, 1)</code>은 처음에 빠르고 끝에서 느려집니다. 두 제어점의 x는 0~1 범위여야 합니다.<sup class="cite"><a href="#source-8" aria-label="출처 8">[8]</a></sup> 거꾸로 재생하면 이징도 뒤집혀 <code>ease-in</code>이 <code>ease-out</code>이 되므로<sup class="cite"><a href="#source-7" aria-label="출처 7">[7]</a></sup>, 꼭대기에서 느리던 공이 내려올수록 빨라집니다.</p>
<p>원문 코드는 찌그러질 때 가로 <code>1.5</code>, 세로 <code>1 / 1.25</code>를 씁니다.<sup class="cite"><a href="#source-1" aria-label="출처 1">[1]</a></sup> 곱이 1.2라 바닥에서 살짝 부풀어 보이니, 면적을 지키려면 한 변수와 그 역수만 씁니다.</p>
<h4>자주 하는 실수: transform 하나로 두 애니메이션 돌리기</h4>
<p>이동은 <code>transform: translateY()</code>, 변형은 <code>transform: scale()</code>로 쓰면 두 애니메이션이 같은 <code>transform</code> 속성을 두고 다투고, 한쪽 값만 남습니다. 원문처럼 <code>translate</code>와 <code>scale</code> 개별 속성으로 나누면 두 애니메이션이 서로 다른 속성을 움직이므로 함께 적용됩니다.<sup class="cite"><a href="#source-1" aria-label="출처 1">[1]</a></sup><sup class="cite"><a href="#source-2" aria-label="출처 2">[2]</a></sup></p>
<h2 id="svg-아이콘에-적용하기-늘어나는-화살표">SVG 아이콘에 적용하기: 늘어나는 화살표</h2>
<p>원문 필자는 실무에서 이 기법을 튀는 공보다 SVG 아이콘의 작은 상호작용에 훨씬 자주 쓴다고 말합니다.<sup class="cite"><a href="#source-1" aria-label="출처 1">[1]</a></sup> 대표 예가 호버하면 늘어나는 화살표로, 화살촉이 살짝 오므라들어 길어지는 만큼 가늘어지는 것처럼 보입니다.<sup class="cite"><a href="#source-1" aria-label="출처 1">[1]</a></sup></p>
<h3 id="d-속성과-path로-경로-바꾸기">d 속성과 path()로 경로 바꾸기</h3>
<p>CSS <code>d</code> 속성은 SVG <code>&#x3C;path></code>가 그릴 경로를 정하고, 있으면 <code>d</code> 속성(attribute)을 덮어씁니다.<sup class="cite"><a href="#source-9" aria-label="출처 9">[9]</a></sup> 값은 따옴표로 감싼 경로 문자열을 받는 <code>path()</code> 함수입니다.<sup class="cite"><a href="#source-9" aria-label="출처 9">[9]</a></sup> 원문은 화살대와 화살촉 두 경로를 호버 때 다른 경로로 바꾸고, 그 사이를 전환으로 이어 줍니다.<sup class="cite"><a href="#source-1" aria-label="출처 1">[1]</a></sup></p>
<pre data-lang="html"><code class="hljs language-html"><span class="hljs-tag">&#x3C;<span class="hljs-name">style</span>></span><span class="css">
  <span class="hljs-keyword">@media</span> (<span class="hljs-attribute">prefers-reduced-motion</span>: no-preference) {
    <span class="hljs-selector-class">.shaft</span>, <span class="hljs-selector-class">.tip</span> {
      <span class="hljs-attribute">transition</span>: d <span class="hljs-number">300ms</span>;
    }
    <span class="hljs-selector-class">.btn</span><span class="hljs-selector-pseudo">:hover</span> <span class="hljs-selector-class">.shaft</span>,
    <span class="hljs-selector-class">.btn</span><span class="hljs-selector-pseudo">:focus-visible</span> <span class="hljs-selector-class">.shaft</span> {
      d: <span class="hljs-built_in">path</span>(<span class="hljs-string">"M 5,12 h 17"</span>);       <span class="hljs-comment">/* 화살대 14 → 17 */</span>
    }
    <span class="hljs-selector-class">.btn</span><span class="hljs-selector-pseudo">:hover</span> <span class="hljs-selector-class">.tip</span>,
    <span class="hljs-selector-class">.btn</span><span class="hljs-selector-pseudo">:focus-visible</span> <span class="hljs-selector-class">.tip</span> {
      d: <span class="hljs-built_in">path</span>(<span class="hljs-string">"M 15,7 l 7,5 l -7,5"</span>); <span class="hljs-comment">/* 촉 높이 14 → 10 */</span>
    }
  }
</span><span class="hljs-tag">&#x3C;/<span class="hljs-name">style</span>></span>

<span class="hljs-tag">&#x3C;<span class="hljs-name">button</span> <span class="hljs-attr">class</span>=<span class="hljs-string">"btn"</span>></span>
  <span class="hljs-tag">&#x3C;<span class="hljs-name">svg</span> <span class="hljs-attr">class</span>=<span class="hljs-string">"arrow"</span> <span class="hljs-attr">aria-hidden</span>=<span class="hljs-string">"true"</span> <span class="hljs-attr">viewBox</span>=<span class="hljs-string">"0 0 24 24"</span>></span>
    <span class="hljs-tag">&#x3C;<span class="hljs-name">path</span> <span class="hljs-attr">class</span>=<span class="hljs-string">"shaft"</span> <span class="hljs-attr">d</span>=<span class="hljs-string">"M 5,12 h 14"</span> /></span>
    <span class="hljs-tag">&#x3C;<span class="hljs-name">path</span> <span class="hljs-attr">class</span>=<span class="hljs-string">"tip"</span> <span class="hljs-attr">d</span>=<span class="hljs-string">"M 12,5 l 7,7 l -7,7"</span> /></span>
  <span class="hljs-tag">&#x3C;/<span class="hljs-name">svg</span>></span>

<p>화살대 끝은 x=19에서 22로 3만큼 늘어나고, 화살촉의 세로 폭은 14(y 5→19)에서 10(y 7→17)으로 줄어듭니다. 가로로 늘린 만큼 세로를 좁힌 것입니다.</p>
<p>MDN 예제도 두 상태의 데이터 포인트 수를 같게 맞춰 경로를 애니메이션합니다.<sup class="cite"><a href="#source-9" aria-label="출처 9">[9]</a></sup> 여기서도 명령 구조는 두고 숫자만 바꿨습니다.</p>
<h4>자주 하는 실수: 여러 줄 문자열과 Safari</h4>
<p>CSS 문자열은 여러 줄로 쓸 수 없습니다. 경로를 한 줄에 쓰거나, 줄 끝을 백슬래시(<code>\</code>)로 이스케이프해야 합니다.<sup class="cite"><a href="#source-1" aria-label="출처 1">[1]</a></sup></p>
<p>지원 범위도 확인해야 합니다. <code>&#x3C;path></code> 전환은 Safari에서 동작하지 않아 원문 기준 지원 범위는 2026년 4월 약 79%입니다.<sup class="cite"><a href="#source-1" aria-label="출처 1">[1]</a></sup> Can I use 표에서도 CSS <code>d</code> 속성의 <code>path()</code>는 Chrome 52, Firefox 97부터 지원하지만 Safari와 iOS Safari는 지원하지 않습니다.<sup class="cite"><a href="#source-4" aria-label="출처 4">[4]</a></sup> MDN은 <code>d</code>를 Baseline이 아닌 제한적 지원(Limited availability) 기능으로 분류합니다.<sup class="cite"><a href="#source-9" aria-label="출처 9">[9]</a></sup> 원문 필자는 꾸미기용 효과라면 지원 범위를 느슨하게 잡아도 된다고 보지만, 모두에게 보여 주고 싶을 때는 Motion 같은 JS 라이브러리를 씁니다.<sup class="cite"><a href="#source-1" aria-label="출처 1">[1]</a></sup> JS 애니메이션과 메인 스레드의 관계는 이전 글 "CSS 애니메이션이 더 부드러운 진짜 이유"에서 다뤘습니다.</p>
<h3 id="스프링-느낌을-css로-linear">스프링 느낌을 CSS로: linear()</h3>
<p>원문은 Motion의 스프링 물리(<code>stiffness: 300</code>, <code>damping: 12</code>)로 화살표가 고무처럼 튕기게 만듭니다.<sup class="cite"><a href="#source-1" aria-label="출처 1">[1]</a></sup> CSS만으로 비슷한 느낌을 내려면 <code>linear()</code> 이징 함수를 씁니다. <code>linear()</code>는 지정한 점들 사이를 직선으로 이어 곡선을 근사하고, 0~1 밖의 값도 허용합니다.<sup class="cite"><a href="#source-10" aria-label="출처 10">[10]</a></sup> 1을 넘었다가 돌아오는 점을 넣으면 목표를 지나쳤다 되돌아오는 탄성이 생깁니다.</p>
<pre data-lang="css"><code class="hljs language-css"><span class="hljs-selector-class">.icon</span> {
  <span class="hljs-attribute">transition</span>: scale <span class="hljs-number">400ms</span> <span class="hljs-built_in">linear</span>(<span class="hljs-number">0</span>, <span class="hljs-number">1.25</span> <span class="hljs-number">40%</span>, <span class="hljs-number">0.9</span> <span class="hljs-number">70%</span>, <span class="hljs-number">1</span>);
}

<span class="hljs-selector-class">.icon</span><span class="hljs-selector-pseudo">:hover</span> {
  <span class="hljs-attribute">scale</span>: <span class="hljs-number">1.15</span> <span class="hljs-number">0.87</span>; <span class="hljs-comment">/* 곱 ≈ 1, 가로로 늘고 세로로 얇아짐 */</span>
}
<span class="hljs-comment">/* 진행률 0 → 40% 지점에서 1.25(지나침)
   → 70% 지점에서 0.9(되돌아옴) → 1(정착) */</span>
</code></pre>
<p>백분율은 오름차순이어야 합니다. <code>linear(0, 0.25 80%, 0.5 60%, 1)</code>처럼 순서가 거꾸로면 잘못된 값입니다.<sup class="cite"><a href="#source-10" aria-label="출처 10">[10]</a></sup> 원문의 이벤트 기반 방식, 즉 호버가 시작될 때 잠깐 늘었다가 150ms 뒤 바로 돌아오는 효과는 타이머가 필요해 JS로 구현합니다.<sup class="cite"><a href="#source-1" aria-label="출처 1">[1]</a></sup></p>
<h2 id="모션-줄이기-prefers-reduced-motion">모션 줄이기: prefers-reduced-motion</h2>
<p><code>prefers-reduced-motion</code>은 사용자가 기기에서 불필요한 움직임을 줄이는 설정을 켰는지 알려 주는 미디어 특성입니다.<sup class="cite"><a href="#source-5" aria-label="출처 5">[5]</a></sup> 큰 물체를 확대·축소하거나 이동하는 애니메이션은 전정 기관 장애가 있는 사람에게 불편을 일으킬 수 있습니다.<sup class="cite"><a href="#source-5" aria-label="출처 5">[5]</a></sup></p>
<h3 id="기본은-정지-허락할-때만-움직이기">기본은 정지, 허락할 때만 움직이기</h3>
<p>원문은 애니메이션 전체를 <code>no-preference</code> 블록 안에 넣어, 설정을 켜지 않은 사용자에게만 효과를 붙입니다. JS로 시작하는 애니메이션도 <code>matchMedia</code>로 같은 조건을 확인합니다.<sup class="cite"><a href="#source-1" aria-label="출처 1">[1]</a></sup> 원문 필자는 움직임이 아주 작아도 모션을 끄고 싶은 이유는 다양하니 조심하는 쪽을 택한다고 말합니다.<sup class="cite"><a href="#source-1" aria-label="출처 1">[1]</a></sup></p>
<pre data-lang="css"><code class="hljs language-css"><span class="hljs-comment">/* 방법 1: 움직임을 opt-in으로 */</span>
<span class="hljs-keyword">@media</span> (<span class="hljs-attribute">prefers-reduced-motion</span>: no-preference) {
  <span class="hljs-selector-class">.ball</span> {
    <span class="hljs-attribute">animation</span>:
      squash <span class="hljs-number">800ms</span> linear infinite,
      bounce <span class="hljs-number">400ms</span> <span class="hljs-built_in">var</span>(--curve) infinite alternate;
  }
}

<span class="hljs-comment">/* 방법 2: 움직임을 다른 효과로 바꾸기 */</span>
<span class="hljs-keyword">@media</span> (<span class="hljs-attribute">prefers-reduced-motion</span>: reduce) {
  <span class="hljs-selector-class">.animation</span> {
    <span class="hljs-attribute">animation</span>: dissolve <span class="hljs-number">4s</span> linear infinite both;
  }
}
</code></pre>
<p>MDN 예제는 두 번째 방식으로, 크기가 변하는 <code>pulse</code>를 투명도만 바뀌는 <code>dissolve</code>로 바꿉니다.<sup class="cite"><a href="#source-5" aria-label="출처 5">[5]</a></sup> 움직임을 없애는 대신 자극이 덜한 효과로 대체할 수도 있습니다.</p>
<h4>자주 하는 실수: 키워드 없이 쓴 쿼리 오해하기</h4>
<p><code>@media (prefers-reduced-motion)</code>처럼 값 없이 쓰면 <code>reduce</code>와 같은 뜻입니다. <code>no-preference</code>는 거짓, <code>reduce</code>는 참으로 평가되기 때문입니다.<sup class="cite"><a href="#source-5" aria-label="출처 5">[5]</a></sup> 움직임을 켜는 블록에 쓰면 정반대가 됩니다.</p>
