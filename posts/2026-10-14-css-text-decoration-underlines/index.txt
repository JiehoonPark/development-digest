17:T52e7,<h2 id="가짜-밑줄이-생긴-이유">가짜 밑줄이 생긴 이유</h2>
<p>밑줄은 원래 글자에 딸린 장식이라 손댈 곳이 거의 없었습니다. 밑줄 색은 글자 색을 그대로 물려받을 수밖에 없었고, 명세가 밑줄 두께를 정하지 않아 두께는 브라우저가 알아서 정했습니다. 그 결과 큰 글자에서 특히 브라우저마다 밑줄 굵기가 달랐습니다.<sup class="cite"><a href="#source-1" aria-label="출처 1">[1]</a></sup></p>
<p>그래서 오랫동안 쓰인 우회책이 밑줄을 끄고 테두리로 선을 긋는 방법입니다.<sup class="cite"><a href="#source-1" aria-label="출처 1">[1]</a></sup></p>
<pre data-lang="css"><code class="hljs language-css"><span class="hljs-comment">/* 오래된 우회책: 테두리를 밑줄처럼 쓰기 */</span>
<span class="hljs-selector-tag">a</span> {
  <span class="hljs-attribute">border-bottom</span>: <span class="hljs-number">1px</span> solid;
  <span class="hljs-attribute">text-decoration</span>: none;
}
<span class="hljs-comment">/* 결과: 색·두께는 마음대로 바뀌지만, 선은 글자가 아니라 상자 아래쪽에 붙는다 */</span>
</code></pre>
<p><code>box-shadow</code>로 상자 아래에 그림자 선을 넣는 방법도 같은 계열입니다. 둘 다 글자가 아니라 요소의 상자를 꾸미는 속성이라, 선이 글자 모양과 상관없이 상자 맨 아래에 그려집니다.</p>
<p>원문 필자는 이 방식이 우아하지 않고 보기에도 좋지 않다고 봅니다. 밑줄은 g, y처럼 아래로 내려오는 획(디센더, descender)이 있는 글자와 만나야 하는데 테두리는 그러지 못하기 때문입니다.<sup class="cite"><a href="#source-1" aria-label="출처 1">[1]</a></sup> 반대로 진짜 밑줄은 글자를 기준으로 그려지므로, 디센더 근처에서 선을 끊을지 말지를 브라우저가 판단할 수 있습니다.<sup class="cite"><a href="#source-6" aria-label="출처 6">[6]</a></sup></p>
<blockquote>
<p>가짜 밑줄은 상자를 꾸미고, 진짜 밑줄은 글자를 꾸밉니다. 디센더 근처를 어떻게 그릴지처럼 글자에 맞춰야 하는 판단은 진짜 밑줄에서만 할 수 있습니다.</p>
</blockquote>
<h2 id="밑줄을-이루는-네-가지-속성">밑줄을 이루는 네 가지 속성</h2>
<p><code>text-decoration</code>은 네 개의 개별 속성을 묶은 축약형(shorthand)입니다. 선의 종류 <code>text-decoration-line</code>, 색 <code>text-decoration-color</code>, 모양 <code>text-decoration-style</code>, 두께 <code>text-decoration-thickness</code>입니다.<sup class="cite"><a href="#source-5" aria-label="출처 5">[5]</a></sup></p>
<h3 id="종류모양색">종류·모양·색</h3>
<p><code>text-decoration-line</code>은 어떤 선을 그을지 정합니다. <code>underline</code>, <code>overline</code>, <code>line-through</code>를 띄어 써서 여러 개를 함께 줄 수 있습니다.<sup class="cite"><a href="#source-7" aria-label="출처 7">[7]</a></sup> <code>text-decoration-style</code>은 선 모양으로 <code>solid</code>, <code>double</code>, <code>dotted</code>, <code>dashed</code>, <code>wavy</code> 중 하나를 고릅니다.<sup class="cite"><a href="#source-8" aria-label="출처 8">[8]</a></sup> <code>text-decoration-color</code>는 선 색이고, 초기값은 <code>currentcolor</code>라서 따로 정하지 않으면 글자 색을 따라갑니다.<sup class="cite"><a href="#source-4" aria-label="출처 4">[4]</a></sup><sup class="cite"><a href="#source-5" aria-label="출처 5">[5]</a></sup></p>
<p>원문이 소개한 코드는 네 속성을 하나씩 다 적은 형태입니다.<sup class="cite"><a href="#source-1" aria-label="출처 1">[1]</a></sup></p>
<pre data-lang="css"><code class="hljs language-css"><span class="hljs-selector-tag">a</span> {
  <span class="hljs-attribute">text-decoration-line</span>: underline;
  <span class="hljs-attribute">text-decoration-color</span>: teal;
  <span class="hljs-attribute">text-decoration-style</span>: solid;
  <span class="hljs-attribute">text-decoration-thickness</span>: <span class="hljs-number">1px</span>;
}
<span class="hljs-comment">/* 결과: 글자 색과 상관없이 청록색 1px 실선 밑줄 */</span>
</code></pre>
<h3 id="두께-text-decoration-thickness">두께: text-decoration-thickness</h3>
<p><code>text-decoration-thickness</code>는 밑줄·윗줄·취소선의 굵기를 정합니다.<sup class="cite"><a href="#source-2" aria-label="출처 2">[2]</a></sup> 값은 네 가지입니다.<sup class="cite"><a href="#source-2" aria-label="출처 2">[2]</a></sup></p>
<ul>
<li><code>auto</code>: 브라우저가 적당한 두께를 고릅니다.</li>
<li><code>from-font</code>: 글꼴 파일에 권장 두께가 있으면 그 값을 쓰고, 없으면 <code>auto</code>처럼 동작합니다.</li>
<li>길이(<code>3px</code>, <code>0.1em</code>): 글꼴의 권장값과 브라우저 기본값을 무시하고 이 값을 씁니다.</li>
<li>퍼센트(<code>10%</code>): 현재 글꼴 <code>1em</code>에 대한 비율이고, 최소 1 장치 픽셀(device pixel)은 보장됩니다.</li>
</ul>
<pre data-lang="css"><code class="hljs language-css"><span class="hljs-selector-class">.thin</span>  { <span class="hljs-attribute">text-decoration</span>: underline red <span class="hljs-number">1px</span>; } <span class="hljs-comment">/* 1px 빨간 밑줄 */</span>
<span class="hljs-selector-class">.thick</span> { <span class="hljs-attribute">text-decoration</span>: underline red <span class="hljs-number">5px</span>; } <span class="hljs-comment">/* 5px 빨간 밑줄 */</span>
<span class="hljs-selector-class">.scale</span> { <span class="hljs-attribute">text-decoration</span>: underline <span class="hljs-number">10%</span>; }     <span class="hljs-comment">/* 글자 크기에 비례 */</span>
</code></pre>
<p>이 속성은 한때 <code>text-decoration-width</code>라는 이름이었고 2019년에 지금 이름으로 바뀌었습니다.<sup class="cite"><a href="#source-2" aria-label="출처 2">[2]</a></sup> 예전 글이나 코드에서 옛 이름을 보면 같은 기능으로 읽으면 됩니다.</p>
<h4>자주 하는 실수: 자식의 글자 크기를 따라갈 거라 기대하기</h4>
<p>퍼센트 두께는 속성을 적용한 상자 전체에서 일정하게 유지됩니다. 안에 글자 크기가 다른 자식 요소가 있어도 두께는 바뀌지 않습니다.<sup class="cite"><a href="#source-2" aria-label="출처 2">[2]</a></sup> 또 <code>text-decoration-thickness</code>는 상속되지 않는 속성입니다.<sup class="cite"><a href="#source-2" aria-label="출처 2">[2]</a></sup> 링크 안에 큰 글씨 <code>span</code>을 넣었다고 그 부분만 밑줄이 굵어지지는 않습니다.</p>
<h3 id="축약형이-초기화하는-것">축약형이 초기화하는 것</h3>
<p>축약형은 편하지만, 적지 않은 값을 초기값으로 되돌립니다. 두께도 축약형에 포함되므로 <code>text-decoration: underline</code>처럼 두께를 빼고 쓰면 앞서 정한 두께가 초기값 <code>auto</code>로 돌아갑니다.<sup class="cite"><a href="#source-2" aria-label="출처 2">[2]</a></sup><sup class="cite"><a href="#source-5" aria-label="출처 5">[5]</a></sup></p>
<pre data-lang="css"><code class="hljs language-css"><span class="hljs-selector-tag">a</span> {
  <span class="hljs-attribute">text-decoration-thickness</span>: <span class="hljs-number">3px</span>;
  <span class="hljs-attribute">text-decoration</span>: underline; <span class="hljs-comment">/* 두께가 초기값 auto로 돌아감 */</span>
}

<span class="hljs-selector-tag">a</span> {
  <span class="hljs-attribute">text-decoration</span>: underline <span class="hljs-number">3px</span>; <span class="hljs-comment">/* 축약형 안에 두께까지 적기 */</span>
}
</code></pre>
<p>반대로 <code>text-decoration-skip-ink</code>, <code>text-underline-offset</code>, <code>text-underline-position</code>은 밑줄에 영향을 주지만 축약형에는 들어 있지 않습니다.<sup class="cite"><a href="#source-5" aria-label="출처 5">[5]</a></sup> 축약형을 다시 써도 이 셋은 유지됩니다.</p>
<h4>자주 하는 실수: 자식에서 밑줄 지우기</h4>
<p>장식선은 자손 텍스트 위로 이어서 그려집니다. 그래서 부모에 밑줄이 있으면 자식에서 <code>text-decoration: none</code>을 줘도 밑줄이 사라지지 않습니다.<sup class="cite"><a href="#source-5" aria-label="출처 5">[5]</a></sup> 링크 안의 아이콘이나 배지에만 밑줄을 빼고 싶다면, 밑줄을 링크 전체가 아니라 글자를 감싼 요소에만 거는 식으로 구조를 바꿔야 합니다.</p>
<pre data-lang="css"><code class="hljs language-css"><span class="hljs-selector-tag">p</span>  { <span class="hljs-attribute">text-decoration</span>: underline; }
<span class="hljs-selector-tag">em</span> { <span class="hljs-attribute">text-decoration</span>: none; }     <span class="hljs-comment">/* 효과 없음: em도 여전히 밑줄 */</span>
<span class="hljs-selector-tag">em</span> { <span class="hljs-attribute">text-decoration</span>: overline; } <span class="hljs-comment">/* em에만 윗줄이 하나 더 생김 */</span>
</code></pre>
<h2 id="위치와-간격-그리고-한글">위치와 간격, 그리고 한글</h2>
<h3 id="간격-text-underline-offset">간격: text-underline-offset</h3>
<p><code>text-underline-offset</code>은 밑줄을 원래 위치에서 얼마나 떨어뜨릴지 정합니다. 밑줄에만 적용되고 윗줄이나 취소선에는 영향이 없습니다.<sup class="cite"><a href="#source-3" aria-label="출처 3">[3]</a></sup> 값은 <code>auto</code>, 길이, 퍼센트이고, MDN은 글자 크기에 맞춰 함께 커지도록 <code>em</code> 단위를 권합니다.<sup class="cite"><a href="#source-3" aria-label="출처 3">[3]</a></sup></p>
<pre data-lang="css"><code class="hljs language-css"><span class="hljs-selector-tag">a</span> {
  <span class="hljs-attribute">text-decoration</span>: underline;
  <span class="hljs-attribute">text-underline-offset</span>: <span class="hljs-number">0.2em</span>; <span class="hljs-comment">/* 글자 크기에 비례해 아래로 */</span>
}
</code></pre>
<p>이 속성은 상속되고, 퍼센트 값은 상대값 그대로 상속되어 글꼴이 바뀌면 함께 달라집니다.<sup class="cite"><a href="#source-3" aria-label="출처 3">[3]</a></sup> 그래서 문서 전체 기준을 한 번 정해 두기 좋습니다.</p>
<pre data-lang="css"><code class="hljs language-css"><span class="hljs-selector-pseudo">:root</span> {
  <span class="hljs-attribute">text-underline-offset</span>: <span class="hljs-number">20%</span>; <span class="hljs-comment">/* 모든 밑줄이 글자 크기의 20%만큼 내려감 */</span>
}
</code></pre>
<p><code>border-bottom</code> 우회에서 <code>padding-bottom</code>으로 하던 일을 이 속성 하나가 맡는다고 보면 됩니다.</p>
<h3 id="위치-text-underline-position">위치: text-underline-position</h3>
<p><code>text-underline-position</code>은 밑줄을 어느 기준에 둘지 정합니다. <code>under</code>는 밑줄을 알파벳 기준선(baseline) 아래, 디센더와 겹치지 않는 위치로 내립니다. 아래 첨자가 많은 화학식이나 수식에서 읽기 좋게 하려는 값입니다.<sup class="cite"><a href="#source-9" aria-label="출처 9">[9]</a></sup> 세로쓰기(vertical writing mode)에서는 <code>left</code>, <code>right</code>로 밑줄을 글자의 왼쪽이나 오른쪽에 둡니다.<sup class="cite"><a href="#source-9" aria-label="출처 9">[9]</a></sup></p>
<p>이 속성도 상속되고 축약형이 초기화하지 않으므로, MDN은 수식이 많은 문서라면 전역에 설정하는 방법을 소개합니다.<sup class="cite"><a href="#source-9" aria-label="출처 9">[9]</a></sup></p>
<pre data-lang="css"><code class="hljs language-css"><span class="hljs-selector-pseudo">:root</span> {
  <span class="hljs-attribute">text-underline-position</span>: under;
}
<span class="hljs-comment">/* 결과: 모든 밑줄이 디센더와 겹치지 않는 기준선 아래에 놓임 */</span>
</code></pre>
<h3 id="잉크-건너뛰기-text-decoration-skip-ink">잉크 건너뛰기: text-decoration-skip-ink</h3>
<p><code>text-decoration-skip-ink</code>는 밑줄과 윗줄이 글자의 위·아래로 튀어나온 획을 지날 때 선을 끊을지 정합니다.<sup class="cite"><a href="#source-6" aria-label="출처 6">[6]</a></sup> 이 속성도 축약형에 들어 있지 않습니다.<sup class="cite"><a href="#source-6" aria-label="출처 6">[6]</a></sup></p>
<ul>
<li><code>auto</code>(기본값): 브라우저가 글자에 닿거나 가까워지는 곳에서 선을 끊을 <em>수 있습니다</em>.</li>
<li><code>none</code>: 끊지 않고 텍스트 전체 길이에 선을 긋습니다.</li>
<li><code>all</code>: 글자에 닿거나 가까워지는 곳에서 <em>반드시</em> 끊습니다.</li>
</ul>
<pre data-lang="css"><code class="hljs language-css"><span class="hljs-selector-tag">p</span>        { <span class="hljs-attribute">text-decoration</span>: underline blue; }  <span class="hljs-comment">/* auto가 기본 */</span>
<span class="hljs-selector-class">.no-skip</span> { <span class="hljs-attribute">text-decoration-skip-ink</span>: none; }   <span class="hljs-comment">/* g, y 아래로 선이 지나감 */</span>
<span class="hljs-selector-class">.cjk</span>     { <span class="hljs-attribute">text-decoration-skip-ink</span>: all; }    <span class="hljs-comment">/* 글자 근처는 항상 끊김 */</span>
</code></pre>
<h3 id="한글-글꼴에서-확인할-점">한글 글꼴에서 확인할 점</h3>
<p>MDN은 일부 한중일(CJK) 글꼴에서 <code>auto</code>가 선을 끊지 않을 수 있고, 이때 <code>all</code>이 도움이 된다고 설명합니다.<sup class="cite"><a href="#source-6" aria-label="출처 6">[6]</a></sup> 한글 본문에서 밑줄이 글자 아래쪽 획에 붙어 보인다면 먼저 <code>all</code>을 켜 보고 결과를 비교하세요.</p>
<p><code>all</code>로도 답답하다면 선 자체를 내리는 방법이 있습니다. <code>text-underline-offset</code>을 <code>em</code>이나 퍼센트로 주거나 <code>text-underline-position: under</code>를 쓰면 됩니다.<sup class="cite"><a href="#source-3" aria-label="출처 3">[3]</a></sup><sup class="cite"><a href="#source-9" aria-label="출처 9">[9]</a></sup> 어느 쪽이 나은지는 글꼴마다 다르니, 실제 서비스에서 쓰는 한글 웹폰트로 받침이 많은 단어를 넣어 확인하는 것이 확실합니다.</p>
<h2 id="링크-hover-밑줄">링크 hover 밑줄</h2>
<h3 id="두께와-간격을-전환하기">두께와 간격을 전환하기</h3>
<p><code>text-decoration-thickness</code>와 <code>text-underline-offset</code>의 애니메이션 유형은 "계산값 유형에 따름(by computed value type)"이고, <code>text-decoration-color</code>는 색으로 보간됩니다.<sup class="cite"><a href="#source-2" aria-label="출처 2">[2]</a></sup><sup class="cite"><a href="#source-3" aria-label="출처 3">[3]</a></sup><sup class="cite"><a href="#source-4" aria-label="출처 4">[4]</a></sup> 반면 <code>text-decoration-line</code>과 <code>text-decoration-style</code>은 중간값 없이 바뀌는 이산(discrete) 유형입니다.<sup class="cite"><a href="#source-7" aria-label="출처 7">[7]</a></sup><sup class="cite"><a href="#source-8" aria-label="출처 8">[8]</a></sup> 그래서 hover 효과는 굵기·간격·색으로 만드는 편이 자연스럽습니다. 두 상태 사이의 변화는 <code>transition</code>으로 정하고, 상태는 <code>:hover</code> 같은 의사 클래스로 나눕니다.<sup class="cite"><a href="#source-10" aria-label="출처 10">[10]</a></sup></p>
<pre data-lang="css"><code class="hljs language-css"><span class="hljs-selector-tag">a</span> {
  <span class="hljs-attribute">text-decoration</span>: underline <span class="hljs-number">1px</span>;
  <span class="hljs-attribute">text-underline-offset</span>: <span class="hljs-number">0.2em</span>;
  <span class="hljs-attribute">transition</span>:
    text-decoration-thickness <span class="hljs-number">0.2s</span>,
    text-underline-offset <span class="hljs-number">0.2s</span>;
}
<span class="hljs-selector-tag">a</span><span class="hljs-selector-pseudo">:hover</span> {
  <span class="hljs-attribute">text-decoration-thickness</span>: <span class="hljs-number">3px</span>;
}
<span class="hljs-comment">/* 결과: hover 하면 밑줄이 0.2초 동안 1px → 3px로 굵어짐 */</span>
</code></pre>
<p><code>border-bottom</code> 방식이라면 같은 효과를 위해 테두리 두께와 <code>padding-bottom</code>을 함께 조정해야 했지만, 여기서는 밑줄 속성만 바꿉니다.</p>
<h3 id="자주-하는-실수-색만-바꾸기">자주 하는 실수: 색만 바꾸기</h3>
<p>MDN은 글자 색과 <code>text-decoration-color</code>만 바꾸는 것으로는 링크에 포커스가 있다는 사실을 알리기에 부족하다고 설명합니다. 색만으로 의미를 전달하지 말라는 것입니다.<sup class="cite"><a href="#source-4" aria-label="출처 4">[4]</a></sup> 굵기나 간격 변화처럼 색이 아닌 단서를 함께 주고, 같은 규칙을 <code>:focus-visible</code>에도 적용하세요. <code>:focus-visible</code>은 요소에 포커스가 있고 브라우저가 포커스를 눈에 보이게 표시해야 한다고 판단할 때 적용되는 의사 클래스입니다.<sup class="cite"><a href="#source-11" aria-label="출처 11">[11]</a></sup></p>
<pre data-lang="css"><code class="hljs language-css"><span class="hljs-selector-tag">a</span><span class="hljs-selector-pseudo">:hover</span>,
<span class="hljs-selector-tag">a</span><span class="hljs-selector-pseudo">:focus-visible</span> {
  <span class="hljs-attribute">text-decoration-thickness</span>: <span class="hljs-number">3px</span>;
  <span class="hljs-attribute">text-decoration-color</span>: currentcolor;
}
</code></pre>
<p>밑줄을 아예 없애는 것도 조심해야 합니다. MDN은 사용자가 링크를 알아보는 데 밑줄에 의존하는 경우가 많으니, 링크의 밑줄을 지울 때 주의하라고 적고 있습니다.<sup class="cite"><a href="#source-5" aria-label="출처 5">[5]</a></sup> 밑줄 색을 흐리게 하거나 대비를 낮출 때도 글자·배경·밑줄 색의 대비가 충분한지 확인해야 합니다.<sup class="cite"><a href="#source-4" aria-label="출처 4">[4]</a></sup></p>
